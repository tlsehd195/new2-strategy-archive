# NEW2 전략 탐색 — TIER1 오프사이트 백업 저장소

**이 저장소가 무엇인가**: 크립토 선물 "실전 승격 가능 전략" 발굴 프로젝트(NEW2)의 **대체 불가 데이터(TIER1) 전용 백업**입니다.
원본은 개발 샌드박스(`~/my-project`)에 있고, 이곳은 **샌드박스 전체 소실에 대비한 유일한 오프사이트 사본**입니다.

- 갱신: **매일 09:00 KST 자동 push** (cron) — GitHub Deploy Key 인증
- 각 커밋 = 그날의 전체 스냅샷 (수집 장부 최신치 포함)
- Private 유지 필수 (연구 데이터 + 수집 장부 포함)

## 보안 모델

- 이 저장소에 대한 권한은 **Deploy Key 1개, read/write 한정** (계정 전체 권한 아님)
- 개인키는 샌드박스에만 존재하며 채팅/외부로 나간 적 없음 (공개키만 등록에 사용)
- 회수: 저장소 Settings → Deploy keys → Delete — 즉시 push 차단
- 민감물 혼입 이중 차단: 백업 스크립트가 allow-list 방식 + 개인키/토큰 감지 시 중단

- 측정 29건이 **전부 정직하게 FAIL/폐기로 기록**되어 있음 — 이 저장소의 가치는 "성공만 담은 백업"이 아니라 **전부를 담은 검증 가능한 연구 기록**임
