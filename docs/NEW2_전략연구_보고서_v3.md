**설계(사전 고정)**: 정산 시 펀딩 z(직전 90회=30일 대비) → |z|≥1.2816(B80)/1.6449(B90) → 역발상 진입(정산 다음 봉 시가) → h∈{4,16,48}봉 뒤 시가 청산 → 왕복 12/16/20bp. 가족 24셀 Holm. 통제: 추종 방향 + 무작위 방향 100시드.

**주요 결과 (순16bp 기준, 상세는 results/fr_extreme_results.md)**:

| 심볼-구간 | 최고 셀 | 비고 |
|---|---|---|
| BTC 2021-05~2022-08 | B80 h48 **+42.5bp** | 단 유효n=4, p_holm=1.0 — 표본 불충분 |
| BTC 2023-04~2024-03 | 전 셀 음수 (-17.6~-33.5bp) | B80 h4 t=-2.34 |

| ETH 2024-12~2026-04 | 전 셀 음수 (-19.5~-35.4bp) | B80 h4 t=-2.31 |

- Holm p<0.05 셀: **0/24** → 사전 고정 판정 규칙에 따라 **PASS = False**
- 추종 방향 통제도 전 셀 음수, 무작위 대조 우위 없음
