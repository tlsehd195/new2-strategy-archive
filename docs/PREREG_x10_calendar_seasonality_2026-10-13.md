## 0. 배경과 범위 고지 (정직 선언)

- **6차 원리 스캔 발굴 (Task 30)**: 22건 기존 측정 패밀리 중 **결정론적 캘린더(시간대) 신호를 1차 신호로 사용한 사례 0건** — 조건부 z/이벤트 신호(P1, X3, F1, C1, C4, C5, X1, L3, F2/X6, X5, L1, X7, X2, X4/F3, C3, C7, C9, X8, X9, KP)와 정보원이 구조적으로 상이. Task 29의 5차 스캔에서 "시간 계절성" 쿼리가 명시적 처분 없이 미결로 남아 있던 공백을 본 측정으로 소진한다.
- **문헌 근거 한계 고지**: 6차 스캔 실행 시점에 검색 인프라 이상(쿼리 3종 전부 무관 결과 반환 — research/r6_scan_*.json 보존)으로 신규 문헌 확인 불가. 가설의 근거는 ①구조적 사전: TradFi 세션 개시 전후 리스크 선호 동조(X1 패밀리에서 ES/NQ Δz와 암호자산 동조 ρ 0.014~0.083 실측)와 세션 개시 유동성 증가 ②L1 진단의 탐색 관측(비납품 금요일 08:00 롱 h48 원시 +25.6bp, n=65)이 세션 의존적 드리프트 존재 가능성을 시사 — 단, **이 탐색 관측을 방향 고정에 사용하지 않음**(X1-R 선례: 사후 발견의 복제 실패).
- **DST 미보정 고정 고지**: 미국 세션 진입을 13:30 UTC 연중 고정(CME 지수선물 정규장 개시의 서머타임 기준). 동절기 실제 개시는 14:30 UTC — 규칙 단순성을 위해 미보정하며, 이로 인한 효과 희석은 검정력 감소 방향(보수적).
- **C4/펀딩 정산 시간 축 부분 인접 고지**: ASIA 셀(00:00 UTC)은 펀딩 정산 및 C4가 측정한 프리미엄 인트라-인터벌 스파이크 시각과 일치. 단 신호원이 상이(C4=프리미엄 지수 조건부 회귀, X10=캘린더 개시 드리프트)이며 EU/US 셀은 비일치.
- 신규 다운로드 0바이트 — 기존 로컬 klines(15m)만 사용. 잠금/예약 TEST 구간(BTC 2024-03-25~06-18, ETH 2026-04-28~08-31) 일절 미사용(스팬 자체가 잠금 밖).

## 1. 가설과 1차 방향 (방향 쇼핑 방지 — 사전 고정)

- **가설(구조적)**: 암호자산 단기 드리프트는 TradFi 세션 개시(아시아 00:00 UTC / 유럽 07:00 UTC / 미국 13:30 UTC) 시각에 집중된다 — 세션 개시 시점 매수는 양의 조건부 기대수익을 갖는다.
- **1차 방향 = 롱 (3세션 공통)**. 반대(숏)는 통제(oppose)로만 보고. 측정 후 유의 방향에 맞춰 방향을 바꾸는 것 금지.
- 세션별 개별 방향 사후 선택 금지 — 3세션×2홀드 전부 롱으로 측정하고 Holm 패밀리 내에서 판정.

## 2. 신호 정의 (사전 고정 — 결정론)

- 세션 개시 시각 (UTC, 일중 오프셋): ASIA=00:00 (0ms), EU=07:00 (25,200,000ms), US=13:30 (48,600,000ms).
- 신호는 조건부가 아닌 **결정론 캘린더 이벤트**: 세션 개시 시각과 open_time이 정확히 일치하는 15m 봉이 존재하면 그 시각이 신호 시점.
- 캘린더는 측정 시점 이전에 완전히 알려진 정보 → 진입봉 시가 진입은 인과성 성립(룩어헤드 없음).

## 3. 셀 구성 (24셀 패밀리)

- 2심볼(BTCUSDT, ETHUSDT) × 2스팬 × 3세션 × h{16,48} = **24셀**.
- 스팬 (잠금 해제 구간 — X8과 동일, 끝 미포함):
  - BTCUSDT: 2021-05-02~2022-08-17, 2023-04-07~2024-03-18
  - ETHUSDT: 2021-05-02~2022-08-17, 2024-12-10~2026-04-20
- 스팬 밖 데이터(잠금·예약 TEST 구간 포함) 일절 미사용 — 세그먼트 독립 보존.

## 4. 거래 규칙 (fail-closed)

- 진입: 세션 개시봉의 **시가**. 세션 개시봉 부재(결측) 시 해당 일 스킵.
- 청산: 진입봉 인덱스 + h 봉의 **시가** (h16=4시간, h48=12시간 홀드).
- 진입→청산 구간에 15m 갭 존재 시 드랍(fail-closed), 청산봉이 스팬 밖이면 스킵.
- **겹침 구조 고지**: 셀 내 진입 간격 24시간 > 최대 홀드 12시간 → 셀 내 트레이드 겹침 없음 → 유효n = n (X8류 n/h 보정 불필요). 방법론 교훈 ⑦(일간 신호의 봉별 중복)과도 무관 — 일 1회 결정론 진입.
- 셀 간 시간 중복(예: ASIA h48 vs EU h16)은 별개 셀이며 패밀리 Holm이 다중성을 흡수.

## 5. 통계 규격 (사전 고정)

- Holm step-down, 패밀리와이즈 α=0.05, **24셀 전체 한 패밀리**.
- t검정: 유효표본 = n (겹침 없음), 기준비용 정액 16bp 왕복(진단 순16) — 엔진은 교차검증 단계.
- 통제: ①반대방향(숏) ②무작위 100시드 (부호 무작위화 후 net16 초과 확률 p_ctrl).
- 승격판정 규칙 (큐 장부 사전 고정 그대로): Holm p<0.05 셀 존재 AND 동일 (세션,h) 조합이 4개 심볼-스팬 중 **≥3 양수(valid_n≥30)** AND OOS 양수 세그먼트 ≥2/4.
- OOS: Holm 통과 시에만, 각 스팬 **하위 40%** (인덱스 60% 지점 이후의 세션 개시봉)에 동일 규칙 적용 (60/40 규칙).
