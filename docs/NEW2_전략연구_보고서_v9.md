## §1. 검증 체계 (변경 없음 — 사전 고정)

1. **사전등록 선행**: 측정 스크립트 실행 전 `PREREG_*.md`에 셀 정의·임계값·Holm 규격·OOS 규칙을 고정. 사후 파라미터 재조정은 위반.
2. **Holm step-down 다중검정 보정**: 24~48셀 패밀리와이즈 α=0.05. 통과 셀 없으면 즉시 FAIL.
3. **엔진 비용 교차검증**: 저장소 `backtest/costs.py` CandleCostModel(fee+half_spread+sqrt impact)을 그대로 적용. $10k/$100k 두 규모.
4. **OOS 보호**: Holm 통과 시에만 구간 하위 40% 세그먼트 검증 (60/40 규칙).
5. **최종 승격**: Phase A 통과 + OOS 통과 → DSR(Deflated Sharpe Ratio) ≥ 0.95 → 사용자 승격 보고.
6. **fail-closed 원칙**: 데이터 누락·지연은 거래 생성 안 함(유리한 쪽으로 채우지 않음).
7. **품질 게이트 실적 (v9)**: F2/X6에서 FG 타임스탬프 버그(fg_days=4 — 초 단위 ts를 ms로 잘못 환산)를 quality 필드 점검으로 판정 전 발견 → 수정 후 재실행. 판정에 오염 없음.

2. **F1**: CME 주말 갭은 필이 아니라 **추종 경향**(BTC span2 h48 추종 총 +73~115bp) — 유의미하지만 Holm 미달 + 비용 미달.
3. **C1**: 베이시스 모멘텀 극단(|z|≥1.28, L=4h~72h)은 **추종 부정, 되돌림 경향** — 반대방향 원시 ~+5bp(L≥48), 4h 스케일(L=16)은 원시 ±2bp 내외로 사실상 0. Boons-Prado basis momentum은 암호 15m~72h 인트라데이 지평에서 성립하지 않음(문헌은 월간 지평).

## §7. 정직한 종합 판정

1. **승격 후보 0건은 변함없음** — 9건의 정식 측정이 전부 FAIL, 나머지 8건은 미측정. "유능하다고 주장되는" 외부 전략의 수익 보고는 전부 제공자/저자 주장이며 본 플랫폼 규격으로 측정되기 전까지 유능 판정 아님.
2. **완전 신규(인접성 없음) 원리는 3차 리서치에서도 0건** — 통과 전원이 패밀리 인접 플래그 또는 주파수 한계를 가진 조건부 통과.
3. **방향 엣지의 실체가 더 명확해짐**: 가격·파생·변동성·센티먼트 4개 패밀리를 모두 정식 측정했고 전부 비용 미달. 특히 v9는 "변동성(L3)과 센티먼트(F2/X6)에는 방향 엣지가 있을 것이다"라는 마지막 무작정 희망 두 가지를 정량적으로 소진. 남은 경로는 ①대형 이벤트(만기 L1/매크로 X2)에서 엣지 ≥ 비용 확인, ②N2 maker로 비용 자체를 축소, ③필터·게이트로 손실 억제(방향 아님) — 3가지로 수렴.
4. **필터/게이트 계열은 리스크 관리 보조**로 분류가 정확 (V1 har80과 동일 보류 목록). F2/X6의 역발상 부정은 "센티먼트 필터를 역발상 방향 신호로 쓰면 안 된다"는 근거로 자산화 가능.
5. **탐색 관측의 엄격한 등급화 도입 (v9)**: 비용 벽을 넘는 관측이라도 ①유효n≥30+교차자산 정합(X1-R — 과제 등록) vs ②단일 이벤트 인공물(F2/X6 +71bp — 기각)을 구분. 기준을 명시해 사후 선택 편향을 통제.
