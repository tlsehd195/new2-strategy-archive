# 사전등록: X7 거래소 사건 — Binance 상장 예고 공지 이벤트 (Will List/Launch)

고정 시각: 2026-10-12 (측정 스크립트 실행 전) · 작성: Z.ai Code (Task 21, 목표 루프 사이클 8-후반)
규칙: 본 문서 고정 후 규칙 변경 금지. 사후 파라미터 재조정은 사전등록 위반.

## 1. 가설

Binance의 신규 상장 예고 공지("Will List / Will Launch")는 시장 전체의 리스크 선호 확대
신호이며, 공지 직후 BTC/ETH에 단기 상방 드리프트가 존재한다 → 공지 직후 **롱** (추종).
근거: 상장 공지는 대표적 리스크온 이벤트(상장되는 알트코인 자체는 즉시 급등이 문헌으로
알려져 있으나, 본 후보는 BTC/ETH로의 파급 방향 실측이 목적 — 알트코인 자체 측정은
프로그램 대상 외). 반대 메커니즘(자금 회전: BTC→알트 이탈로 단기 하락)도 이론상 가능하므로
반대 통제(숏)를 정보성으로 함께 산출하되, 1차 방향은 롱으로 사전 고정(방향 쇼핑 방지).

## 4. 거래 규칙 (고정)

- 진입: releaseDate + δ·15m 이후 첫 퍼페 15m봉 시가, δ ∈ {0, 4, 16} (0분/1h/4h 지연 — 3값 고정).
  해당 봉이 구간 밖이거나 없으면 스킵(fail-closed).
- 방향: **롱 고정** (§1 1차 가설).
- 청산: 진입 15m봉 + h봉 후 시가, h ∈ {4, 16, 48} — 3값 사전 고정.
- 보유 구간 내 15m 갭 → 드랍+카운트(fail-closed). 청산봉 구간 밖 → 드랍.

## 5. 셀 구조와 통계 (고정)

- 셀 = (δ, h) → 구성당 9셀 × 4구성(2심볼×2구간) = **패밀리 36셀**, Holm step-down (α=0.05)
- 수익: 롱 수익 평균 → 총bp; 순12/순16/순20 = 평균 − 정액비용(12/16/20bp)
- t검정: (평균 − 16bp)/(sd/√valid_n), **valid_n = n/h (기존 15m 관행 준용)**, 양측 p
- 통제: ①반대방향(숏, 정보성) ②무작위 100시드(seed=20261012) ③구간 드리프트 베이스라인
  (정보성: 해당 구간 전체에서 96봉 간격 무조건 롱 h봉 보유 — 공지 이벤트가 구간 드리프트와
  구별되는지 문서화). 클래스 B는 정보성 수치만.
- 유효표본 조건: valid_n ≥ 30

## 6. 구조적 한계 사전 고지 (측정 전 선언)

- h=48 셀의 PASS 요건은 n ≥ 30×48 = 1,440거래인데, 클래스 A 전체가 882건(구간 내 채택은
  더 적음) → **h48 셀은 구조적으로 PASS 불가**(L1 선례 준용, 규칙은 변경하지 않음).
  h4(요건 n≥120)와 h16(요건 n≥480)만 실질 경쟁 셀.
- 공지가 강세장에 군집하는 선택 편의 존재 → 구간 드리프트 베이스라인으로 문서화(보정 아님).

## 7. 판정 규칙 (고정)

- PASS = Holm p<0.05 셀 ≥1 AND 동일 (δ,h) 조합이 4구성 중 ≥3 양수(순16>0, valid_n≥30)
- 통과 시 즉시 OOS(구간 하위 40%, 양수 세그먼트 ≥2/4). 전원 실패 시 폐기 권고로 종결,
  재파라미터링 없음.

## 8. 비용 교차검증 (고정)

- 엔진 CandleCostModel(costs.py:104-117): fee 5bp + half_spread 2bp + 10%·√participation per side
- $10k/$100k, participation = 주문금액/바 거래대금(qv), 5% 초과 fail-closed
- 엔진 기준 Holm 재계산 — 본 검증이 최종 판정 우선
