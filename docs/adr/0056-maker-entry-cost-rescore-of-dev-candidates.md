## 방법 (결과 전에 고정)
- 후보: 네 파일의 가설 **전부 25개**(H1~H4, N1~N5, 101 Alphas 8개, 잔차 8개). S1·S2를 보고 고르지 않았다. 요청에 이름이 나온 H1, N4, A101, W200 R4는 먼저 보고하되 같은 규칙으로 판정.
- 환산: 연 수익 R(λ,h) = (1−h)·R(비용0) − λ·(R(비용0) − R(기본 비용)). 변동성은 비용 0 행 기준. λ는 후보 자신의 비용에 곱하는 배수.
- 시나리오 (ADR 0049 비율): 손익분기 수수료 λ=1.00(메이커 4bp 이상, 이득 없음) / 낙관 λ=0.47(닿으면 체결) / 중립 λ=0.70(120초 대기, 미체결은 시장가 추격으로 전량 체결) / **보수 λ=0.79 + 체결 손실 h=0.34**(진입만 지정가·청산 시장가로 놓친 거래 반영, 최악 종목 미체결률 34%만큼 총수익을 잃되 놓친 다리의 비용은 줄이지 않음 = 일부러 가혹한 경계. 놓친 다리가 가격이 달아난 쪽이라는 역선택을 이 경계가 담는다).
- 판정: ADR 0040 조건 a~e를 그대로(a 우연 최댓값 초과, b 알파 t≥2, c 앞·뒤 절반 모두 양, d S2>0.5, e 비용 2배에서 S1>0). **보수 시나리오에서 모두 충족해야 PROMISING.**
- 선형 환산의 타당성(결과 보기 전 검증): 발표된 비용 2배 행과 비교하면 S1 오차 대부분 0.01 이내(W200 잔차 최대 0.22), 잔차 파일에 이미 있던 지정가 0.70 행과는 S1 오차 0.00~0.04로 일치. 소수점 둘째 자리의 차이(예: 손익분기 λ=1.0에서 W200 R4 0.87 대 발표 0.81)는 변동성이 비용마다 약간 다른 데서 온다. 앞·뒤 절반은 S1 변화만큼 평행 이동한 근사다.

## 결과 (S1/S2 연 샤프, 비용 후)
| 후보 | 기본 | 낙관 λ0.47 | 중립 λ0.70 | 보수 λ0.79+h0.34 | S1 비용 손익분기 λ |
|---|---|---|---|---|---|
| H1 모멘텀 28일 | 0.28 / 1.37 | 0.44 / 1.58 | 0.37 / 1.50 | 0.14 / 0.88 | 1.9 |
| N4 테이커 흐름 | 0.50 / 1.23 | 0.56 / 1.27 | 0.54 / 1.25 | 0.32 / 0.80 | 5.6 |
| A101 | 0.19 / 1.24 | 0.43 / 1.40 | 0.33 / 1.33 | 0.07 / 0.78 | 1.4 |
| W200 잔차 MAX(R4) | 0.81 / 0.17 | 1.13 / 0.61 | 1.02 / 0.42 | 0.51 / 0.01 | 2.8 |

- **S1·S2가 모두 양(+)인 후보 수** (25개 중): 손익분기 8, 낙관 9, 중립 9, 보수 7. 지정가 효과는 비용이 자본의 20~30%인 후보(A101, A006, W200 계열)에서 S1 +0.2~0.3으로 가장 크고, 비용이 7%인 N4에서는 +0.04에 그친다(총수익이 이미 비용보다 훨씬 커서 비용이 원래 벽이 아니었다).
- **판정: 세 시나리오 모두에서 조건 a~e를 충족한 후보 0개, 보수 시나리오 PROMISING 0개.** 이유는 비용이 아니라 신호의 크기다.
  - H1: 알파 t 0.2~0.7, 뒤 절반이 음수 또는 0 근처. A101: t 0.1~0.7, 보수에서 뒤 절반 음수.
  - N4: 앞·뒤 절반, S2>0.5, 비용 2배는 통과(ADR 0040과 같음)하나 알파 t 0.5~0.9, 낙관 S1 0.56이 우연 최댓값 0.75 아래.
  - W200 R4: 가장 가깝다. 낙관에서 S1 1.13이 우연 최댓값 0.91(N=8)은 넘지만 누적 시도 기준(2.44)과 알파 t(1.81 < 2)에서 떨어지고, 중립·보수에서는 S2가 0.42·0.01로 0.5 미만이다. 이 코인 200개 유니버스는 비용이 자본의 22%인 얇은 코인 중심이라 ADR 0049의 체결 추정(유동성 큰 10종목)이 가장 덜 맞는 곳이다.
- ADR 0055에서 기준을 풀면 남던 H1·N4·A101·W200 R4는 비용을 낮춰도 같은 자리다. 비용이 막았던 것이 아니라 신호가 약했다(총수익 S1 0.2~0.6 수준, 표준오차 약 0.63 이내).
- 빠른 단기 20개와 R9 33개는 ADR 0049에서 이미 같은 방법으로 다시 평가했고(20개 NOT_PROMISING, 진입 통과 4개 중 독립 3개로 기준 5개 미달), 이번에 다시 하지 않았다.

## 한계
- 지정가 비율은 유동성 큰 10종목, 사흘 반의 공개 호가 시뮬레이션 값이다. 알트 200개로 일반화한 것은 가정이다.
- 역선택은 무작위 시점 주문으로 쟀다. 신호는 큰 움직임 뒤에 나오므로 더 나쁠 수 있다(보수 시나리오와 손익분기 λ가 여유를 보여 준다: 기본 S1이 양수인 후보는 H1·N4·A101·W200 R4 모두 λ가 1.4 이상이어도 S1이 양수).
- 보수의 h=0.34는 가혹한 경계이지 추정이 아니다. 일 단위 28일 보유 후보에서 실제 미체결은 리밸런싱 날 추격 시장가로 흡수되므로 중립에 가까울 것이다.
- 환산은 선형 근사이고 앞·뒤 절반은 평행 이동이다. 원 거래를 다시 돌리지 않았다.
- S1·S2는 이전 ADR에서 이미 본 숫자라 새 정보가 없다. 사전등록은 선택 편향 방지용이지 자료를 늘리지 않는다.
