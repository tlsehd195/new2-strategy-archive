# ADR 0001 — 탐색 엔진 잔여 핵심 결함 수정

- 상태: Accepted (PR #1, 머지 커밋 `66646cdda5216ce385c459d02feff2c66673834e`)
- 날짜: 2026-10-15
- 범위: `run/discovery/`

## 맥락
감사에서 다음 결함이 재현되었다: BH-FDR이 평가 순서에 따라 결과가 달랐다(후보를 먼저/나중에 평가하면 같은 p=0.02가 합격/탈락). 포트폴리오 자산곡선이 미실현 손익을 빠뜨려 보유 중 50% 낙폭이 MDD 0.0015로 나왔다. 비용 계산 실패 시 7bp짜리 더 싼 비용으로 대체했다. 데이터가 없어도 잠금 TEST가 "사용 1회"로 기록되었다. 환경 ID가 펀딩·FNG·비용 파라미터·실제 코드를 포함하지 않았다. 승격 게이트가 불리언 입력을 믿었고, `run_cycle.sh`는 배치 인자를 전달하지 않고 하드코딩 경로를 썼다.
제약: 실거래·자금 이체·실계좌 API 금지, 테스트 삭제·비활성화 금지, 기존 원장·잠금 TEST 기록 삭제 금지, 통계 기준 완화 금지.

## 결정
1. **FDR은 세대 단위로 한 번만.** 사전등록된 전체 후보 공간(세대, `G-…`)이 m이다. 모든 후보의 dev 결과가 나온 뒤 BH(q=0.05)를 한 번 실행하고, 결정은 append-only로 저장한다. 그 전에는 누구도 생존하지 못하므로 잠금 TEST를 예약하지 않는다. p-값이 없는 후보는 m에 포함하고 기각하지 않으며 p를 대체하지 않는다. 새 상태 `AWAITING_FDR`를 둔다.
2. **포트폴리오는 시가평가(MTM).** equity = cash + 미실현 손익, MDD도 같은 곡선. 격리 마진, 청산 시 마진을 한 번만 잃음, 마지막 봉은 시가에 강제 청산. 가격을 매길 수 없는 청산은 대체 비용 없이 `cost_status`로 표시해 통과 불가.
3. **비용 실패는 분류한다.** `FAIL_COST`(거부), `DATA_MISSING`, `ERROR`(수치 오류)로 나누고 유리한 fallback을 제거했다. 비용 모델은 검증 전까지 `UNVERIFIED_COST_MODEL`이며 그 PASS는 승격 불가.
4. **잠금 TEST 상태 머신**: `AVAILABLE→RESERVED→EVALUATION_STARTED→CONSUMED`, `BLOCKED_DATA_MISSING`/`FAILED`. 데이터 부재는 소비 없이 차단, 평가 시작부터 노출로 간주, `fcntl.flock`으로 동시성 제어, 결과는 불변.
5. **실험 컨텍스트 ID(`C2-…`)** = 클라인·펀딩·FNG 내용 해시, 데이터 정책, 비용 파라미터 전체와 비용 모델 소스 해시, 엔진 소스 해시, 검증 설정, 런타임 버전의 정규화 해시. 시계·uuid·호스트는 넣지 않는다.
6. **사전등록 manifest**: 후보 id 정렬 목록+정규화 정의+생성기 버전+FDR 스펙의 해시(`G-…`)를 write-once 파일로 저장. 기존 `preregistration.json`은 그대로 둔다.
7. **승격 게이트는 증거 기반**: manifest 소속, 최종 FDR 결정, 잠금 TEST 사용 기록, 검증된 비용 모델, 조합은 실제 포트폴리오 결과가 필요하다.
8. **`run_cycle.sh`**: 배치 인자 검증·전달, `pipefail`, 종료 코드 보존, 어느 cwd에서나 실행, 중복 실행 방지는 runner의 `ProcessLock`으로 단일화.
기존 테스트 중 결함 동작을 굳혀 둔 6개는 새 동작에 맞게 다시 썼다(삭제·기준 완화 없음).

## 결과
- 테스트 168개(기존 91 + 신규 77) 통과, 판정 `PARTIAL`.
- 알려진 한계: 전체 779개 후보를 모두 평가해야 최종 판정이 나온다(batch 10 기준 최소 78사이클). BH의 PRDS 가정은 미검증. 비용 모델 미검증. 다중 심볼 포트폴리오 그리드 불일치는 fail-closed 기록. 청산은 엔진 가정이며 거래소 규칙이 아님. 실데이터가 없어 실사이클은 `BLOCKED_DATA_MISSING`, 수익성은 `NOT_VALIDATED`.
