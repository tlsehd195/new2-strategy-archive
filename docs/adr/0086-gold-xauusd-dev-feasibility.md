- 날짜: 2026-11-17
- 범위: 사전등록 `run/audit/evidence_gold_dev_20261117/prereg_gold_dev_v1.json`(결과 계산 전 커밋 `305b890`), 새 도구 `run/gold_dev.py`, 테스트 `run/test_gold_dev.py`(5개), 결과 `gold_dev_result.json`, 시도 기록 `run/audit/dev_search_trials.jsonl` 1줄(13건, 새 탐색 맥락 `GOLD-XAUUSD-spot-v1`). 엔진·통계 기준·비용 프로필·사전등록 v2/v3 변경 없음.
- 사용자 요청: 동동, 2026-11-17 "구조를 바꾸는건 어때? … 금 선물로 하면 고래들이 조작 할 수 없잖아 그리고 차트에 선을 그었을 때도 정확도가 훨씬 높기도 하고"

## 데이터 (이 환경에서 키 없이)
- 거래소 공개 REST(Binance·OKX·Bybit·Hyperliquid), data.binance.vision, Yahoo, Stooq, Dukascopy, HistData, Kaggle, CME는 모두 프록시에서 403(차단). GitHub·PyPI만 열려 있다.
- 쓴 자료: GitHub 공개 저장소 `Dypoi/XAUUSD_Dataset`의 현물 금 1분봉 매수·매도호가(2016-09~2026-09, 연 1파일, 출처 미기재, Dukascopy 형식으로 보임). **UNVERIFIED_THIRD_PARTY**, 장외 현물 호가이지 선물 체결이 아니며 거래량은 그 호가처의 호가량이다. 주말 공백 위치(금 20:45/21:45 → 일 22:00/23:00)로 UTC로 판단.
- 다른 후보: `Touhid-HZ/xauusd-tick-data-2025/2026`(Dukascopy 틱, 2025~2026만), MT5 내보내기 저장소 여러 개. 실제 금 무기한(Binance XAUUSDT, 2026-01 상장)은 기록이 10개월 남짓이고 이 환경에서 못 받는다.

## 비용
- 이 자료의 호가 간격 중앙값 2.02bp(평균 2.21, 상위 10% 2.60; 시간대별 1.94~2.44bp, 미국장 마감 뒤 넓음).
- 판단 비용 perp_taker: 수수료 편도 5bp + 자료의 매수·매도호가로 체결 + 보유 일수 연 3% 운반비(롱 지불·숏 수령) → 왕복 약 12bp. 암호화폐 측정 비용 약 26.6bp의 절반 정도.
- CME GC 같은 경로(futures_1bp: 편도 1bp + 호가): 왕복 약 4bp. 보고만.
- 기존 비용 모형(`estimate_v1/v3`, 거래량 비례 충격)은 거래소 호가창 기반이라 그대로 쓸 수 없다. 금에 새로 필요한 것: 거래 시간·주말 공백(15분 시험은 보유 중 30분 넘는 공백이 있으면 진입 안 함, 일봉은 공백 위험 그대로 반영), 펀딩 또는 만기 롤오버(운반비로 대체), 무기한의 실제 호가·펀딩 기록.

## 결과 (S1 2016-09~2019-08 931일 / S2 2019-09~2021-08 623일, 연 샤프)
- **13개 모두 NOT_PROMISING.** 13개 우연 기대 최댓값(S1 3년) 0.98.
- 고저선+거래량 급증(15분, 반전 8개+돌파 1개): 거래당 총수익 −6.4 ~ +0.6bp, 비용 0에서도 샤프 −1.64 ~ 0.19. 비용 후 S1 샤프 −2.4 ~ −6.3, S2도 모두 음수. CME형 4bp 비용에서도 음수. 돌파 거울은 반전의 정확한 부호 반대라 총 −0.6bp.
- 아시아 범위 돌파: 총 +0.26bp/거래, perp 비용 후 −11.8bp, 샤프 −2.76.
- 일봉 추세 TSMOM 60일: S1 0.49 / S2 0.46(t 0.85, S1 거래 40회), 20일 0.03 / −0.50, Donchian 20일 0.00 / −0.67. 같은 기간 금 보유만 해도 S1 0.50 / S2 0.60이라 추세 규칙이 보유를 넘지 못했다.
- 결론: 금은 비용이 암호화폐의 절반 수준이지만, 시험한 규칙의 비용 전 수익이 0에 가깝다. 실패 원인(신호 크기)은 자산을 바꿔도 그대로다.

## 결정
- 13개 모두 승격하거나 검증·전진 창 후보로 보내지 않는다. 누적 DEV 시도 수에 13을 더한다(맥락은 금으로 분리, ADR 0083 이후 방향과 같음).
- 금 2021-09 이후 자료는 읽지 않은 채로 둔다. 금으로 더 하려면 새 가설을 사전등록하고 같은 DEV 구간에서만 시험한다.

## 한계
- 출처 불명 제3자 현물 호가 자료. 선물·무기한의 실제 호가·펀딩·롤오버와 다르다. 거래량은 시장 전체가 아니다.
- 단일 자산 3년이라 검정력이 낮다(연 샤프 1의 진짜 효과도 놓칠 가능성이 큼, 사전에 명시).
- Binance 금 무기한의 실제 수수료·호가는 이 환경에서 확인하지 못했다(표준 USDT-M 테이커 5bp로 가정).
