- 상태: Accepted (측정·기록만, 추정치 상태 변경 없음 — 1건이라 VERIFIED 아님)
- 날짜: 2026-11-02
- 사용자 요청: 동동, 2026-11-02 (OKX BTCUSDT 영구선물 실거래 스크린샷 업로드, "해봐")
- 범위: `research/okx_real/real_fills.csv`(실거래 기록, 모의와 분리), `real_fills_TEMPLATE.csv`, `HOWTO_실거래기록_올리는법.md`, `run/okx_real_cost.py`

## 기록한 건 (앱 표시값)
BTCUSDT Perp, 롱, 격리 20배. 진입 77,303.12, 청산 78,363.2. 실현손익 +54.81 USDT(+24.40%). 최대 보유=청산 보유=4,491.31 USDT. 2026-10-30 17:37:26 ~ 11-02 13:51:55(앱 시각, 시간대 미확인, 약 67시간).
- 일관성 점검: 증거금 = 4,491.31/20 = 224.57, 54.81/224.57 = 24.41% ≈ 표시 24.40% → 4,491.31은 진입 명목, 수익률은 증거금 기준.

## 역산
- 가격 변동만의 총손익 = (4,491.31/77,303.12) × 1,060.08 = +61.59 USDT (+137.1bp).
- 실현손익 54.81과의 차이 = 6.78 USDT = **진입 명목의 15.1bp**. 이것이 수수료 + 펀딩 + (시장가였다면) 체결가 미끄러짐의 합이다.
- 이 값을 나눌 수 없다. Linked orders(분할 체결, 메이커/테이커, 수수료)와 펀딩 내역이 없다. 참고로 양쪽 테이커 5bp라면 수수료만 약 10.1bp(4.52 USDT), 나머지 약 5bp가 펀딩·슬리피지인데 계정 수수료 등급을 모르므로 가정일 뿐이다. 보유 중 8시간 정산이 8번 이상 있어 펀딩이 들어간 것은 확실하나 크기를 모른다. 또 앱의 "실현손익"이 수수료·펀딩을 포함하는지는 OKX 표시 정의에 의존한다(포함으로 가정, 확인 필요). 시각의 가격은 앱의 평균 진입가라 분할 체결이면 평균이다.

## 기존 측정과의 비교 (형식)
| 항목 | 값 | 비고 |
|---|---|---|
| 이번 실거래 왕복(수수료+펀딩+미끄러짐) | 15.1bp (n=1) | 진입 명목 기준, 보유 약 67시간 |
| ADR 0011/0049 측정 왕복(시장가, 중앙~최악) | 12.0 ~ 15.6bp | 공개 호가 기반, 펀딩 제외 |
| 보수적 판정 비용 | 26.6bp | 최악 종목·90% 분위 |
| 지정가 환산 | 18.5bp | 0.70 배 |
- 15.1bp는 측정 시장가 왕복 범위 안이며 26.6bp보다 낮다. 그러나 **1건이고 BTC(가장 유동적인 종목)에 소액이라** 분포를 대표하지 않고, 펀딩이 섞여 있어 같은 정의가 아니다. 추정을 낮출 근거로 쓰지 않는다(비용 가정 변경 없음).
- 이전 모의투자(`okx_paper`)는 40만~330만 USDT 크기에 슬리피지 미반영이라 이 값과 비교 불가.
