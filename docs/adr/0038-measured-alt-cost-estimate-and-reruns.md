- 모수: 수수료 5bp(가정 유지), 반스프레드 7.27bp(가정 2bp+3bp 여유=5bp 보다 큼), 충격계수 0.0015(가정 0.1보다 약 65배 작음), 최대 참여율 5%.

## 2. 진입 기준(S1 연 샤프 ≥ 1.0) 재집계, 33개 후보, 유동성 9종목
- 후보 규격 33개는 저장돼 있지 않아 같은 명령(R9, DEV 전용, 컨텍스트 `C2-ccfa2ef38101803483e1`, 894 평가/63 통과/33개 후보)을 다시 돌려 복원했다. 후보 목록과 순서가 기존과 같다.
- **통과 1/33**(가정 비용에서는 0/33, 최고 0.17). 통과한 `S-ed2d1c8ed9cf1879`는 S1 1.009로 문턱을 간신히 넘었고 S2는 −0.04다. 다음은 0.91, 0.87.
- v2 규칙은 진입 기준을 넘는 처음 5개가 필요하므로 **5개 미만 → 규칙상 등록하지 않는다**. 비용 추정 덕에 후보는 늘었지만 등록 요건에는 크게 못 미친다.

## 3. 알트 4개 가설 재실행 (동동 님 허락, 2026-10-27; 같은 4개, 같은 규칙, 새 실행으로 셈)
- 같은 주소의 공개 아카이브를 다시 받아 만든 자료이고, 비용 0 행이 ADR 0035와 소수점까지 같아 자료는 같다. 비용만 측정값(한쪽 12.3bp + 0.0015·√(주문/거래대금))으로 바꿨다.

| 가설 | S1 (가정→측정) | S2 (가정→측정) | S1 앞/뒤 절반 | 표시 |
|---|---|---|---|---|
| H1 모멘텀 28일 | −1.26 → 0.37 | −0.53 → 1.56 | 0.60 / 0.06 | NOT |
| H2 반전 7일 | −3.21 → −0.70 | −3.54 → −2.39 | −0.81 / −0.58 | NOT |
| H3 펀딩 캐리 | −1.51 → 0.60 | −1.12 → 0.69 | 1.11 / −0.10 | NOT |
| H4 저변동성 | −1.37 → −0.43 | −1.18 → −0.15 | −0.13 / −0.82 | NOT |

- 비용이 낮아져 H1·H3는 플러스가 됐지만 S1 값이 우연 기대 최댓값(4개 중 최고 0.66) 아래이고, H3는 뒤 절반에서 사라진다(−0.10). H1은 S2에서 1.56이지만 S2는 판단에 쓰지 않는다. 결론은 4개 모두 NOT_PROMISING으로 그대로이며 승격·검증 창으로 보내지 않는다.
