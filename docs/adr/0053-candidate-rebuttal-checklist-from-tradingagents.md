# ADR 0053 — 후보 반박 체크리스트 (TradingAgents의 "리스크 심사" 구조를 규칙으로 옮김, 문서만)

- 상태: Accepted (문서만. 코드·통계 기준·비용 가정·사전등록 변경 없음)
- 날짜: 2026-10-29
- 사용자 요청: 동동, 2026-10-29 (TauricResearch TradingAgents 조사 후 "추천하는 대로 진행")
- 열지 않은 것: 사전등록 활성화, 검증·잠금·IW1 구간. LLM 호출, 외부 API 키, 설치 없음.

## 맥락
TradingAgents(arXiv 2412.20138, Apache-2.0)는 트레이더의 결정을 리스크팀이 따로 반박하고 마지막에 승인/거절하는 단계를 둔다. 논문 백테스트는 2024-01~03 약 3개월, 3종목, 거래비용·슬리피지 언급 없음, 논문 스스로 샤프가 "예상 범위를 넘는다"고 적었고, LLM 학습 기억에 의한 룩어헤드 오염은 논의하지 않았다. 따라서 성과 수치는 우리 기준의 증거가 아니며, LLM이 신호를 정하는 용도로는 쓰지 않는다(재현 불가, 시도 횟수 계산 불가).
빌릴 것은 구조뿐이다: **후보가 DEV를 통과하면 반대 논거를 정해진 항목으로 기계적으로 점검한다.** LLM 없이 규칙으로 한다.

## 결정: 후보 반박 체크리스트 (후보 하나당, 결과를 보기 전에 항목을 고정)
각 항목은 "통과 증거"가 아니라 "탈락 사유 탐색"이다. 하나라도 걸리면 후보는 보류 사유를 기록한다. 기존 ADR의 도구·수치를 그대로 쓴다.

| # | 반박 질문 | 확인 방법 (기존 근거) |
|---|---|---|
| 1 | 비용 후에도 남는가? | 측정/추정 비용 프로필 기준 순수익. 비용 0에서도 우연 최댓값보다 높은가 (ADR 0038, 0045, 0048) |
| 2 | 비용 가정이 낙관적이지 않은가? | 수수료·스프레드·충격 배수 민감도, 메이커 행은 낙관 경계로만 (ADR 0029 cost_sensitivity, 0049) |
| 3 | 시도 횟수가 반영됐나? | 누적 DEV 시도 수 대비 우연 기대 최댓값. 진입 기준 S1 샤프≥1.0은 변별력 없음(ADR 0048) |
| 4 | 같은 거래의 복제가 아닌가? | 같은 진입 신호 중복, 실제 거래 겹침 (ADR 0031, 0033, 0029 behaviour_overlap) |
| 5 | 한 장세·한 기간에서만 번 것 아닌가? | 장세별 성적표, S1/S2 부호 일치 (ADR 0026, 0044, 0050) |
| 6 | 종목·종목군 쏠림이 없는가? | 독립 종목 수(N_eff), 상위 종목 제거 시 수익 (ADR 0047) |
| 7 | 시점 누출이 없는가? | 시점 고정(point-in-time) 입력, 당일 정보만 사용 (ADR 0003, 0029 재현 번들) |
| 8 | 규칙이 사전에 고정됐나? | 사전등록 해시가 결과보다 먼저 커밋됐는가, ACTIVE 상태인가 (ADR 0029 prereg_gate) |
| 9 | 최대 낙폭·꼬리 손실이 감당 가능한가? | DEV 낙폭, 최악 일·최악 거래 비중 |
| 10 | 효과가 유동성이 낮은 곳에서만 나오지 않는가? | 저유동 보정 비용 재실행 (ADR 0041) |

판정 표기: 항목별 `PASS / FLAG / NOT_CHECKED`. FLAG가 하나라도 있으면 후보 상태는 바뀌지 않고(효력 없음) 사유만 기록한다. 이 체크리스트는 새 관문이 아니며 기존 관문을 대체하지 않는다.

## 쓰지 않는 것
- LLM이 매수/매도를 정하게 하는 것. 뉴스·감성 분석가 역할(우리 데이터에 시점 고정된 과거 뉴스가 없고 LLM 기억 오염 위험).
- 논문의 샤프·수익률을 기대치로 삼는 것.

## 보조 용도(선택, 아직 안 함)
- 진입 이유의 자연어 기록과 NOT_PROMISING 결과 요약. 신호에 되먹임하지 않으면 시도 횟수에 영향이 없다. 시작하려면 외부 API 사용 허락을 먼저 받는다.

## 결과
- 장점: 새 위험 없이 후보 점검 순서가 고정되고, 이미 흩어져 있던 점검이 한 표로 모인다.
- 비용/남은 위험: 항목 9(낙폭·꼬리)는 기존 ADR에 단일 도구가 없어 수동 확인이 필요하다. 자동화하려면 별도 ADR로 코드를 추가한다.
