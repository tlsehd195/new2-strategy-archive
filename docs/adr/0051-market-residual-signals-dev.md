# ADR 0051 — 시장 요인을 뺀 잔차 신호 4개 사전등록과 DEV 실행 (U50·W200, 보정 비용)

- 상태: Accepted (측정만, 기준 변경 없음)
- 날짜: 2026-10-29
- 범위: 사전등록 `run/audit/evidence_residual_signals_20261029/prereg_residual_signals_v1.json`(자료를 받기 전에 커밋 `469e6c3`), 새 도구 `run/residual_signals_dev.py`(ADR 0047 엔진을 신호·가설·유니버스만 바꿔 재사용), 테스트 `run/test_residual_signals.py`(6개), 결과 `residual_signals_dev.json`, 시도 기록 `run/audit/dev_search_trials.jsonl` 1줄(8건). 엔진·통계 기준·비용 프로필·사전등록 v2/v3 변경 없음.
- 선행: [ADR 0047](0047-wide-universe-effective-names-dev.md)(코인이 사실상 한 요인으로 움직여 유효 독립 종목 약 3개 → 다음 시도로 "시장 요인을 뺀 잔차 기준 신호"를 권고)
- 사용자 요청: 동동, 2026-10-29 ("10월 31 그거 결과와 시작 가능한 아이디어 새 사전등록")
- 열지 않은 것: 사전등록 활성화, 검증·잠금·IW1·종이 구간. 읽은 시장 자료는 DEV 구간뿐.

## 무엇을 고정했나 (결과를 보기 전)
- 시장 요인: 그 시점 상위 50개 종목의 일별 수익률 동일가중 평균(BTC는 S2에서 읽지 않으므로 쓰지 않음). 종목마다 직전 90일로 베타를 구하고(절편 포함, 최소 60일) 잔차 e = r − β·m.
- 가설 4개(문헌 근거, 보유일·방향은 결과 보기 전에 고정):
  - R1 잔차 모멘텀(Blitz–Huij–Martens 2011): 28일 잔차 합 / 잔차 표준편차, 큰 쪽 롱, 28일 보유
  - R2 잔차 단기 반전(Blitz 등 2013): 7일 잔차 합, 작은 쪽 롱, 7일 보유
  - R3 고유 변동성(Ang 등 2006): 30일 잔차 표준편차, 작은 쪽 롱, 28일 보유
  - R4 잔차 복권 수요(Bali–Cakici–Whitelaw 2011의 잔차판): 28일 잔차 최댓값, 작은 쪽 롱, 28일 보유
- 유니버스·엔진·비용은 ADR 0047 그대로: U50, W200(하루 거래대금 200만 USDT 이상, 상위 200), 5분위 롱숏, 보정 비용(테이커 수수료 5bp 기본 등급, 메이커 2bp는 쓰지 않음)이 판단. 참고 행으로 비용×2, 얇은 호가 구간만 ×2, 비용 0, 지정가 환산 0.70배(ADR 0049, 검증 불가라 판정에 안 들어감).
- 시도 8건(4×2). 판정 표시는 ADR 0047과 같은 6조건(우연 최댓값 초과, 베타 뺀 알파 t ≥ 2, S1 앞·뒤 반 모두 양수, S2 > 0.5, 비용×2·얇은 구간×2에서 S1 > 0). 기준 완화 없음.

- **8건 모두 NOT_PROMISING.** 우연 최댓값은 8건 기준 0.91, 누적 시도(11,886건) 기준 2.44. 가장 나은 W200 R4(0.81)도 8건 기준 0.91에 못 미치고, 베타 뺀 t 1.31(< 2), S2 0.17(< 0.5), 비용×2의 S2는 −0.51이라 탈락이다. S1 앞·뒤 반이 모두 양수인 것은 이것뿐이다.
- **시장을 뺐는데도 순위가 거의 안 바뀐다.** 잔차 신호와 원래(총수익) 신호의 순위 상관이 평균 0.84~0.93이다(S1·S2 모두). 코인 베타가 서로 비슷해서 시장을 빼도 "누가 위·아래인가"가 그대로라는 뜻이며, 새로운 정보를 더한 시도라기보다 같은 시도의 재표현에 가깝다. 8건은 독립이 아니고 ADR 0035·0047 원신호들의 재판이다. 포트폴리오 시장 베타는 −0.07~0.03이라 롱숏 자체가 이미 시장 중립이었다.
- 잔차화로 얻은 것은 거의 없다: 같은 U50에서 원신호 저변동성은 0.43이었는데 잔차판 R3는 0.12이고, 잔차판에서 0.81이 나온 곳은 W200 R4뿐이다. 얇은 코인(W200)에서만 나은 값이 나오는데, W200의 비용은 자본의 20~59%이고 거래 다리의 32~41%가 호가 참여율 5% 한도를 넘는다(ADR 0047과 같은 패턴). 지정가 0.70배(검증 불가)로도 결론은 같다.
- 유효 독립 종목 수는 ADR 0047과 같다(U50 3.2, W200 2.7 / S2 3.4, 3.2).

## 결정
- 8건 모두 승격하거나 검증·전진 창 후보로 보내지 않는다. 사전등록 상태는 DRAFT_FOR_DEV_ONLY 그대로이고 효력이 없다. 어떤 사전등록(v2/v3)도 활성화하지 않았다.
- 누적 DEV 시도 수에 8을 더한다(시도 기록 1줄).
- W200 R4가 우연 최댓값 근처이므로 기록만 해 둔다. 이것만 따로 파고드는 것(창 길이·K·보유일 변경)은 새 시도이며, 앞서 본 W200 얇은 코인 비용 문제 때문에 추천하지 않는다.

## 한계
- 시장 요인은 U50 동일가중 평균이라 BTC 단독 요인과 다르다. 베타 추정 창(90일)이 신호 창을 포함한다(문헌 관행, 사전등록에 명시).
- 비용은 ADR 0041 외삽(41만 USDT 미만 구간은 전부 외삽)이며 VERIFIED가 아니다.
- S1 2.55년은 짧다. 80% 검정력의 최소 탐지 연 샤프가 약 2.1이므로, 연 샤프 1짜리 진짜 효과는 대부분 NOT_PROMISING으로 나온다.
- 상장폐지 종목은 결측일을 0 수익으로 둔다(생존 편향 방향은 알 수 없다).
