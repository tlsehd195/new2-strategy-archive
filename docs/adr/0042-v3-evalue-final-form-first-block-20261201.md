- 사용자 결정: 동동, 2026-10-28 ("추천으로 진행", 10-31 질문 3개에 대한 답, 프로젝트 조정자 경유)

## 결정 (동동, "추천으로")
1. **v2는 등록하지 않는다(A).** 진입 기준 통과 1/33, 규칙상 5개 필요(ADR 0023 D5). v2 초안은 DRAFT로 그대로 둔다.
2. **v3를 2026-12-01 첫 블록으로 마무리한다(C).** 베팅 규칙은 이미 정한 WS-R 식 (15)/(26) 베팅곱(ADR 0030/0032).
3. **알파 분할 유지.** v3 α = 0.0091(기각선 E ≥ 약 110). v2 몫 0.0213은 v3로 옮기지 않고 쓰지 않은 채 남긴다.

## 최종형 초안에서 정한 것 (`walkforward_evalue_v3_FINALFORM_DRAFT.json`)
- 스키마를 최종형(`walkforward_evalue_prereg_v3`)으로 바꾸고 상태 줄에 DRAFT를 남겼다. `prereg_gate`에 이 스키마의 필수 항목 규칙을 추가했고, 게이트는 빠진 항목 없이 **DRAFT**로 판정한다.
- **구성원 규칙**: DEV 전용 evolve 상태의 `validation_candidates()` 순서대로 처음 5개(진입 기준 없음). 각 규칙을 9종목 모두에 적용, 동일 비중 묶음.
- **매 블록 재실행에 대한 발견**: 초안은 "블록마다 직전 데이터로 엔진 재실행"이었지만, 엔진의 DEV 읽기는 고정 날짜에서 끝난다(2025-10-21 이후는 ETH 검증·잠금·종이 구간이라 금지). 그래서 재실행해도 매번 같은 후보가 나온다. 구성원을 한 번 고정하고 매 블록 같은 묶음을 거래하며, 블록마다 구성원 파일 해시와 코드 고정값 두 개를 다시 확인한다. 가설은 여전히 하나다.
- **비용**: 초안의 규칙("첫 블록 전에 측정 비용이 봉인되면 그것을 쓴다")이 발동했다. ADR 0038의 `PE-ed757f477622f48d054b4172`(2026-10-27 봉인, 커밋 e40e502). VERIFIED는 아니다.
- **종목**: 측정 비용으로 75bp 규칙을 다시 적용해도 9종목 모두 남는다(한쪽 약 13bp). 기록이 다루지 않는 알트는 추가하지 않는다.
- **크기**: DEV S1에서 묶음 일별 변동성이 블록 자본의 1%가 되도록 배율 k(상한 10). 동결 때 한 번 계산해 구성원 파일에 봉인한다.
- **손절·바닥**: UTC 하루 끝마다 평가(닫힌 거래는 순손익, 열린 거래는 마지막 15분 종가로 평가하고 왕복 비용 전부와 펀딩 비례분을 뺀다). 처음으로 −L(5.48%) 이하가 되면 그 값에서 모두 닫고 블록 끝까지 쉰다. 손실은 −B(10.95%)에서 막는다. 갭 공제 c 0.27%, λ 상한 0.75는 그대로다.
- **장부**: `run/audit/evalue_v3/ledger_v3.jsonl` 추가만 하는 해시 사슬. 블록은 끝난 뒤 한 번, 순서대로만 기록하며, 기각이나 VOID 뒤에는 더 기록하지 않는다. 실제 블록 기록은 게이트가 ACTIVE일 때만 된다.
- **활성화 전 남은 일**(초안 `pending_at_activation`): 동동의 최종 확인, 동결할 코드로 DEV 전용 상태 디렉터리 생성, 활성화 파일 작성, freeze → dev-scale, 동동 승인 `prereg_activation_v1` 기록을 **2026-12-01 00:00Z 전에** 커밋. 늦으면 첫 블록이 2027-01이 된다.

## 리허설 (DEV만, 기록 없음)
`run/audit/evidence_v3_final_20261028/README.md`에 숫자가 있다. R9 후보 33개의 처음 5개로 동결 → DEV 배율 → DEV 달 하나로 블록 계산을 끝까지 돌려 도구가 실제 자료에서 동작함을 확인했다. 실제 구성원은 활성화 때 동결 코드로 새로 정한다.

## 한계
- 근거는 합성 시뮬레이션뿐이다. 블록 길이는 실제 달(28~31일), 시뮬레이션은 30일.
- 매 블록 같은 묶음이고, 후보들의 DEV 샤프는 높아야 1 안팎이라 2~3년 안에 110에 닿지 못할 가능성이 크다.
- 하루 끝 평가는 15분 봉보다 거칠어서 하루 안에서 손절선을 지나칠 수 있다. 바닥과 c는 시뮬레이션한 범위까지만 이를 덮는다.
