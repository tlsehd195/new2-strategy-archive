# ADR 0059 — 독립 증거 구간을 늘리는 방법: 후보 자료별 "독립 표본" 계산, 2017-08~2019-12 현물 자료 확보(미개봉), 우선순위

- 상태: Accepted (측정·자료 확보만, 엔진·기준·비용·사전등록 변경 없음)
- 날짜: 2026-11-02
- 사용자 요청: 동동, 2026-11-02 ("1 2 진행" 중 2번: 다른 시기·코인·시장의 실제 자료를 더해 독립 표본을 늘리는 방법 정리)
- 범위: `run/audit/evidence_independent_samples_20261102/`(`fetch_spot_pre2020.py` 다운로더, `neff_s1.py` 계산, `neff_s1_results.json` 결과), 테스트 `run/test_independent_samples.py`(합성 3개). 새 자료는 저장소에 넣지 않고 프로젝트 파일 `data/pre2020_spot_binance_15m_UNREAD.zip`(65 MB, sha256 `2044f436…ddf484`)에 따로 보관.
- 열지 않은 것: 검증·잠금·IW1·종이 구간, 알트의 미개봉 틈새 구간, 사전등록 활성화. 읽은 시장 자료는 **DEV S1(2021-01-01~2023-09-18, 알트 15종)의 일 종가 수익**뿐이다.
- 새로 받은 자료(2017-08~2019-12 현물)는 **무결성만 확인**했다(파일 수·봉 수·15분 간격 빠짐·중복·게시된 SHA-256). 수익률·변동성·상관 같은 통계는 계산하지 않았다. 정직하게 적는다: 형식 확인 중 BTC 2018-03 파일의 첫 두 줄이 화면에 한 번 출력됐다(통계로 쓰지 않음).

## 1. 질문을 이렇게 읽었다
"통과/탈락을 가릴 독립 표본이 모자란다. 이미 쓴 자료를 쪼개 붙이는 것(ADR 0048, `papers/stitching_augmentation_20261101.md`)이 아니라 **진짜 새 자료**를 더하면 독립 표본이 얼마나 늘고, 무엇부터 해야 하나?"

## 2. 독립 표본을 세는 방법
- 한 가설을 "코인 하나당 연 샤프 s"로 놓으면, 증거의 양은 **M = 연수 × 유효 독립 종목 수(N_eff)**(코인·년)이고 80% 검정력에 필요한 양은 **M = (z/s)²**이다. z = z(1−α)+z(0.8), α = 0.05/K(K = 같은 가설군의 시도 수). s = 1이면 K=1에서 6.2, K=10에서 11.7 코인·년(ADR 0055의 6.2년, 11.7년과 같은 식).
- N_eff는 DEV S1(알트 15종, 2.7년, 일 수익)에서 쟀다.
  - 방향성(롱 위주) 수익: 쌍별 평균 상관 **0.58**(반기별 0.55~0.72), N_eff(상관 환산) **1.64**, 참여비 2.55. 종목 6/9/15개일 때 1.53/1.59/1.64, **종목을 무한히 늘려도 1/ρ = 1.72에서 멈춘다**(86종목 1.71, 300종목 1.72).
  - 시장 평균을 뺀 잔차(롱숏 중립·횡단면 수익): 참여비 11.9/14(축당 0.85). 즉 **알트의 방향성 수익은 독립 베팅 1.6개, 횡단면 잔차는 약 12개**로 보면 된다.
- 한계: 상관은 S1 하나의 시기에서 쟀고(상관은 위기 때 올라감), 다른 시기·거래소·현물에는 같은 값을 **가정**한다. 코인마다 샤프가 같다는 단순화다. 비용은 반영하지 않았다(아래 §5).

## 4. 더하면 얼마나 검출할 수 있나 (80% 검정력, 한쪽 α = 0.05/K, 샤프는 **DEV 종목 폭에서의 포트폴리오 연 샤프** 기준)
`detectable = z/√M · √N_eff(DEV)`. 방향성은 N_eff(DEV) = 1.64, 횡단면은 11.9.

| 조합 | M 방향성 | 검출 가능 최소 샤프 방향성 K=1 / K=10 | 횡단면(잔차) K=1 / K=10 |
|---|---|---|---|
| 지금 계획(전진 12개월만) | 1.3~1.6 | 2.5~2.8 / 3.5~3.8 | 3.3 / 4.5 |
| 전진 36개월만 | 4.0~4.8 | 1.5~1.6 / 2.0~2.2 | 1.9 / 2.6 |
| IW1 A + 현물 2017~19 | 4.5~5.4 | 1.4~1.5 / 1.9~2.1 | 1.4 / 1.9 |
| IW1 A + 현물 + 전진 12개월 | 5.9~7.0 | **1.2~1.3 / 1.7~1.8** | 1.3 / 1.7 |
| IW1 A + 현물 + 전진 36개월 | 8.5~10.2 | **1.0~1.1 / 1.4~1.5** | 1.1 / 1.5 |
- 읽는 법: 자료를 다 더해도(전진 1년 포함) 방향성 후보는 **연 샤프 1.2~1.3이 K=1에서 간신히 잡히는 수준**이고, 시도가 10개 가설이면 1.7~1.8이다. 0.5짜리는 어떤 조합으로도 못 잡는다(M 25~47 필요, 방향성으로는 불가능). **새 자료가 늘려주는 것은 "연 샤프 2.5~2.8 이상만 보이던 구간"을 "1.2~1.8 이상"까지 끌어내리는 정도**다.
- 방향성은 종목을 아무리 늘려도 N_eff 1.72에서 막히므로 **시간(기간)만이 지렛대**다. 횡단면 잔차는 종목 폭도 지렛대지만, 필요한 비용 가정이 얇은 코인에서 무너져 있다(ADR 0035/0047/0056).
- 시간에 걸친 샤프 일정 가정(레짐이 다르면 s가 달라짐)과 비용 무시는 모든 행에 숨어 있다. 이 표는 **상한**이다.

## 5. 이번에 받은 현물 2017-08~2019-12가 줄 수 있는 것과 없는 것
- 받은 것: 31종, 521개 월 파일, 1,464,046봉(15분). 게시 SHA-256 전부 일치. 15분 간격 빠짐 284건(거의 월 1건 = 거래소 점검, 채우지 않음, 엔진 규칙과 동일), 중복 0. 종목별 상장 월은 `_dq_pre2020_spot.jsonl`(zip 안). 종목: ADA BAT BNB BTC BTT CELR DASH EOS ETC ETH FET HOT ICX IOST IOTA LINK LTC NEO NULS ONG ONT QTUM TRX VET WAVES XLM XMR XRP ZEC ZIL ZRX. 스테이블·상폐·분기 코인 제외. 월별 종목 수는 2017-08~2018-04 사이 2~7개, 2018-05 11개, 2018-06~12 15~17개, 2019-03 이후 31개.
- 장점: ① 시간적으로 완전히 새 시기(2018 폭락, 2019 횡보·회복)로 레짐이 달라 "한 시기에만 되는 전략"을 가려낸다. ② 이 아카이브는 2021-01-01 이전을 읽지 못하게 막혀 있다(`runner.READ_START`) → 별도 조치 없이도 DEV 도구가 실수로 읽지 않는다. ③ 사람이 2018년 폭락을 알고 있다는 점은 오염 가능성이지만, 파이프라인이 본 적은 없다.
- 한계(중요):
  1. **현물이라 숏 불가**: 롱·현금 전략만 시험된다. 숏 후보(ADR 0028)는 시험 못 한다.
  2. **비용 자료가 없다**: 2018~2019 호가 자료는 없고 수집도 불가능하다. 현물 테이커 수수료 10bp(BNB 할인 7.5bp)가 USD-M 5bp의 약 2배이고 당시 책은 더 얇았다. 따라서 이 구간의 비용은 **가정(ASSUMED)**만 가능하며 ADR 0009에 따라 비용 검증 전에는 잠금 TEST·승격 근거로 못 쓴다. 연구용 증거(사전등록된 가설의 부호·크기 확인)로만 쓴다.
  3. **펀딩·기초 수익이 없다**(현물). 펀딩이 핵심인 가설(ADR 0020 CC1 등)은 못 시험한다.
  4. 이 세션 네트워크는 바이낸스 S3 미러(`data.binance.vision`)만 열려 있어 다른 거래소·다른 자산군 자료는 받지 못했다. 표의 "다른 자산군·다른 거래소" 행의 가용성은 **지식 기반이며 확인하지 않았다**.
- 보관 방식: 프로젝트 파일 `data/pre2020_spot_binance_15m_UNREAD.zip`. 파일명의 UNREAD가 상태다. 이 구간을 처음 읽는 사람은 ADR로 "개봉"을 기록해야 한다(IW1의 history 행과 같은 규칙을 쓰자는 제안이며, 코드는 아직 없음).

## 6. 우선순위 제안 (비용 대비 얻는 M, 위험)
1. **전진 창을 짧게 끊지 않고 길게 두기**(v2 12개월 → v3 e-값이 36개월까지 누적). 같은 거래소·같은 비용이라 가장 믿을 수 있고 1년에 M +1.3~1.6. 이미 12-01 시작으로 결정됨. 추가 작업 없음.
2. **현물 2017-08~2019-12를 두 번째 봉인 확인 구간(가칭 IW0)으로 지정**(받음). M +3.2~3.9로 IW1의 2.5배. 조건: 롱·현금 후보만, 가정 비용, 사전등록(후보·비용·종목·판정을 읽기 전에 고정)을 먼저 쓰고 1회만 연다. 제안만 하며 이 ADR은 지정하지 않는다.
3. **IW1(2020)은 계속 닫아 둔다.** 이유: 6종(A)의 M은 1.3~1.5라 샤프 2.6~2.8 이하는 잡지 못한다(ADR 0017의 검정력 15~52%와 일치). 지금 DEV 후보 중 기대 샤프가 이만한 것이 없다(ADR 0055: 비용 후 S1 최고 약 1.0). 열면 알파와 단회 기회만 소비한다.
4. 같은 시기 새 종목은 "종목 밖 점검" DEV로만(새 증거 아님, 비용 문제).
5. 다른 자산군·거래소 일봉은 동동 PC에서 받을 수 있는지 확인한 뒤, **크립토 후보의 보편성 점검**이라는 별도 가설로 사전등록. 이 세션에서는 받지 못함.
6. 쪼개 붙이기·합성은 더하지 않는다(M 0).

## 7. IW1을 열어야 하는 경우의 근거와 위험 (사용자 최종 확인 요청)
- 열 근거가 생기는 조건: 기대 연 샤프 ≳ 2.8(방향성)인 DEV 후보가 생기고, 비용이 측정 이상으로 확인되었을 때. 현재는 없다.
- 위험: ① 단회 사용·알파 소비(ADR 0016). ② 6종 M 1.3~1.5로 검정력이 낮아 "못 잡음"이 "없음"을 뜻하지 않는다. ③ 2020은 코로나 급락·디파이 상승 같은 특수 시기로 비용(호가) 자료가 없다. ④ 한 번 열면 되돌릴 수 없다.
- **요청: 지금은 IW1을 열지 않는 것으로 두고, 열자는 결정은 사용자의 별도 최종 확인을 받는다.** (이번 작업은 IW1·잠금·검증·종이 구간을 읽지 않았다.)

## 8. 결정 대기 (효력 없음)
- (a) 현물 2017~19를 IW0 봉인 구간으로 지정하고 사전등록 초안을 쓸지.
- (b) 동동 PC에서 다른 자산군·거래소 일봉을 받아 보편성 점검 가설을 만들지.
- 둘 다 하지 않아도 현재 계획(전진 12개월→36개월)은 그대로 간다.
