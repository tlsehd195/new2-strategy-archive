# ADR 0025 — 매 블록 e-값 누적 검증: 합성 시뮬레이션과 사전등록 v3 초안 (효력 없음)

- 상태: Proposed (초안, 효력 없음. V1은 2026-10-22에 결정·확정(7:3), V2~V4는 열림)
- 날짜: 2026-10-22
- 범위: `run/evalue_walkforward_sim.py`(신규, 합성 전용; 알파 분할 비교 `--parts split` 포함), `run/test_evalue_walkforward.py`(신규), `run/audit/evidence_evalue_v3_20261022/`(신규: 결과, README, v3 초안). 엔진, 통계 기준, 비용 기준 변경 없음. v2 초안은 알파 분할(V1 결정)만 반영: 0.0304 → 0.0213(합계 알파는 그대로). 시장 데이터·검증·잠금 구간·IW1을 읽지 않았다.
- 선행: [ADR 0023](0023-forward-window-prereg-v2-draft.md)(v2 초안), [ADR 0022](0022-false-negative-power-audit.md), [ADR 0021](0021-dev-bundle-stable-small-profit.md). 논문 정리: 프로젝트 파일 `papers/fill_gaps_round2_20261022.md`, `papers/reuse_of_spent_windows_20261022.md`
- 사용자 요청: 동동, 2026-10-22 ("ㅇㅇ": 시뮬레이션으로 오류율 확인 → 사전분포 과대 추정 검정력 → v3 초안)

## 맥락
v2는 12개월 뒤 한 번만 판정한다. 논문 조사(Waudby-Smith–Ramdas 2010.09686, Wang–Ramdas 2310.03722, Safe Testing 1906.07801)에서 "블록마다 e-값을 곱해 누적하면 언제 멈춰도 오류율이 유지된다"는 설계가 나왔지만, 변동성 군집·두꺼운 꼬리가 있는 손익에서 실제로 그런지, 소진 구간 효과 크기를 사전분포로 쓰면 어떤지는 논문에서 확인하지 못했다. 그래서 직접 시뮬레이션했다.

## 결정
1. 가설: "엔진이 직전까지 데이터로 고른 전략이 다음 블록에서 비용 후 이긴다". 귀무: 과거 조건부 블록 순손익 평균 ≤ 0.
2. 손실 하한은 **거래 규칙으로** 만든다: 블록 안 손절 L(1 sd) + 격리 증거금 바닥 B(2 sd). 손익을 나중에 잘라내는 방식은 금지(시뮬레이션에서 1종 오류 3~24%).
3. **갭 공제 c**(0.05 sd = 블록 자본 0.27%)를 매 블록 빼고 베팅한다. 증거금 바닥은 바닥 아래 갭 손실을 없애 주므로 무능한 전략도 평균이 약간 양수가 되기 때문이다(측정: 블록당 최대 +0.066%). c 없이 120블록 1종 오류는 0.6~1.35%였고 기간이 길어지면 계속 오른다.
4. 베팅은 사전분포 없는 plug-in(λ ≤ 0.75). 소진 구간 효과 크기는 쓰지 않는다.
5. α = 0.0304(IW1·v2와 동일). 느슨하게 하지 않았다.

## 결과 (`run/audit/evidence_evalue_v3_20261022/README.md`)
- **1종 오류**: 정규, GARCH t4, GJR 왼쪽 치우친 t4/t3, 변동성 국면, AR 수준 자기상관 7개 과정, 2만 경로·120블록(10년)에서 최대 0.83%(가장 공격적인 고정 베팅), plug-in 최대 0.21%. 목표 3.04% 이하.
- **검정력(plug-in, GARCH t4)**: 연 샤프 2 → 24블록 28%, 36블록 62%, 중앙 31블록. 샤프 3 → 76%/95%, 중앙 19. 샤프 4 → 94%, 중앙 14. 샤프 1 → 60블록 21%.
- **사전분포 과대 추정**: 귀무에서는 영향 없음(≤0.12%). 대립에서는 베팅 상한 덕분에 3배까지 손실이 작지만 5배에서 샤프 3의 24블록 검정력 89% → 41%. DEV의 과대 정도는 약 3~5배(ADR 0021)라 plug-in이 안전하다.
- **선택 과정 포함 장난감 엔진**: 마팅게일 자산에서 기각 ≤ 0.025%. 예측 가능한 자산(AR 0.2)에서도 고른 전략의 블록 샤프는 1.4에 그쳐 60블록 기각 57%.
- **널 생성법**: 부호 뒤집기 3.8~5.9%(수준 5%), 블록 부호 뒤집기 4.5~4.8%(검정력 거의 없음), 정상 블록 부트스트랩 0.2~0.4%(과보수, 원인 미확정), iid 부트스트랩 3.7~6.0%. 의존성을 모두 보존하면서 정확히 교환가능한 생성법은 **찾지 못했다**. v3는 널 생성이 필요 없는 e-과정을 주 검정으로 쓴다.

## v2와 비교 (판단)
- v2(12개월 1회): 80% 검정력에 연 샤프 2.2~2.7 필요(ADR 0023, 정규 근사).
- v3: 같은 12블록에서는 샤프 4도 25%로 v2보다 약하다. 대신 끝이 없어서 24~36블록이면 샤프 3을 76~95%로 잡고, 중간에 봐도 오류율이 깨지지 않고, 후보가 바뀌어도 가설이 하나다.
- 결론: **오류율은 지킨다. 권할 수 있다.** 다만 빠른 판정 도구가 아니라 "길게 쌓는" 도구다. 샤프 2 이하는 2~3년이 걸린다.

## V1 결정: 알파 분할 (동동, 2026-10-22 "2번으로 해")
- v2와 v3가 같은 전진 데이터(2026-11~)를 쓰고, 전진 창 가족 알파 0.0304를 **Bonferroni로 나눈다**. 합이 0.0304이므로 두 검정의 상관과 무관하게 가족 전체 오류율이 지켜진다.
- 비율은 시뮬레이션(`split_results.json`, README 6절)으로 비교했다. 두 검정이 같은 엣지를 번다고 두면 "둘 중 하나가 36개월 안에 기각"은 비율과 거의 무관하고(샤프 2: 67~68%), 비율은 증거가 나오는 시점을 바꾼다.
- **권장 7:3: v2 0.0213, v3 0.0091**(v3 기각선 E ≥ 약 110). 분할 전보다 v2의 12개월 검정력이 샤프 2에서 67.5% → 62.6%, 샤프 3에서 90.0% → 88.0%로 조금 줄고, v3는 36개월에 샤프 3을 87.7%, 샤프 2를 36.6% 잡는다. 동결 후보가 시간이 지나며 약해진다고 보면(ADR 0021) 5:5가 낫다(v2 샤프 2: 57.9%, v3 36개월: 47.5%).
- 두 초안에 반영했다(v2 `test.alpha` 0.0304 → 0.0213, `alpha_split` 추가; v3 `alpha` 0.0091). 둘 다 여전히 **효력 없음**. **비율 7:3은 동동 님이 2026-10-22에 확정**했다("추천으로 해").

## 한계
- 합성 과정이다. 실제 엔진의 블록 손익 분포와 다르다.
- 갭 공제는 시뮬레이션한 꼬리에서만 충분하다. 바닥이 깨지는 사건(자동 디레버리징, 거래소 장애)은 VOID 처리로 정했다. 이것은 증명된 보장이 아니라 규칙이다.
- 블록 길이 30일 하나, 전략 변동성 1% 하나만 봤다.
