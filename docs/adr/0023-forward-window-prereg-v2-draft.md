# ADR 0023 — 사전등록 v2 초안: 12개월 전진 창, 종목 바구니 평균 검정, 후보 5개

- 상태: Proposed (초안, 효력 없음. D1~D5 모두 결정됨)
- 날짜: 2026-10-21
- 범위: `run/audit/evidence_prereg_v2_20261021/forward_window_v2_DRAFT.json`만. 코드·설정·통계 기준 변경 없음. 구간을 열거나 데이터를 읽지 않았다.
- 선행: [ADR 0022](0022-false-negative-power-audit.md), ADR 0016/0017(IW1)
- 사용자 요청: 동동, 2026-10-21 ("ㅇㅇ": v2 초안 만들기)

## 맥락
ADR 0022 결론: 진짜 좋은 전략을 놓치는 이유는 검증 증거가 적어서다. 기준을 풀지 않고 증거를 늘리는 설계를 사전등록 초안으로 만들었다.

## 초안의 핵심
- **전진 창 12개월**(2026-11-01~2027-10-31). 데이터가 아직 없으므로 누구도 본 적이 없다. 끝난 뒤 한 번만 평가하고 중간에 보지 않는다.
- **종목 15개 바구니**(BTC, ETH + 시총 순 13개)의 평균 수익을 한 번에 검정한다. "종목마다 각각 통과" 대신 "바구니 전체에서 평균 > 0"이라는 주장이다.
- **후보 5개**, 사전에 DEV 연 샤프 1.0 이상인 것만 동결.
- **통계 기준은 같거나 더 엄격**: 단측 StepM, α=0.0304(IW1과 동일), 최소 거래 60건, 부트스트랩은 1,000 → 10,000회(ADR 0022 부수 발견 반영).

## 필요한 연 샤프(80% 검정력, 정규 근사, 종목 간 상관 0.6 기준 현실적인 행)
| 설계 | 필요한 연 샤프 |
|---|---|
| 지금 BTC/ETH 6개월 | 6.9~8.0 |
| IW1 묶음 A | 2.8~4.0 |
| **v2, 12개월** | **2.2~2.7** (상관 0.3이면 1.6~2.0) |
| v2, 24개월 | 1.5~1.9 (상관 0.3이면 1.1~1.4) |

연 샤프 1.5 전략의 통과 확률: 12개월 27~51%, 24개월 57~79%(상관 0.6).

## 한계
- 결과는 2027-11에야 나온다. 이 사이에 후보를 바꿔 같은 창을 쓰면 안 된다.
- 바구니 평균은 시장 상승 노출(베타)로도 통과한다. 초안은 베타를 보고서에 요구하고, 헤지 후 평균을 두 번째 관문으로 둘지는 D4로 남겼다.
- 종목 간 상관이 높으면 합치는 이득이 작다. 상관 0.6 행이 현실적이다.
- 연 샤프 1.5 이하는 여전히 검증하기 어렵다.

## 결정 (동동, 2026-10-21)
- **D3 = 예**: 후보 5개를 **묶음 하나(가설 하나)**로 검정한다(K=1). 묶음은 DEV에서 고른 것이라 선택이 한 단계 더 있다는 점을 보고서에 적는다.
- **D4 = 예**: 시장 상승분(15종목 단순 보유에 대한 베타)을 뺀 묶음 수익도 같은 α에서 기각돼야 한다. 두 검정을 모두 통과해야 하므로(교집합 검정) α를 쪼개지 않아도 크기가 α 이하다. 대신 검정력은 둘 중 약한 쪽을 넘지 못한다.
- **D1 = 12개월**(2026-11-01~2027-10-31, 결과는 빨라야 2027-11). 늘리지 않고 필요하면 같은 가족의 두 번째 창(알파 k=2)을 따로 등록한다.
- **D2 = 측정값이 나오면 교체.** 단 결과를 보고 고르는 것을 막기 위해 **동결일(10-31) 전에 봉인된 추정만** 쓴다. 그러면 종목 규칙, 후보 선택, 평가를 모두 그 비용으로 처음부터 다시 한다. 동결일 뒤에 나오면 이 창은 가정 비용을 그대로 쓰고 측정값은 참고로만 보고한다.
- **D5 = 후보 동결일 2026-10-31.** 그날 DEV 전용 evolve 실행으로 5개를 고정한다. 진입 조건(DEV 연 샤프 1.0 이상)을 넘는 후보가 5개 미만이면 창을 등록하지 않고 아무것도 쓰지 않는다.
- 남은 열린 결정 없음. 효력은 동결일에 후보 파일이 고정되고, 사용자가 마지막으로 확인한 뒤 이 파일이 sha256과 함께 커밋될 때 생긴다.

## 신뢰도 표시
묶음과 종목 선택은 알트 비용 **가정**(`assumed_public_v1`) 위에서 정했다. 알트 호가를 측정하지 못했다. 측정이 봉인되면(D2) 종목과 후보를 다시 고른다. 이 초안은 아직 효력이 없다.

## 갱신 (2026-10-22)
- 동동 결정으로 같은 전진 데이터를 쓰는 v3(매 블록 e-값, [ADR 0025](0025-walkforward-evalue-prereg-v3-draft.md))와 가족 알파 0.0304를 Bonferroni 7:3으로 나눈다. v2 초안의 α는 **0.0213**(두 관문 모두). 위 검정력 표는 α 0.0304 기준이라 조금 낙관적이다. 여전히 효력 없음.
