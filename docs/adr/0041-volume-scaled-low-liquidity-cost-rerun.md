# ADR 0041 — 저유동 코인용 거래량 비례 비용 보정, 알트 4개 가설 DEV 재실행

- 상태: Accepted (측정만, 기준 변경 없음)
- 날짜: 2026-10-27
- 범위: 보정 도구 `run/lowliq_cost_calibration.py`(신규), 보정 기록 `run/audit/lowliq_cost_20261027/calibration_v1.json`, 사전 고정 `prereg_lowliq_cost_v1.json`(재실행 전에 커밋·푸시), 결과 `broad_universe_lowliq.json`. `run/broad_universe_dev.py`에 `--cost-calibration` 옵션만 추가(기본 동작 그대로), 테스트 1개, 시도 기록 1줄.
- 선행: [ADR 0035](0035-broad-universe-cross-sectional-dev.md), [ADR 0038](0038-measured-alt-cost-estimate-and-reruns.md)
- 열지 않은 것: 사전등록 활성화, 검증·잠금·IW1·종이 구간. 수집기는 클라우드에서 돌리지 않았고 호가 파일만 읽었다.

- 번호 메모: 작업 중 0039·0040이 다른 PR로 먼저 병합돼 0041로 옮겼다. 코드 주석, `prereg_lowliq_cost_v1.json`, 커밋 메시지의 "ADR 0039"는 이 문서를 가리킨다(해시 보존을 위해 고치지 않았다).

## 왜
ADR 0038의 측정 비용은 유동성 큰 알트 7개 중 가장 비싼 값 하나를 모든 코인에 쓴다. 상위 50개 중 거래량이 작은 코인에는 낙관적일 수 있어, 거래량에 따라 비용이 오르도록 보정해 다시 돌렸다.

## 보정 방식 (결과 보기 전에 고정)
- 입력: 호가 10종목(SOL XRP DOGE BNB ADA AVAX LINK SUI LTC DOT) 96시간, 기준 v3 그대로. 종목별 반스프레드 모수(스프레드 90분위+지연)와 충격계수, 15분봉 거래대금 중앙값 q.
- 형태: ln(반스프레드)와 ln(충격계수)를 ln q에 대한 직선으로 최소제곱 적합. 절편은 10종목을 모두 덮도록 가장 큰 양의 잔차만큼 올림(상한선). 기울기가 양이면 거부.
- 적용: 리밸런싱 때 각 코인의 q = 직전 30일 평균 일 거래대금 / 96. 한쪽 비용 = 수수료 5bp + 반스프레드(q) + 충격계수(q)·√(1만 / 23:45 봉 거래대금). q는 [1만, 822만 USDT]로 자름(그보다 얇은 곳으로 더 외삽하지 않고, 가장 두꺼운 표본 이상은 더 싸게 치지 않음).
- 결과: 반스프레드 기울기 −0.19, 충격계수 기울기 −0.46. q 1만 → 16.7bp / 0.0175, 20만 → 9.6bp / 0.0044, 100만 → 7.1bp / 0.0021, 822만 → 4.8bp / 0.0008. 직선 형태를 고르려고 종목별 표(호가 자료)는 봤지만 전략 결과는 이 비용으로 계산한 적 없다. 판정 기준은 ADR 0035 그대로.

## 한계
- 비용이 절대 거래대금에만 의존하고 2021~2025년과 2026년 10월 사이에 그 관계가 같다고 가정했다(과거 시장 구조 차이는 반영 못 함).
- 측정 코인은 유동성 큰 10개뿐이라 410k 미만은 전부 외삽이다. 10개 점의 적합(상관 −0.47, −0.85)이라 오차가 크고, 상한 절편으로 보수적으로 잡았다.
- 호가는 체결이 아니다(ESTIMATED_FROM_PUBLIC_DATA, VERIFIED 아님). 4일 구간이다.
- 아카이브 다운로드 일부가 끊겨 재시도했고 비용 0 행이 ADR 0035와 같아 자료는 같다.
