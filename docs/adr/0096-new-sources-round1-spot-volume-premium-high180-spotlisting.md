# ADR 0096 — 새 정보원 반복 탐색 1라운드: 180일 고점 근접도, 무기한/현물 거래대금 비율, 프리미엄 지수 변화, 현물 상장 이벤트

- 상태: Accepted (측정만, 기준 변경 없음)
- 날짜: 2026-11-20
- 사용자 요청: 동동, 2026-11-20 "기준을 통과하는 전략이 나올때까지 계속 돌려 멈추지 말고". 이 ADR은 그 반복 탐색의 1라운드다. 통과 기준(DSR·PBO·비용·S1/S2 조건)은 낮추지 않는다.
- 범위: 사전등록 `run/audit/evidence_newsrc_r1_20261120/prereg_newsrc_r1_v1.json`(현물·프리미엄 파일을 받기 전에 커밋 `bb7f3f1`), 도구 `run/newsrc_r1_dev.py`(ADR 0047/0094 유니버스·비용·비중 흐름 재사용), 테스트 `run/test_newsrc_r1.py`(5개), 결과 `newsrc_r1_dev.json`, 시도 기록 1줄(7건, 문맥 `U50W200-14d-newsrc-r1-v1`).

## 1. 새로 본 것 (이전 ADR과 겹치지 않음)
- **현물 시장 자료를 처음 사용**: 바이낸스 현물 1일봉(S3 미러)으로 무기한/현물 거래대금 비율(레버리지 주도 vs 현물 주도)의 수준(V1)과 변화(V2).
- **프리미엄 지수 변화**(B1, 베이시스 모멘텀): 지금까지는 펀딩 수준(캐리)과 베이시스 수확만 시험했다.
- **180일 고점 근접도**(P1, 앵커링): 횡단면 모멘텀(28일)·MAX와 다른 가격 구조.
- **이벤트: 무기한이 먼저 상장된 코인의 현물 상장 후 숏**(E1): ADR 0060은 무기한 상장 자체였다.

## 2. 사전에 고정한 것
- 유니버스 ADR 0047과 같음(U50, W200), 횡단면 5건은 **14일마다** 5분위 롱숏, 신호 i−2일, 거래 i일 시가, 실제 펀딩, ADR 0041 보정 비용.
- 이벤트 2건: 현물 첫 거래일 L, 무기한이 L 전 30봉 이상·30일 평균 거래대금 200만 이상, L+1 시가 숏(자본 −10%), 7일/28일 뒤 청산. S1 이벤트 20건 미만이면 INSUFFICIENT_EVENTS.
- 판정은 ADR 0094와 같다: S1 샤프 > 실력 없는 7건 중 최고 기대값, 알파 t ≥ 2, S1 두 절반 > 0, S2 > 0.5, 비용 ×2·얇은 종목 ×2에서 S1 > 0.

- **7건 모두 NOT_PROMISING.** 우연 기대 최댓값(7건) P 0.93, 나머지 0.87; 누적 12,223건 기준은 2.45~2.63. 넘은 것이 없다.

- 현물 상장 이벤트: S1(2021~2023)에는 무기한이 먼저 상장된 코인이 사실상 없었다(현물 첫날 이전 무기한 봉이 있는 경우 1건, 1봉). 이 구조는 2024년 이후 생겼고 S2에 11건뿐이다. 28일 보유는 평균 +40%(숏 손실)로 상장 후 급등이 많았다.
- PBO(횡단면 5건, 2021-07-05~2023-09-17) 0.79: S1 앞에서 고른 것이 뒤에서 하위로 가는 경향이 강하다(과적합 신호).

## 4. 자료
- 현물 1일봉·프리미엄 1일봉 17,102개 파일(CHECKSUM 확인), 없음 5,609. 현물 상장 목록 490종목 중 400종목에 현물 USDT 쌍. 단위 접두사(1000, 1000000, 1M)는 떼고 매칭. 2025년 현물 아카이브의 마이크로초 시간은 밀리초로 변환.
- 현물 첫 거래일이 금지 구간에 있으면 그 이벤트는 버렸다(그 파일의 다른 값은 쓰지 않음).

## 5. 결정
- 승격·검증 후보 없음. 사전등록은 DRAFT_FOR_DEV_ONLY 그대로. 누적 DEV 시도 수 +7(PR #95 병합 후 12,216 → 12,223).
- **누적 보정 기록**: 누적 시도 수가 늘어 우연 기대 최댓값(누적 N, S1 2.2~2.6년)은 이번 라운드 2.45~2.63이다. 라운드마다 이 값이 조금씩 오른다.
- 변형(다른 룩백·보유·방향·유니버스)은 새 사전등록이 필요하다.
