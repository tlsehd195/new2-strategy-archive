# ADR 0085 — 잠금 TEST 캠페인 수·노출 기록을 상태 디렉터리 간에 공유한다 (L-1)

- 상태: Accepted
- 날짜: 2026-11-17
- 요청: 동동, 2026-11-17 "전부 추천으로" (ADR 0079 보고서 L-1 항목)
- 관련: ADR 0078/0079(F-11 잠금), `campaigns.py`, `engine_lib.LockTestRegistry`
- 번호: 열린 PR #84가 0084를 쓰고 있어 0085를 쓴다.

## 1. 문제

`locked_window_campaigns.jsonl`(창별 캠페인 수·알파 소비)과 `lock_test_usage.json`((전략, 심볼)별 노출 기록)이 모두 **상태 디렉터리 안**에 있었다. 디렉터리 A와 B가 같은 잠금 창에서 각자 캠페인 1(알파 전액 사용)을 가질 수 있었고, 같은 전략이 디렉터리마다 한 번씩 노출될 수 있었다. 잠금 구간은 저장소 수준의 데이터인데 사용 횟수는 디렉터리 수준이라, 새 디렉터리를 만들면 횟수가 0으로 돌아가는 구멍이다(검증 창에는 ADR 0013의 `validation_window_history.jsonl`이 이미 같은 목적으로 있다).

## 2. 재현 (수정 전)

`run/discovery/tests/test_shared_lock_state_20261117.py`를 먼저 작성해 수정 전 코드로 실행했다(공유 경로 함수만 빈 껍데기로 보강). 11개 중 7개 실패: 두 번째 디렉터리의 캠페인 색인이 2가 아닌 1, 창 소진(max=1)이 다른 디렉터리에서 안 보임, 동시 등록 4개가 같은 색인을 가짐, 다른 디렉터리에서 노출된 전략의 `reserve`가 허용됨, 예약 경합에서 두 번째 `start`가 막히지 않음, v1 기록 공유 불가.

## 3. 수정

공유 기록은 `shared_lock_dir()` 아래 추가 전용 파일이다. 기본 `run/discovery/locked_shared/`(검증 이력처럼 저장소에 커밋), `NEW2_LOCK_SHARED_DIR`로 바꿀 수 있다.

- **캠페인** (`locked_window_campaigns.jsonl` 공유 사본): 모든 기록(PREREGISTERED·ABORTED_NO_EXPOSURE·RESULT)을 공유 파일에 먼저, 로컬에 다음으로 덧붙인다. 창별 캠페인 수는 로컬+공유 합집합(동일 기록은 한 번)에서 센다. 등록은 로컬 락과 공유 락을 같은 순서(로컬→공유)로 잡고 그 안에서 읽고 결정한다. 등록 때 로컬에만 있던 기존 기록을 공유로 복사한다(`sync_shared`, 로컬 파일은 다시 쓰지 않음). 재개(`find`)·열린 캠페인은 로컬만 본다(다른 디렉터리의 캠페인을 이어받지 않음).
- **노출** (`lock_test_exposures.jsonl`): `start()`(실제 노출 순간)를 공유 락 아래에서 결정한다. 다른 디렉터리가 이미 노출했으면 `LockRegistryError`로 노출 전에 거부한다. `reserve`·`entry_status`·`uses`·`state`는 공유 기록의 다른 디렉터리 노출을 더한다(더 엄격한 쪽). 쓰기 전에 로컬 노출·v1 기록을 공유로 복사한다(락 순서는 항상 공유→로컬).
- 노출 안 된 시도(BLOCKED_DATA_MISSING, 노출 전 FAILED)와 노출 전 중단된 캠페인은 어디서도 세지 않는다(기존 규칙 그대로).

## 4. 호환·한계

- 기존 로컬 파일 형식·내용은 바꾸지 않는다(추가만). 로컬 기록이 없어도, 공유 파일이 없어도 동작한다.
- 다른 디렉터리의 이전 기록은 그 디렉터리가 한 번 쓰기 경로(`preregister`·`reserve`·`start`·`sync_shared`)를 거치기 전에는 공유에 없다. 이미 소진된 디렉터리가 있다면 그 상태 디렉터리에서 `sync_shared()`를 한 번 실행해야 한다.
- 같은 내용(같은 해시)의 캠페인 id가 두 디렉터리에 과거부터 있으면 하나로 세어진다(구별 수단이 없음).
- 단위 테스트는 `tests/test_00_isolate_shared_lock_dir.py`가 공유 경로를 임시 디렉터리로 돌려 저장소의 `locked_shared/`를 건드리지 않는다.
- 기준·임계값·알파 공식 불변. 실제 잠금 구간·prereg·IW 창을 열지 않았다.
