## 맥락
측정 비용으로 진입 기준 통과 후보가 33개 중 1개로 확정됐다(규칙상 5개 필요). 10-31에 사용자가 고를 선택지를 정리하고, 10-31이라는 날짜의 근거를 찾았다.

## 결과
- **10-31의 출처**: ADR 0023 D5(동동, 2026-10-21). 12개월 전진 창이 2026-11-01에 시작하므로(D1) 그 전날을 후보 동결일로 잡은 것으로 읽힌다. 이유를 직접 적은 문장은 저장소에서 찾지 못했다(위는 해석). 같은 날짜가 D2(동결일 전에 봉인된 비용 추정만 사용)에도 쓰였고 ADR 0029·0036·0037이 이어받았다. 규칙이 아니라 계획일이라 지나가도 위반은 아니다.
- **선택지**: A 보류(규칙대로 등록 안 함, 기본), B 규칙 변경(추천 안 함: 결과를 본 뒤 기준 조정, 후보 1개는 선택 편향이 큼, 기준을 0.9/0.87로 낮춰도 2/3개로 5개에 미달), C v3 e-값 전환(이미 합의된 경로, 첫 블록 2026-12-01). 추천은 A+C.
- C의 열린 일: V3 베팅 규칙, 엔진 커밋·설정 해시 고정, 12-01 전 sha256 커밋, v2 몫 알파(0.0213)를 v3로 돌릴지(결정 없음).
- 자세한 쉬운 설명: `run/audit/evidence_v2_options_20261027/10-31_선택지.md`.
