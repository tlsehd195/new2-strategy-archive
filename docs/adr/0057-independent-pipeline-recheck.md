# ADR 0057 — 파이프라인 독립 재검증: 계산 오류 때문에 후보가 떨어지는가?

- 상태: Accepted (점검만, 기준·엔진·비용 변경 없음)
- 날짜: 2026-11-02
- 사용자 질문: 동동, 2026-11-02 "이 정도면 너가 뭔가 잘못해서 안되는거 아니야?"
- 범위: 사전 기록 `run/audit/evidence_independent_check_20261102/prereg_independent_check.md`(결과 보기 전 커밋 `a397547`), 새 다운로더 `fetch_raw.py`, 새 계산 코드 `independent_engine.py`·`run_checks.py`, 결과 `independent_check_results.json`, 테스트 `run/test_independent_check.py`(합성 자료 4개).
- 열지 않은 것: 검증·잠금·IW1·종이 구간, 사전등록 활성화. DEV 구간(S1 2021-01-01~2023-09-18, S2 2024-06-19~2025-10-20, S2 BTC 제외) 밖의 행은 읽자마자 버림. 새 전략 시도가 아니므로 시도 기록에 더하지 않음.

## 한 일
1. 바이낸스 공개 아카이브(S3 미러)에서 USD-M 900종목 일봉 11,861개·펀딩 11,706개 월 파일을 새 다운로더로 다시 받음(CHECKSUM 확인).
2. 기존 `run/*_dev.py` 계산 코드를 보지 않고 ADR·사전등록 문장만으로 최소 엔진을 새로 짬(유니버스 선정, 신호, 롱숏 비중, 흘러가는 비중, 펀딩, 연 샤프). 비용은 0.
3. 같은 후보 4개의 비용 0 연 샤프를 기존 결과와 대조, 답이 정해진 점검(보유 수익 계산, 미래정보 오라클, 누설, 부호 반전, 무작위 신호 200회), 신호 지연 ±1봉, 문헌 모멘텀 재현, 자료 품질 점검.

- 다른 사람이 처음부터 다시 짜도 같은 숫자가 나온다. 후보가 떨어지는 이유는 계산 실수가 아니다.

## 결과 2: 답이 정해진 점검
- 보유 수익 계산: BTC·ETH 일별 수익을 곱하면 가격 비율과 오차 1e-15 이하로 같음.
- 미래정보 오라클(다음 보유기간 수익으로 고르기): S1 연 샤프 7.7~20.6. 정렬이 맞음.
- 누설 점검: 모멘텀을 진입 당일 종가까지 쓰게 하면 0.41 → 2.50으로 뜀. 지금 엔진은 그 정보를 쓰지 않음.
- 부호 반전: 펀딩 제외 수익이 정확히 반대(오차 2e-17).
- 무작위 신호 200회(같은 유니버스·비중): 평균 −0.09~0.02, 표준편차 0.53~0.64(이론 √(365/924)≈0.63). H1·N4·A101은 무작위 중 상위 10~14%(1 표준편차 남짓), R4는 상위 0.5%. 단, 누적 1만 건 이상 시도 중의 최고값이라 이것만으로는 의미 없음(ADR 0048·0055).

## 결과 3: 문헌 단순 전략 (비용 0)
- 횡단면 모멘텀(Liu–Tsyvinski–Wu 2022) 7·14·21·28일, U50 주간: S1 0.18 / 0.29 / 0.42 / 0.41, S2 1.88 / 1.54 / 0.78 / 1.37. 4개 모두 양수 → 사전 기준 "문헌 방향과 일치".
- 시계열 모멘텀 28일(Moskowitz–Ooi–Pedersen 2012; Liu–Tsyvinski 2021): BTC S1 0.63(같은 기간 보유 −0.01), ETH S1 0.63(보유 0.48), ETH S2 1.24. 사전 기준 "S1 > 0" 충족.
- 엔진은 알려진 효과를 제 방향으로 잡는다. 크기는 연 샤프 0.2~0.6(S1)로, 문헌의 강한 결과(소형 코인 포함, 2014~2018)보다 작다. 상위 50 선물·2021~2023에서는 원래 효과가 작다는 뜻이지 계산이 효과를 죽인다는 뜻이 아니다.

## 결과 5: 자료 품질 (DEV 구간, 606종목, 335,648 행)
- 중복 행 0, 00:00 UTC가 아닌 시각 0, OHLC 모순 0, 0 이하 가격 0.
- 하루 |수익| > 50%: 413건(대부분 소형 코인 급등, 예 ALPACA 2025-04-30 +520%, DOGE 2021-01-28 +390%). 실제 시장 움직임으로 보이며 오류 아님.
- 전일 종가와 당일 시가 차이 > 5%: 7건(무시할 수준).
- 아카이브 결측일 323 종목·일(예: 2022-02-26~28, 2022-04-01~02 여러 종목 공통, ICP 2022-09 26일). 보유 중 결측이면 그날과 다음 날 수익이 0으로 처리됨(기존·독립 엔진 공통). 무작위한 잡음이고 방향 편향은 없다.
- 거래량 0인데 가격이 있는 날 19,561: 상장폐지된 계약의 고정 가격 행(예: BTCST 1,409일). 30일 거래대금 순위 때문에 유니버스에 들어오지 않음.

## 찾은 오류
- **기존 파이프라인에서 결론을 바꾸는 오류는 없음.**
- 작은 관례 차이(영향 무시 가능, 수정 안 함): 기존 엔진은 첫 리밸런싱(2021-03-01)이 60봉 미달(58봉)로 건너뛰어져도 그 기간을 0 수익일로 S1 931일에 포함한다. 주간 가설 7일, 28일 가설 28일의 0이 들어가 연 샤프를 약 0.5~1.5% 낮춘다(예: 0.61 → 0.62 수준). 영향 ADR: 0035, 0038, 0040, 0041, 0047, 0051, 0054(모두 판정 불변).
- 이 점검 중 내 독립 코드에서 오류 1개를 찾아 고침: 구간을 이어 붙인 표에서 전일 종가가 2023-09-18 → 2024-06-19로 이어져 가짜 17배 수익이 생김(R4 S2에만 영향, 1.04 → 1.19). 기존 코드는 구간별로 따로 읽어서 이 문제가 없음을 코드로 확인함.

## 판단(쉬운 말)
- "계산이 틀려서 안 된다"는 아니다. 독립 구현이 기존 숫자를 ±0.04(R4만 0.13) 안에서 재현했고, 미래 정보를 넣으면 크게 뛰고, 부호를 바꾸면 정확히 뒤집히고, 문헌의 모멘텀 효과도 제 방향으로 나온다.
- 진짜 원인은 그대로다: 비용 전에도 엣지가 연 샤프 0.6 안팎이고, 2.5년 자료에서 무작위 신호의 표준편차가 0.6이라 우연과 구분이 안 된다. 거기에 비용(0.4~0.5)을 빼면 남는 것이 거의 없다.
