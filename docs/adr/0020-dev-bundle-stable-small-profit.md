# ADR 0020 — 후보 묶음으로 "작고 안정적인 수익"이 비용 후 남는지 DEV에서 확인

- 상태: Accepted
- 날짜: 2026-10-21
- 범위: `run/discovery/config/bundle_stable_v1.json`(신규, 사전 고정), `run/discovery/bundle_stable.py`(신규, 읽기 전용), `run/discovery/tests/test_bundle_stable.py`(신규), `run/audit/evidence_bundle_stable_20261021/`(신규). 엔진, 통계 기준, 비용 기준 변경 없음.
- 선행: [ADR 0018](0018-short-and-long-short-support-check.md)(`bundle_dev.py`, PR #17), ADR 0015(R6), ADR 0016(IW1)
- 사용자 요청: 동동, 2026-10-21 "2번 진행" — 큰 샤프를 노리지 말고 이미 있는 후보를 묶어 안정적인 작은 수익을 노린다.

## 맥락
- R6 DEV 통과 64개(롱 56, 숏 3, 양방향 5)는 하나씩 보면 약하다. 묶으면 서로 상쇄되어 흔들림이 줄 수 있다.
- 같은 DEV 날짜로 묶음을 고르면 숫자가 부풀려진다. 그래서 규칙을 먼저 고정하고, DEV를 앞/뒤 절반으로 나눠 한쪽에서 고른 묶음을 다른 쪽에서 채점했다.
- ADR 0018의 묶음 숫자는 거래마다 bp를 더한 값이라 자본 대비 수익률이 아니었다. 이번에는 전략 하나에 자본 1을 주고 종목 수로 나눠(한 종목에서 동시에 열린 포지션 최대 K개면 1/K) 어떤 묶음도 1배를 넘지 않게 했다.

## 결정
- 규칙은 `bundle_stable_v1.json`(sha256 `fda77643…`)에 결과를 보기 전에 커밋했다(`391b3f2`). 묶음 4가지, 채점 구성 6개:
  B1 전부 동일 비중, B2 방향별 1/3(롱·숏·양방향), B3 상관 군집(1−상관 0.5에서 자르고 군집마다 샤프 1위 하나), B4 변동성 역수 비중. B3/B4는 앞 절반으로 맞추고 뒤 절반에서 채점, 반대로도 한 번.
- 비용 두 가지: 주 비용 = R6과 같은 공개 호가 추정(estimate_v1), 스트레스 = IW1이 쓰는 `assumed_public_v1`(편도 10bp). 비용 전 수익도 같이 냈다.
- 시장 노출: BTC/ETH 50/50 보유와의 베타·상관, 베타를 뺀 수익.
- "DEV_STABLE" 표시(판정 아님): 해당 절반에서 주 비용 연 샤프 ≥ 0.5, 연수익 > 0, 최대 낙폭 ≤ 15%, 스트레스 비용 연수익 > 0, 베타 뺀 수익 > 0.

## 해석 (솔직하게)
- 묶으면 흔들림은 확실히 준다(뒤 절반 변동성 연 4~6%, 낙폭 10~13%). 그러나 **뒤 절반에서 비용 후 남는 수익은 연 2.5~4.3%로 얇고, IW1과 같은 가정 비용(편도 10bp)이면 모든 묶음이 손실이다.** 비용 전 수익 7~9% 중 절반 이상이 비용으로 나간다.
- 앞 절반으로 고르고 뒤 절반에서 채점한 3개 구성은 모두 NOT_STABLE이다. 반대 방향(뒤로 고르고 앞에서 채점)이 좋아 보이는 것은 64개 후보 자체가 앞 절반이 강한 구간을 포함한 DEV 전체로 뽑혔기 때문이다(구성원 선택 편향). 이 4줄은 증거로 쓰지 않는다.
- 결론: 지금 후보 묶음은 "작지만 안정적인 비용 후 수익"을 보여주지 못한다. 앞 절반의 좋은 숫자는 시간이 지나며 사라졌고, 남은 것은 비용에 민감한 얇은 수익이다.

## IW1에서 묶음을 검정할 수 있나
- 현재 v1 사전등록은 후보 20개를 각각 StepM으로 검정한다. 묶음 하나를 가설로 두는 검정은 없다. v1은 아직 열지 않았으므로, 열기 전이라면 v2로 바꿀 수 있다.
- 초안만 만들었다: `run/audit/evidence_bundle_stable_20261021/independent_window_v2_DRAFT.json`. 묶음 규칙을 미리 고정(B2, 대안 B1)하고 묶음 하나를 α 0.0304 전부로 검정하며, 2020년 상승장 때문에 베타 뺀 수익도 양수여야 통과한다. 엔진은 이 파일을 읽지 않는다. 채택과 IW1 개방은 사용자가 정한다.
- 검정력(정규 근사, 335일, α 0.0304): 연 샤프 0.8 → 13%, 1.5 → 33%, 2.0 → 52%, 3.0 → 84%. 위 뒤 절반 샤프(0.44~0.90)와 IW1 비용에서의 손실을 보면 **지금 열면 통과 가능성이 낮다. 열지 않는 것을 권한다.**

## 한계
- 청산일에 손익을 기록하고 보유 중 평가손은 반영하지 않는다. 실제 낙폭은 더 클 수 있다.
- 수익은 단순합(복리 아님)이다. 시장 50/50의 124% 낙폭도 단순합 기준이다.
- H2는 대부분 ETH 한 종목이다.
- 구성 6개와 표시 기준 하나를 미리 정했다. 이 결과를 보고 규칙을 바꾸면 그것은 새 선택이며 v2로 기록해야 한다.
- IW1, BTC/ETH 검증·잠금 구간은 열지 않았고 원장에 쓰지 않았다. 실주문·NEW2 연결 없음.
