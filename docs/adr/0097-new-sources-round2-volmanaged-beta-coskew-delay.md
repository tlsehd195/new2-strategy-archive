## 1. 새로 본 것
- 지금까지 위험 계열은 총변동성(LOWVOL30)·고유변동성(R3)·MAX뿐이었다. 이번에는 **시장 베타, 하방 베타, 공왜도, 가격 지연(시장 움직임을 늦게 반영하는 정도)** 순위와 **변동성 관리(최근 변동성에 반비례해 노출을 줄이는) 알트 지수**를 처음 계산했다.

## 2. 사전에 고정한 것
- 유니버스 ADR 0047과 같음, 14일 리밸런싱, 신호 i−2일, 거래 i일 시가, 실제 펀딩, ADR 0041 보정 비용. 룩백 90일(60일 이상 유효). 시장 = 현재 유니버스 동일 가중 평균.
- VM1: U50 동일 비중 롱, 총 노출 = min(2, 0.60 / 최근 30일 연환산 변동성). 나머지는 5분위 롱숏(BAB 낮은 베타 롱, DB 높은 하방 베타 롱, CSK 낮은 공왜도 롱, DLY 높은 지연 롱; DLY는 U50·W200).
- 판정 ADR 0094/0096과 같다. 평가 S1 2021-04-12~(2.44년), S2 2024-09-30~.
