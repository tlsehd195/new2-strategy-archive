# 사전등록: L3 실현변동 수준 → 방향 효과 (RV Tail Signal, Lee 2024 변형 시계열 검정)

고정 시각: 2026-10-12 (측정 스크립트 실행 전) · 작성: Z.ai Code (Task 17, 루프 사이클 5)
규칙: 본 문서 고정 후 규칙 변경 금지. 사후 파라미터 재조정은 사전등록 위반.

## 0. 중복 확인 (큐 지시 사항 — 선결제)

- 저장소 기존 게이트(인벤토리 65행 실측): `vol_gate_lo(0.5) ≤ 단기/장기 실현변동 비율 ≤ vol_gate_hi(2.0)`
  이탈 시 진입 차단 (side_indicators.py volatility_ratio, daytrade.py 윈도우 96/960 봉) — **비율 기반
  진입 차단기**로 방향 신호 아님.
- 본 후보는 Lee(2024) "실현분산 수준 자체가 미래 수익률을 음(-)으로 예측"의 **시계열 꼬리 검정** —
  RV 수준 극단의 방향 효과를 거래 규격으로 측정. 메커니즘·용도 상이(스케일링 제안이 아니라 방향 효과 실측) →
  비중복으로 판정하고 진행. 원본 ADR-0082 문서는 본 세션에 저장소 미클론으로 직접 열람 불가 —
  인벤토리 기록을 근거로 대체하며 이 한계를 명시.
- 시계열 변형의 정직성: Lee 효과는 크로스섹션 패널 주장이나 BTC/ETH 2자산 제약으로 시계열 꼬리 형태로
  변환 — 귀무(효과 없음) 하에서 양방향 중 하나만 우연히 유의할 수 있음을 사전 등록.

## 1. 가설

실현변동(RV)이 최근 L 봉 기준 극단적으로 높으면(z ≥ +1.2816) 미래 수익률이 낮다(음) → **숏**,
극단적으로 낮으면(z ≤ −1.2816) 미래 수익률이 높다(양) → **롱** (문헌 방향 그대로의 매핑 —
"고RV→저수익 추종"). 반대 통제(고RV→롱)는 충돌 가설(충격 후 반등)을 자동으로 검정.

## 2. 데이터

- 가격: `NEW2_run/data/klines/{SYM}-15m-*.csv` (로컬, 15m close) + qv(엔진 교차검증용)
- 측정 구간 (기존 관행과 동일 — 잠금 해제 구간만):
  - BTCUSDT: 2021-05-02~2022-08-17, 2023-04-07~2024-03-18
  - ETHUSDT: 2021-05-02~2022-08-17, 2024-12-10~2026-04-20

## 3. 신호 정의 (고정)

- r_t = ln(close_t / close_{t−1}) (15m 로그수익, 연속 봉만 — 갭 시 NaN)
- RV_t(L) = std(r_{t−L+1..t}, ddof=1), L ∈ {96, 288, 960, 2880} 봉 (1d/3d/10d/30d) — 4값 사전 고정
- z_t = (RV_t − mean(직전 960개 RV 관측)) / std(직전 960개 RV 관측) — 현재 제외(인과, shift 1),
  결측 RV는 관측에서 제외, std≤0 또는 NaN이면 신호 없음
- 버킷: **B80 단일, 양측** — z ≥ +1.2816 → **숏** / z ≤ −1.2816 → **롱** (문헌 방향 매핑 — C1과 부호
  반대 구조임을 명시)

## 4. 거래 규칙 (고정)

- 진입: 신호봉 t의 다음 봉(t+1) 시가 — 다음 봉 없으면 스킵(fail-closed)
- 청산: 진입봉 + h봉 후 시가, h ∈ {4, 16, 48}
- 보유 구간 내 kline 결측(갭) 있으면 드랍 + 카운트(fail-closed), 청산봉 구간 밖이면 드랍

## 5. 셀 구조와 통계 (고정)

- 셀 = (L, h) → 구성당 12셀 × 4구성(2심볼×2구간) = **패밀리 48셀**, Holm step-down (α=0.05)
- 수익률: 단일 거래 수익(부호 반영), 평균 → 총bp; 순12/순16/순20 = 평균 − 정액비용(12/16/20bp)
- t검정: (평균 − 16bp)/(sd/√valid_n), valid_n = n/h, 양측 p
- 통제: ①문헌 반대(각 거래 부호 반전 = 고RV→롱) ②무작위 100시드(seed=20261012)
- 유효표본 조건: valid_n ≥ 30

## 6. 판정 규칙 (고정)

- **PASS = Holm p<0.05 셀 ≥1 AND 해당 (L,h) 조합이 4구성 중 ≥3 양수(순16>0, valid_n≥30) AND 유효표본 충족**
- 통과 시 즉시 OOS: 각 구간 하위 40% 동일 규칙, 양수 세그먼트 ≥2/4 필요
- 전원 실패 시 폐기 권고 종결, 재파라미터링 없음

## 7. 비용 교차검증 (고정)

- 엔진 CandleCostModel (costs.py:104-117 공식), $10k/$100k, participation 5% 초과 fail-closed
- 엔진 비용 기준 Holm 재계산 — 본 검증이 최종 판정 우선

## 8. 패밀리 사전검증 (정보성)

- L3 RV z(L별) vs 펀딩 z, C1 베이시스 모멘텀 z 스피어만 — 변동성 신호가 캐리/베이시스 패밀리와
  독립인지 확인. |ρ|≥0.5면 패밀리 중복 기록(판정 규칙 변경 없음).
- 데이터 한계: L=2880은 워밍업(L+960봉=40일)으로 구간 초반 수일 신호 부재 — fail-closed 유지.
