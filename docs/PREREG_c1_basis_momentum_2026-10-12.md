# 사전등록: C1 베이시스 모멘텀 (Basis Momentum, Boons-Prado 2019)

고정 시각: 2026-10-12 (측정 스크립트 실행 전) · 작성: Z.ai Code (Task 13)
규칙: 본 문서 고정 후 규칙 변경 금지. 사후 파라미터 재조정은 사전등록 위반.

## 1. 가설

Boons-Prado (JF 2019) basis momentum: 선물 베이시스의 모멘텀이 지속된다 — 베이시스가 최근 L 기간 동안 상승했으면(퍼페가 인덱스 대비 강세) 앞으로도 상행 지속 → **롱**, 하락했으면 → **숏** (양측 추종).
X3 실측(붕괴 z≤−1.28 후 h4 추종 하락 유의, 되돌림 부정)은 본 가설의 하측 추종과 방향 호환 — 그러나 본 등록은 독자 규격이며 X3 결과에 맞춰 규칙을 조정하지 않음.

## 2. 데이터

- 프리미엄 인덱스 15m kline: `NEW2_run/data/premium/{BTCUSDT,ETHUSDT}-15m-*.csv` (65개월, 결측 0 — X3에서 재검증됨)
- 가격 실행: `NEW2_run/data/klines/{SYM}-15m-*.csv` 시가

  - ETHUSDT: 2021-05-02~2022-08-17, 2024-12-10~2026-04-20

## 3. 신호 정의 (고정)

- Δ_t(L) = basis_t − basis_{t−L} (basis = premiumIndexKlines close, 단위 %)
- z_t = (Δ_t − mean(직전 960개 Δ)) / std(직전 960개 Δ) — 현재 Δ 제외(인과, shift 1), std≤0 또는 NaN이면 신호 없음
- L(룩백) ∈ {16, 48, 96, 288} 봉 (4h, 12h, 24h, 72h) — 4값, 사전 고정
- 버킷: **B80 단일, 양측** — z ≥ +1.2816 → 롱 / z ≤ −1.2816 → 숏 (추종)

## 4. 거래 규칙 (고정)

- 진입: 신호봉 t의 다음 봉(t+1, t+900000ms) 시가 — 다음 봉 없으면 스킵(fail-closed)
- 청산: 진입봉 + h봉 후 시가, h ∈ {4, 16, 48}
- 보유 구간 내 kline 결측(갭) 있으면 드랍 + 카운트(fail-closed)
- 청산봉이 구간 밖이면 드랍

## 5. 셀 구조와 통계 (고정)

- 셀 = (L, h) → 구성당 12셀 × 4구성(2심볼×2구간) = **패밀리 48셀**, Holm step-down (α=0.05)
- 수익률: 단일 거래 수익 (롱/숏 부호 반영), 평균 → 총bp; 순12/순16/순20 = 평균 − 정액비용(12/16/20bp)
- t검정: (평균 − 16bp) / (sd/√valid_n), valid_n = n/h (중복 보정, P1·X3 관행 동일), 양측 p
- 통제: ①추종 반대(각 거래 부호 반전) ②무작위 100시드(부호 무작위, seed=20261012)
- 유효표본 조건: valid_n ≥ 30

## 6. 판정 규칙 (고정)

- **PASS = Holm p<0.05 셀 ≥1 AND 해당 (L,h) 조합이 4구성 중 ≥3 양수(순16>0, valid_n≥30) AND 유효표본 기준 충족**
- 통과 시 즉시 OOS: 각 구간 하위 40% 동일 규칙 적용, 양수 세그먼트 ≥2/4 필요
- 전원 실패 시 폐기 권고로 종결, 재파라미터링 없음

## 7. 비용 교차검증 (고정)

- 저장소 엔진 CandleCostModel (costs.py:104-117): fee 5bp + half_spread 2bp + 10%·√participation per side
- 시나리오: $10k / $100k, participation = 주문금액 / 바 거래대금(qv), 5% 초과 fail-closed
- 엔진 비용 기준 Holm 재계산 — 본 검증이 최종 판정 우선

## 8. 패밀리 사전검증 (정보성, 판정에 불가입)

- C1 z(L별) vs P1 펀딩 z 스피어만 상관 — 펀딩 프록시 여부 확인
- X3와의 구조 관계: 동일 변수(베이시스 변화 z)의 하측에서 방향 매핑 반대(추종 vs 되돌림) — 하측 트리거 집합은 L=16에서 X3 B80과 동일
