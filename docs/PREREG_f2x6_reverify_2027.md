## 0. 목적과 사전 고지 (정직성)

- 대상: Task 35에서 정확 재생산된 C-B 셀 — **ETHUSDT thr25/75 h288 양측** (v≤25 롱 + v≥75 숏),
  엔진 비용 차감 후 양수인 유일 관측(taker +36.19bp·maker promo +53.29bp, 체결률 1.000).
- **파워 사전 고지**: 현재 효과 크기(mean 53.29bp·std 597.6bp·valid_n 59)에서 본 재검증의
  통과 확률은 2027-01-11 시점 **~6.8%**(효과 절반 가정 ~3.1%) — 파워 분석(Task 36)으로 실측.
  재검증은 비용 0·자동 데이터 누적 하에서 실행 가치가 있으나 승격 기대치는 낮음을 사전 확정.
- PASS 시 의무: 효과 크기 재추정치를 기존 점추정과 함께 보고하고, 승자의 저주(상향 편의) 가능성을
  명시. 신규 이벤트만의 부분 통계를 결합 통계와 병기.

## 2. 통계 규약 (고정)

- **결합 표본 검정**: 기존 + 신규 전체 이벤트 풀, 이벤트당 수익률, t 양측
  valid_n = n/max(1, h/96) = n/3 (일간 규약 — 원기록·Task 35 교차검증과 동일)
- Arm: 1차 **maker promo δ0/K16 promotion-basis(N2 규격)**, 2차 taker 참고(판정 근거 아님)
- 패밀리: **m=2** — {F2/X6-R cell, X1-R Config R 통합 풀(4구성 union, 동일 규약)} → Holm
  step-down (α=0.05). 최소 p 셀은 α/2=0.025 기준.

## 3. 판정 시점 (고정 — 2회 한정)

- **1차: 2027-01-11** (P3 90일 수집 완료와 동시 — 운영 단일화)
- **최종: 2027-07-01**
- 중간 극단 스펠 종료 시: 신규 이벤트 기록·기술 통계만 산출(정보성) — **판정 아님**.
  판정 문구·승격 주장은 위 2회에서만 가능.

## 4. 판정 규칙 (고정)

- **G-R1 (유의성+경제성)**: Holm p<0.05 AND 엔진(CandleCostModel $10k) 차감 후 양수
- **G-R2 (일관성)**: 각 구간(원 s1·s2·신규) 하위 40% OOS 순16 양수 세그먼트 ≥ 2/3
- **G-R3 (통제)**: 무작위 100시드(seed=20261014) P(랜덤≥) < 0.05
- **G-R4 (신규 방향, 정보성)**: 신규 이벤트 n≥10일 때 신규 부분집합 평균 부호 일치
- **PASS = G-R1 ∧ G-R2 ∧ G-R3** — 통과 시 엔진 교차검증·OOS 전체 보고 후 승격 심사 상신.
- 전원 실패 시: 폐기 권고 유지, 재파라미터링 없음. 다음 판정은 2027-07-01뿐.

## 5. 변경 금지
