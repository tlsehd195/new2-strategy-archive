# PREREG — X8: 테이커 플로우 불균형 (집계 프록시) — 사전등록

작성일: 2026-10-13 · 측정 스크립트 실행 전 고정 · 규칙 변경 금지
패턴 준용: PREREG_c1_basis_momentum_2026-10-12.md (48셀·Holm·엔진 교차검증·OOS 60/40)

## 0. 배경과 범위 고지 (정직 선언)

- **감사 발굴 (5차)**: 큐 장부가 C2(오더플로우·호가 불균형)를 "bookDepth/aggTrades 아카이브 수백 GB + maker 전제 → N2 실행 계층 의존"으로 분류했으나, **로컬 Binance 15m kline 표준 12컬럼 중 9번 컬럼(taker buy base volume)이 존재** — 실행된 공격자(aggressor) 방향의 **집계 프록시**는 신규 다운로드 0바이트로 즉시 측정 가능함이 실측 확인됨 (klines/BTCUSDT-15m-2021-04.csv 1행 실측: vol=2589.573, tbv=1450.817).
- 본 측정은 **C2 전체 규격의 복원이 아니다**: 호가잔량(bookDepth)·틱 단위 aggTrades 기반 불균형은 여전히 N2 의존. 본 검증은 "집계 공격자 플로우 방향"이라는 **별개·독립 원리**의 측정이며, 신규 ID **X8**로 등록한다.
- 기존 18건 측정 중 tbv(테이커 매수량) 컬럼을 신호로 사용한 사례 **0건** — 비겹침 원리 (프리미엄/베이시스/펀딩/RV/FG/DVOL/스프레드/이벤트 전원과 정보원 상이).

## 1. 가설과 1차 방향 (방향 쇼핑 방지 — 사전 고정)

- **가설(문헌 방향)**: 공격자 매수 비중 극단은 단기 **추종(continuation)** 신호다. 근거: aggressor/order-flow imbalance → 같은 방향 단기 수익 편향 (시장 미시구조 문헌 일반 결론).
- **1차 방향 = 추종**: z ≥ +thr → 롱, z ≤ −thr → 숏 (양측).
- 되돌림은 **반대 통제(oppose)** 로만 보고 (X3·C1 선례 준용). 측정 후 통계 유의 방향에 맞춰 방향을 바꾸는 것을 금지.

## 2. 신호 정의 (사전 고정)

- 봉 단위 테이커 매수 비중: `s_t = tbv_t / vol_t` (vol=0 봉은 NaN → fail-closed 스킵).
- 윈도우 집계: `R_t(L) = Σ tbv (직전 L봉) / Σ vol (직전 L봉)`, L ∈ {16, 96} (4h, 24h).
- 인과 z: `z_t = (R_t − mean(R, 직전 960봉)) / std(R, 직전 960봉)` — **현재 봉 제외(shift 1)**, std≤0이면 NaN (C1의 NWIN=960 관례 동일).
- 임계: B80 = |z| ≥ 1.2816, B90 = |z| ≥ 1.6449.

## 3. 셀 구성 (48셀 패밀리)

- 2심볼(BTCUSDT, ETHUSDT) × 2스팬 × L{16,96} × B{80,90} × h{4,16,48} = **48셀**.
- 스팬 (잠금 해제 구간 — X3/C1과 동일, 끝 미포함):
  - BTCUSDT: 2021-05-02~2022-08-17, 2023-04-07~2024-03-18
  - ETHUSDT: 2021-05-02~2022-08-17, 2024-12-10~2026-04-20
- 잠금/예약 TEST 구간(BTC 2024-03-25~06-18, ETH 2026-04-28~08-31) 일절 미사용 — 스팬 자체가 잠금 밖.
- z 윈도우(960봉=10일)는 스팬 시작 전 데이터로 오염되지 않도록 스팬 내 첫 유효 z는 스팬 시작 960봉 이후부터 형성됨 → 초기 무신료 구간은 스팬 내 원 데이터로만 채움(스팬 밖 데이터 미사용 — 세그먼트 독립 보존).

## 4. 거래 규칙 (fail-closed)

- 신호봉 t 종가 확정 → **t+1 봉 시가 진입**, t+1+h 봉 시가 청산 (h ∈ {4,16,48}).
- 진입·청산 사이 15m 봉 갭 존재 시 해당 거래 **드랍(fail-closed)** — 유리하게 채우지 않음.
- 신호봉 직후 봉(t+1) 부재 시 스킵.

## 5. 통계 규격 (사전 고정)

- Holm step-down, 패밀리와이즈 α=0.05, **48셀 전체 한 패밀리**.
- t검정: 유효표본 = n/h (겹침 보정), 기준비용 정액 16bp 왕복(진단) — 엔진은 교차검증 단계.
- 통제: ①반대방향(oppose) ②무작위 100시드 (부호 무작위화 후 net16 초과 확률 p_ctrl).
- 승격판정 규칙 (큐 장부 사전 고정 그대로): Holm p<0.05 셀 존재 AND 동일 (L,B,h) 조합이 4개 심볼-스팬 중 **≥3 양수(valid_n≥30)** AND OOS 양수 세그먼트 ≥2/4.
- OOS: Holm 통과 시에만, 각 스팬 **하위 40%** 구간에 동일 규칙 적용 (60/40 규칙).
