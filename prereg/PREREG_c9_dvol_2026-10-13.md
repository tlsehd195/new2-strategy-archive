## 1. 가설

내재변동성(공포·스트레스 프록시) 수준이 최근 기간 대비 극단일 때 이후 수익은 **반등(역발상)**한다:
DVOL z ≥ +thr (고변동 극단) → 롱, DVOL z ≤ −thr (저변동 극단) → 숏.
- 1차 방향의 문헌 근거: Giot (2005) "Implied volatility markets and trading strategies" — 고 VIX 국면 이후
  주식 초과수익(역발상 롱 유리). 프로그램 내 패밀리 정합: F2/X6 센티먼트 극단 역발상과 동일 방향 매핑.
- 추종(모멘텀)은 반대 통제로 자동 검정되며, 1차 방향 부정 시 방향 쇼핑 없이 FAIL 종결.
- 귀무 하에서 양방향 중 하나만 우연히 유의할 수 있음을 사전 등록(전 셀 Holm 일괄 보정).

## 2. 데이터

- **DVOL**: `GET https://www.deribit.com/api/v2/public/get_volatility_index_data?currency={BTC,ETH}&start_timestamp=..&end_timestamp=..&resolution=1D`
  — 응답 data = [ts, open, high, low, close], ts = 해당 일자 00:00 UTC(bar 시작). 월간 청크 다운로드, 결측·중복 검사 후
  `data/dvol/c9_dvol_{BTC,ETH}_1d.csv` 저장, HTTP 실측 로그 `research/c9_dvol_download_log.json`.
- **실행 가격/거래대금**: 바이낸스 USDT-먼저선물 15m kline (기존 `data/klines/` — 2021-04~2026-04 + C3 백필, 선행 측정 17건과 동일).
- **측정 구간 규칙 (다운로드 전 고정 — 실측일은 다운로드 후 정직 기록)**:
  - 측정 종점: **2026-10-12 00:00 UTC** (당일 진행 중 봉 제외).
  - 구간 시작 = 각 심볼 DVOL 첫 유효 일자(다운로드 후 실측, 예상 BTC 2021-04, ETH 2021-10).
  - 잠금/예약 TEST 구간 일절 미사용: BTC 2024-03-25~06-18, ETH 2026-04-28~08-31 **완전 제외**(신호·수익·z 윈도우 어디에도 사용 금지).
  - 제외로 분단된 연속 세그먼트 중 길이 30일 이상만 측정 구간 → 예상 4구성: BTC s1(잠금 전)/s2(잠금 후), ETH s1/s2.
  - **z 윈도우 오염 방지(fail-closed)**: z 계산에 쓰이는 [t−L, t] 일자 중 잠금 구간 일자가 하나라도 있으면 그 일자 z=NaN.
    (잠금 직후 세그먼트는 L일 워밍업 손실 — 정직한 비용으로 수용. ETH s2는 42일로 L90 전체·L30 대부분 무효가 예상되는 저파워 세그먼트임을 사전 고지)

## 3. 신호 정의 (고정)

- dv_t = DVOL 일자 t 종가. 인과 z: **z_t = (dv_t − mean(dv_{t−L..t−1})) / std(dv_{t−L..t−1})** — 현재 값 제외, 과거 L일 윈도우만
  (C3 수준 z 규약의 일간 전치). std≤0 또는 윈도우 결측·잠금 오염 → z=NaN.
- L(룩백) ∈ {30, 90} 일 — 2값 사전 고정.
- 버킷: **B80 = |z| ≥ 1.2816, B90 = |z| ≥ 1.6449** (정규분위 관행값, C4 규약 준용) — 양측.
- 방향 매핑(1차, 사전 고정): z ≥ +thr → **롱**(고변동 극단 반등), z ≤ −thr → **숏**(저변동 극단 반락).

## 4. 거래 규칙 (고정)

- 인과 매핑: 일 D의 15m 신호봉은 **D−1 일자 DVOL 종가 z**를 사용. D−1 종가는 00:00 UTC(D) 경계에 확정되므로
  **일 D의 첫 봉(00:00)은 신호봉에서 제외**(진입 최소 지연 15분 보장 — F1 fail-closed 정신 준용). 신호봉 = 일 D의 00:15~23:45 봉(95개/일).
- 진입: 신호봉 t의 다음 봉(t+1) **퍼페 시가** — 다음 봉 없거나 구간 밖이면 스킵(fail-closed).
- 청산: 진입봉 + h봉 후 시가, **h ∈ {96, 288, 672}** (1일/3일/7일 — 일간 신호 전용 그리드, F2/X6/X5 규약 준용).
- 보유 구간 내 kline 결측(갭) 있으면 드랍 + 카운트(fail-closed). 청산봉 구간 밖이면 드랍.
- 신호는 연속 허용(C1 진입 규약 — dedup 없음), **유효표본 valid_n = n/h** (일간 신호 → 15m 실행 규약, Task 18 확립).

## 5. 셀 구조와 통계 (고정)

- 셀 = (L, 버킷, h) → 구성당 12셀 × 4구성(2심볼×2세그먼트) = **패밀리 48셀**, Holm step-down (α=0.05).
- 수익률: 단일 거래 수익(롱/숏 부호 반영), 평균 → 총bp; 순12/순16/순20 = 평균 − 정액비용(12/16/20bp).
- t검정: (평균 − 16bp) / (sd/√valid_n), 양측 p.
- 통제: ①추종 반대(각 거래 부호 반전 = 고변동→숏/저변동→롱) ②무작위 100시드(seed=20261013).
- 유효표본 조건: valid_n ≥ 30. 저파워 셀(특히 ETH s2)은 사전 고지대로 그대로 판정에 반영(규칙 변경 없음).

## 6. 판정 규칙 (고정)

- **PASS = Holm p<0.05 셀 ≥1 AND 해당 (L,버킷,h) 조합이 4구성 중 ≥3 양수(순16>0, valid_n≥30) AND 유효표본 기준 충족**
- 통과 시 즉시 OOS: 각 세그먼트 하위 40% 동일 규칙, 양수 세그먼트 ≥2/4 필요.
- 전원 실패 시 폐기 권고로 종결, 재파라미터링 없음. 이 경우 '방향 원리 고갈' 결론은 C9 포함으로 갱신된다.

## 7. 비용 교차검증 (고정)

- 저장소 엔진 CandleCostModel (costs.py:104-117): fee 5bp + half_spread 2bp + 10%·√participation per side.
- 시나리오: $10k / $100k, participation = 주문금액 / 퍼페 바 거래대금(qv), 5% 초과 fail-closed.
- 엔진 비용 기준 Holm 재계산 — 본 검증이 최종 판정 우선.
