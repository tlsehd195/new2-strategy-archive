# 사전등록: C5 분기선물 커브 슬로프 (Quarterly Futures Curve Slope / Calendar Spread)

고정 시각: 2026-10-12 (측정 스크립트 실행 전) · 작성: Z.ai Code (Task 15)
규칙: 본 문서 고정 후 규칙 변경 금지. 사후 파라미터 재조정은 사전등록 위반.

## 1. 가설

분기선물 기간구조(커브)의 변화가 방향 예측을 한다 — 근월-원월 캘린더 스프레드(스코프)가
최근 L 기간 동안 확대됐으면(원월 베이시스가 근월 대비 상대적 상승 = 캐리 커브 상승 = 포지셔닝 강세
기대) 상행 지속 → **롱**, 축소됐으면 → **숏** (양측 추종).
근거: web_research_round2 C5 (커브 슬로프 수준/변화가 방향 예측). C1(퍼페-인덱스 단일 베이시스
모멘텀)과 달리 본 후보는 **만기구조 차원** — 서로 다른 만기 계약 간 스프레드의 변화. 실행은
납품계약이 아니라 퍼페(분기물 유동성 낮음 — 연구 노트 사전 고정).

  - ETHUSDT: 2021-05-02~2022-08-17, 2024-12-10~2026-04-20

## 3. 신호 정의 (고정)

- near(t) = 납품일 ≥ t + 7×24h 를 만족하는 가장 이른 분기 계약 (납품 주간 왜곡 제외 — 사전 고정)
- far(t) = near 다음 분기 계약. near·far·스팟의 1h close가 모두 t에 존재해야 함(하나라도 결측이면
  신호 없음 — fail-closed)
- slope_t = (far_close(t) − near_close(t)) / spot_close(t)  — 양수 = 원월 우위(캐리 커브 상승)
- Δ_t(L) = slope_t − slope_{t−L} (1h 격자), L ∈ {24, 120, 480, 960} 시간 (1d/5d/20d/40d) — 4값 사전 고정
- z_t = (Δ_t − mean(직전 720개 Δ)) / std(직전 720개 Δ) — 현재 Δ 제외(인과, shift 1), std≤0 또는 NaN
  이면 신호 없음. z는 1h 격자에서 산출.
- 버킷: **B80 단일, 양측** — z ≥ +1.2816 → 롱 / z ≤ −1.2816 → 숏 (추종)

## 4. 거래 규칙 (고정)

- 진입: 신호 1h봉 t의 close(= t+1h 시점 확정) 직후, open_time == t+3600000 인 퍼페 15m봉 시가.
  해당 봉 없으면 스킵(fail-closed)
- 청산: 진입 15m봉 + h봉 후 시가, h ∈ {4, 16, 48} (1h/4h/12h) — 3값 사전 고정
- 보유 구간 내 15m kline 결측(갭) 있으면 드랍 + 카운트(fail-closed)
- 청산봉이 구간 밖이면 드랍

## 5. 셀 구조와 통계 (고정)

- 셀 = (L, h) → 구성당 12셀 × 4구성(2심볼×2구간) = **패밀리 48셀**, Holm step-down (α=0.05)
- 수익률: 단일 거래 수익 (롱/숏 부호 반영), 평균 → 총bp; 순12/순16/순20 = 평균 − 정액비용(12/16/20bp)
- t검정: (평균 − 16bp) / (sd/√valid_n), valid_n = n/h (중복 보정, P1·X3·C1 관행 동일), 양측 p
- 통제: ①추종 반대(각 거래 부호 반전) ②무작위 100시드(부호 무작위, seed=20261012)
- 유효표본 조건: valid_n ≥ 30

## 6. 판정 규칙 (고정)

- **PASS = Holm p<0.05 셀 ≥1 AND 해당 (L,h) 조합이 4구성 중 ≥3 양수(순16>0, valid_n≥30) AND 유효표본
  기준 충족**
- 통과 시 즉시 OOS: 각 구간 하위 40% 동일 규칙 적용, 양수 세그먼트 ≥2/4 필요
- 전원 실패 시 폐기 권고로 종결, 재파라미터링 없음

## 7. 비용 교차검증 (고정)

- 저장소 엔진 CandleCostModel (costs.py:104-117): fee 5bp + half_spread 2bp + 10%·√participation per side
- 시나리오: $10k / $100k, participation = 주문금액 / 바 거래대금(qv, 퍼페 15m), 5% 초과 fail-closed
- 엔진 비용 기준 Holm 재계산 — 본 검증이 최종 판정 우선

## 8. 패밀리 사전검증 (정보성, 판정에 불가입)

  |ρ|≥0.5면 "펀딩 변형"으로 기록하되 판정 규칙은 변경하지 않음.
- 데이터 사전 한계 등록: ①납품계약 1h 저유동성 결측 → fail-closed로 신호 밀도 저하 가능
  ②L=960(40d)은 z 윈도우 720 + L 누적으로 구간 초반 최대 ~70일 신호 부재 (2021-05 구간에서
