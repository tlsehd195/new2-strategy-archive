# 사전등록: X5 스테이블코인 공급 모멘텀 (Stablecoin Supply Flow, 일간 규약)

고정 시각: 2026-10-12 (측정 스크립트 실행 전) · 작성: Z.ai Code (Task 19, 루프 사이클 7)
규칙: 본 문서 고정 후 규칙 변경 금지. 사후 파라미터 재조정은 사전등록 위반.

## 0. 데이터 정직성 선언과 규약

- 로컬 파일 `r3_llama_usdt_hist.json`은 파일명과 달리 **전체 스테이블코인 순환공급(peggedUSD)** 일간
  스냅샷(DefiLlama, 2017-11-29~2026-10-12, 3,240레코드, 00:00 UTC 실측) — USDT 단일 아님. 본 등록은
  "스테이블코인 총공급" 가설로 정직하게 진행하며 USDT 단일 재수집은 하지 않음(정확한 USDT 시계열은
  별도 과제).
- 일간 규약(F2/X6에서 확립): **valid_n = n / max(1, h ÷ 96)** — 15m 규약의 일간 변형(중복 보정의
  정확한 정의). 진입은 스냅샷 시각(00:00 UTC) 다음 첫 완성 봉(00:15 UTC) 시가로 인과성 확보.
- 알려진 약점(사전 등록): 일간 주파수 + 공급 변화의 자기상관(민팅은 연속 며칠 지속) → 유효 독립
  표본이 n보다 작을 수 있음. 규약의 중복 보정(h÷96)이 이를 부분적으로 처리.

## 1. 가설

스테이블코인 총공급의 단기 변화는 암호자산 유동성 유입/유출의 프록시다 — 공급 확장(z ≥ +1.2816,
민팅 우위) 직후 상승(롱), 축소(z ≤ −1.2816) 직후 하락(숏) (**추종** — 유동성 흐름 방향).

## 2. 데이터

- 공급: `NEW2_run/research/r3_llama_usdt_hist.json` (일간 스냅샷 00:00 UTC)
- 실행: `NEW2_run/data/klines/{SYM}-15m-*.csv` (로컬, 시가) + qv
- 측정 구간 (표준): BTCUSDT/ETHUSDT 각 2구간 (기존과 동일 — 잠금 해제 구간만)

## 3. 신호 정의 (고정)

- S_t = t일 00:00 UTC 총공급(peggedUSD)
- Δ_t(L) = S_t − S_{t−L}, L ∈ {1, 7, 30}일 — 3값 사전 고정
- z_t = (Δ_t − mean(직전 90개 관측 Δ)) / std(직전 90개 관측 Δ) — 현재 제외(인과), 결측 Δ는 관측 제외,
  std≤0 또는 NaN이면 신호 없음
- 버킷: **B80 단일, 양측** — z ≥ +1.2816 → 롱 / z ≤ −1.2816 → 숏 (추종)

## 4. 거래 규칙 (고정)

- 진입: 신호일 t의 00:15 UTC 15m봉 시가 (open_time == t + 900000). 없으면 스킵(fail-closed)
- 청산: 진입봉 + h봉 후 시가, h ∈ {96, 288, 672} (1/3/7일)
- 보유 구간 15m 결측 → 드랍(fail-closed), 청산봉 구간 밖 → 드랍

## 5. 셀 구조와 통계 (고정)

- 셀 = (L, h) → 구성당 9셀 × 4구성 = **패밀리 36셀**, Holm step-down (α=0.05)
- 수익률: 단일 거래 수익(부호 반영), 평균 → 총bp; 순12/순16/순20
- t검정: (평균 − 16bp)/(sd/√valid_n), valid_n = 일간 규약, 양측 p
- 통제: ①추종 반전 ②무작위 100시드(seed=20261012), 유효표본 valid_n ≥ 30

## 6. 판정 규칙 (고정)

- **PASS = Holm p<0.05 셀 ≥1 AND 해당 (L,h) 4구성 중 ≥3 양수(순16>0, valid_n≥30) AND 유효표본 충족**
- 통과 시 OOS(구간 하위 40%), 양수 세그먼트 ≥2/4. 전원 실패 시 폐기 권고 종결
