# PREREG — C3 코인베이스 프리미엄 추종 (Coinbase−Binance 현물 스프레드)
작성·고정: 2026-10-12 (Task 23, 측정 스크립트 실행 전). 본 문서 고정 후 규칙 변경 금지.

## 0. 배경·등급·데이터 제약 사전 고지
- C3는 신규 원리 스캔 잔여 2건 중 마지막. 원리: 코인베이스 프리미엄(Coinbase 현물 − Binance 현물 스프레드)은 미국 기관/규제 시장 수요 프록시이며, 프리미엄 확대가 단기 상승 모멘텀을 예측한다는 가설(CryptoQuant/Coinglass 지표 정의 준용).
- **패밀리 인접 사전 고지**: C3는 교차거래소 스프레드이고 X3/C1/C4는 바이낸스 퍼페 프리미엄 인덱스(동일거래소 파생-현물 스프레드)로 데이터 원천이 다르지만, 양쪽 모두 "프리미엄 수준의 방향성 정보"라는 광의 패밀리 인접성이 있다. 패밀리 사전검증(§5)에서 스피어만 상관을 정량화하며, C3 FAIL이 "프리미엄 패밀리 전체 소진"의 마지막 증거가 된다.
- **비용벽 사전 고지**: 프로그램 누적(측정 14건)에서 방향 엣지는 존재해도 taker 왕복 31~41bp($10k)에 전부 미달. C3도 같은 벽을 통과해야 승격.
- **kline 커버리지 제약(§ C2 정정에서 실측된 사실)**: 로컬 15m kline은 BTC 2023-03~2024-03, ETH 2024-11~2026-04 연속 커버리지. C3 측정 구간도 이 안에서 정의된다.
- **잠금 구간 미사용**: BTC 2024-03-25~06-18, ETH 2026-04-28~08-31.
- **API 실측**: Coinbase Exchange 공개 API /products/{X}-USD/candles?granularity=900 — 최근 200 OK(0.06s), 과거 3일 창 289봉 200 OK(BTC 1.0s/ETH 0.26s). 300봉/요청 한도 확인.

## 1. 신호 정의 (고정)
- 15m 봉 t의 프리미엄 P_t = (Coinbase close − Binance close) / Binance close (같은 15m 버킷 close 사용, 양쪽 UTC 정렬).
- z_t = (P_t − mean(P_{t−L..t−1})) / std(P_{t−L..t−1}, ddof=1) — 현재 봉 제외(인과), min_periods=L.
- L ∈ {96, 480, 1920} 봉 = 24h, 5d, 20d (C2와 동일 규약).
- 임계값 |z| ≥ 1.2816 (B80 양측).
- **방향: 추종(follow)** — z ≥ +1.2816 → 롱, z ≤ −1.2816 → 숏. 근거: 기관 수요 프록시의 모멘텀 해석. 되돌림 방향은 통제로만 사용.

## 2. 셀 구성 (고정)
- 심볼-구간 4개 × L 3 × h 3 = **36셀**. h ∈ {4, 16, 48} 봉 = 1h, 4h, 12h.
- 구간(C2 정정 v1과 동일 — kline 실측 연속 커버리지 기계 적용):
  - BTCUSDT: span1 2023-03-01 ~ 2023-08-15, span2 2023-08-16 ~ 2024-03-24
  - ETHUSDT: span1 2024-11-01 ~ 2025-08-15, span2 2025-08-16 ~ 2026-04-20
- 프리미엄 웜업: BTC 2023-02-01~, ETH 2024-10-01~ 다운로드(L=1920 완충).
- 진입/청산: 신호봉 t 다음 봉 시가 진입, t+1+h 봉 시가 청산. 홀딩 중 결측 봉 또는 제외 일 포함 시 drop(fail-closed).

## 3. 판정 기준 (고정, 프로그램 표준)
1. Holm step-down p<0.05 (36셀 패밀리, 순16 기준 t, valid_n=n/h, df=valid_n−1)
2. 엔진 비용 차감 후 양수 (CandleCostModel $10k/$100k)
3. 동일 (L,h) 조합이 4개 심볼-구간 중 ≥3 양수(순16) + valid_n≥30
4. OOS: 각 구간 하위 40% 세그먼트 순16 양수 ≥2/4
- 4개 전부 통과 시 즉시 중단 후 승격 후보 보고. 하나라도 미달이면 FAIL 기록.

## 4. 비용 계산 (고정)
- 진단: 정액 왕복 net12/16/20. 교차검증: CandleCostModel (fee 5bp + half_spread 2bp + 10%·√participation per side, MAX_PART 5%, $10k/$100k).

## 5. 통제·패밀리 사전검증 (고정)
- 반대방향 통제(순16), 무작위 100시드 통제.
- 패밀리 사전검증(정보성): C3 z vs C1 베이시스 모멘텀 z(L=48) 스피어만(바이낸스 프리미엄 패밀리 중복 정량화), C3 z vs P1 펀딩 z.

## 6. 품질 게이트 (고정)
- 프리미엄 봉 결측(양쪽 중 한쪽이라도 없음) → P=NaN → z min_periods로 fail-closed.
- 일별 유효 프리미엄 봉 <90이면 해당 일 제외(신호·홀딩 모두) — C2 규약 재사용.
- API 실패 3회 재시도 후 실패 시 해당 창 결측, 결측률 >5%면 측정 중단.
- Binance close는 로컬 15m kline, Coinbase close는 다운로드 캔들 — 양쪽 중복봉 제거 후 조인.
