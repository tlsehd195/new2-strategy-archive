# PREREG — N2: 지정가(maker) 진입 실행계층 — 사전등록

작성일: 2026-10-13 · 측정 스크립트 실행 전 고정 · 규칙 변경 금지
패턴 준용: PREREG_x1r_reverify_2026-10-13.md (이벤트 셋) + PREREG_x8_taker_flow_2026-10-13.md (셀·Holm 구조)

## 0. 배경과 범위 고지 (정직 선언)

- N2는 **신호(방향 원리)가 아니라 실행계층** 측정 — 프로그램 최초 비신호 측정. 방향 원리 20건 전원 FAIL의 공통 원인은 taker 비용벽(엔진 $10k 왕복 31~41bp)이며, "유일 구조적 경로 = N2 maker 실행계층"이 큐 장부에 등록돼 있었음. 본 측정은 그 가치를 **가정이 아니라 실측**으로 판정한다.
- **유일하게 'taker 벽에만 막힌 양의 원시 엣지'가 문서화된 차량 = X1-R Config A**(BTC 22개월 홀드아웃, 원시 +14.71~+27.05bp vs 엔진비용 30.4~30.7bp, 엔진 net>0 0/4). N2의 질문: maker 진입으로 이 엣지가 순익 양전환하는가.
- **검정력 사전 고지**: X1-R 당시 정액 순16 기준 Holm p 0.75~0.98(유효n 25.5~32.9)이었고, maker-taker 예상 왕복 ≈ 17~18bp로 개선 폭은 약 13~14bp에 불과 → **G-N2(Holm) 통과 확률이 낮음을 사전에 고지**한다. 본 측정의 1차 과학적 가치는 Q1·Q2의 정량화이며, 승격 판정(G-N1~N4)은 부수 결과다.
- 과학적 질문 3개 (사전 고정):
  - **Q1 체결률**: 지정가 주문이 신호 후 K봉 내 채워질 확률은 δ(오프셋)·K(윈도우)의 어떤 함수인가
  - **Q2 불리한 선택**: 체결 조건부 수익은 무조건부 대비 얼마나 열위한가 — 신호 시점 체결이 무신호 대조군보다 유리한가 불리한가
  - **Q3 구원 가능성**: maker 진입 + taker 청산 비용 구조에서 X1-R 원시 엣지가 promotion-basis 순엣지 양전환하는가
- **범위 제외 (사전 고정)**: ①maker 청산(maker-maker)은 Phase B — 청산 체결 시뮬레이션의 복잡도(무한대기·부분체결·이동 규칙)로 Phase A 제외, 청산은 taker 고정 ②C2 호가잔량/L2 세분화는 N2와 별개 측정(본 측정으로 소진되지 않음) ③추격(taker 진입) 모델은 정보성 보조로만 측정 — 승격 회계에서 제외(미체결 = 거래 없음이 현실 배포 기본).

## 1. 이벤트 셋 (사전 고정 — 방향 쇼핑 방지)

- **유일 차량: X1-R Config A 이벤트** — PREREG_x1r_reverify_2026-10-13.md의 사전 고정 규격을 **한 글자도 변경 없이** 준용:
  - 신호: ES/NQ 1h 모멘텀 Δ z (L ∈ {24, 120}, 직전 720 관측 인과 표준화), |z| ≥ 1.2816
  - 방향: **역방향** (z ≥ +thr → 숏, z ≤ −thr → 롱) — X1-R 사전 고정 방향 그대로. X1-R Holm/게이트 결과와 무관하게 방향을 다시 고르지 않는다.
  - 실행 자산: BTCUSDT 퍼페 15m, 스팬 2024-06-19~2026-04-20 (BTC 잠금 2024-03-25~06-18 구조적 배제된 기존 구간). ETH 잠금 구간 일절 미사용.
- 근거: 21건 측정 원기록 전수에서 '원시 엣지 > 0 이면서 엔진비용 미달로만 FAIL'한 유일 패밀리. 다른 후보(C7 원시 +10.3bp, X4/F3 ≤+4bp, X8 추종 +1~2bp)는 maker 비용(~17bp)보다 작아 구원이 구조적으로 불가능함이 이미 문서화돼 있다(X4/F3 행 명시).
- 이벤트 재생성은 x1r_reverify_diag.py의 ext_z·run_segment 로직 그대로 (신호 시점 t에서 t+1h 시점 15m 봉 ei에 진입 예정 — N2는 이 시점에 taker 대신 지정가 배치).

## 2. 실행 규격 (사전 고정)

- **주문 배치**: 신호 1h 봉 t 확정 → t+1h 시점 = 15m 봉 ei 개시 시점에 지정가 주문 배치 (X1-R taker 진입 시점과 동일 — 실행계층만 교체).
- **지정가**: 롱 P_lim = open(ei) × (1 − δ), 숏 P_lim = open(ei) × (1 + δ), δ ∈ {0, 5, 10, 20} bp.
- **체결 판정 (보수적)**: 체결 윈도우 = ei 포함 K봉, K ∈ {4, 16} (1h, 4h).
  - 롱: 윈도우 내 첫 봉 b에서 open(b) < P_lim → **체결가 open(b)** (갭 통과 시 더 나은 가격) / 아니면 low(b) < P_lim → **체결가 P_lim** (가 통과로만 체결 인정).
  - 숏: 대칭 — open(b) > P_lim → open(b) / high(b) > P_lim → P_lim.
  - 터치(low == P_lim)는 미체결 (엄격 통과 기준). 체결된 봉 f에서 포지션 시작.
- **홀드·청산**: 체결봉 f 개시 → f+48봉 시가 **taker 청산** (h=48, X1-R 준용). f+48 부재·스팬 밖·15m 갭 → 해당 이벤트 드랍(fail-closed).
- **fail-closed (사전 고정)**: 체결 탐지 구간 [ei, f] 또는 홀드 구간 [f, f+48] 내 15m 봉 갭 존재 시 이벤트 드랍. 미체결 종료 시 갭 무관 (거래 없음).
- **비용 (사전 고정)**:
  - 진입 maker 수수료 **2bp** (바이낸스 USDT-M 일반 티어 maker 0.02%) — 수동 유동성 공급으로 스프레드·임팩트 0.
  - 청산 taker 1면 = 엔진 공식: 5bp + half_spread 2bp + 10%·√(order_value / qv_exit), participation > 5% → fail-closed (드랍).
  - 민감도: maker 수수료 {0, 1}bp 정보성 기록 (승격 회계는 2bp 고정).
  - 대조군: 동일 이벤트 taker-taker 엔진 왕복 비용 (X1-R 엔진 교차검증과 동일 공식) — 절감폭 = (taker왕복 − maker왕복).

## 3. 셀 구성 (32셀 패밀리)

- {ES, NQ} × {L24, L120} × δ{0, 5, 10, 20} × K{4, 16} = **32셀, 단일 패밀리 Holm**.
- 회계 단위 (사전 고정): **promotion-basis 순엣지 = 체결률 × E[순익 | 체결]** (bp) — 미체결 이벤트의 기여 0. 배포 시 "미체결은 포기" 규칙의 as-lived 기대값.
- t검정: 체결분 순익 기준, 유효n = 체결수/48 (겹침 보정, 기존 셀 통계 관례 준용). promotion-basis 평균과 t통계의 관계(체결률이 분모·분자에 공통 곱)를 §5에 기록.

## 4. 통계 규격 (사전 고정)

- Holm step-down, 패밀리와이즈 α=0.05, **32셀 전체 한 패밀리**.
- **불리한 선택 (AS)**: E[sgn·(open(f+48) − open(ei))/open(ei) | 체결] − E[sgn·(open(f+48) − open(ei))/open(ei) | 전체] (bp) — 진입 가격 개선과 분리된 순수 선택 효과 (ei 기준 동일 홀드 비교).
- **진입 개선**: E[롱: (open(ei) − P_fill)/open(ei), 숏: (P_fill − open(ei))/open(ei)] (bp, 체결분).
- **무신호 대조군**: 동일 스팬 무작위 2,000 시점(시드 20261013 고정), 동일 δ·K 격자 양방향 — 체결률·AS를 신호 시점과 대비 (신호 시점 체결이 시장 평균보다 유리한지 정량). Q2 판정 기준.
- Holm 통과 셀의 세그먼트 일관성: 스팬 전반 60% / 후반 40% 분할 (X1-R OOS 관례 cut = s + 0.6×(e−s) 준용).

## 5. 게이트 (사전 고정)

- **G-N1 경제성**: promotion-basis 순엣지 > 0 셀 존재 (엔진 청산비용 포함, maker 2bp).
- **G-N2 유의성**: Holm(32셀) p<0.05 셀 ≥1.
- **G-N3 일관성**: 통과 셀의 동일 (자산, L, δ, K) 조합이 전반 60%·후반 40% 세그먼트 모두 promotion-basis 양수.
- **G-N4 OOS**: 후반 40% 세그먼트 양수 (G-N3의 부분集合이나 관례 준용으로 별도 기록).
- **전 통과 시 → CONDITIONAL_CANDIDATE**: 루프 중단, maker 실행계층+X1-R 조합의 승격 후보 보고 후 사용자 결정 대기.
- 하나라도 FAIL → **N2 종결**: 실행계층 구조 실측치(Q1·Q2)는 기록 보존하되 승격 경로로서 폐기. 잔여 경로는 P3(90일 누적 대기)·포트폴리오 계층·데이터 축적 대기만 남음 — 루프 종료 보고를 이 결과로 갱신.
