## 2. Dufour 최대화 MC 검정 (`evalue_mmc_results.json`)
귀무 족: 평균 0 GARCH(1,1), 단위분산 t 혁신, 격자 a×b×ν 10점. 통계량: 12개 규칙 중 최대 순 샤프. N = 99, 600회, 수준 5%(표준오차 0.89%p).

| 자료 과정 | 귀무 족 안? | MMC 기각률 | 한 점(국소) MC | 정상 부트스트랩 진단: corr(S₀, 재표본 중앙값) | 평균 S₀ / 재표본 중앙값 |
|---|---|---|---|---|---|
| GARCH t4 | 예 | 1.7% | 3.5% | 0.56 | 0.0551 / 0.0639 |
| 변동성 국면 t4 | 아니오 | 1.7% | 3.0% | 0.57 | 0.0544 / 0.0656 |
| GJR 비대칭 t | 아니오 | 2.2% | 3.0% | 0.56 | 0.0543 / 0.0650 |
| AR 0.05 (예측성 있음) | — | 2.7% | 4.0% | 0.70 | |
| AR 0.10 (예측성 있음) | — | 13.2% | 18.0% | 0.75 | |

- MMC는 논문 명제 4.1대로 수준을 지키고 보수적이다(논문: 크기가 수준보다 낮을 수 있다).
- 정상 부트스트랩이 지나치게 보수적이던 이유(ADR 0025에서 미확정): 재표본이 관측 계열에서 만들어지므로 S₀와 강하게 상관하고(0.56~0.75) 평균적으로 S₀보다 크다. Dufour의 정확성 조건(S₀..S_N 교환가능, 명제 2.2/2.4)을 어긴다.

## 3. StepM FWER와 블록 길이 (`stepm_block_results.json`)
전략 10개, 365일, B = 499, 800회, α = 5%(표준오차 0.77%p). 귀무 10개 모두(완전 귀무) 기준.

| 자료 과정 | 현행 게이트 (고정 σ, b = n^(1/3) ≈ 7.1) | PPW 자동 블록 | bootstrap-t (논문 식 (11), b ≈ 7.1) | b = 1 | b = 15 | b = 30 | RW 알고리즘 6.1이 고른 b (40회) |
|---|---|---|---|---|---|---|---|
| iid t4 | 5.25% | 5.1% | 4.1% | 4.6% | 7.9% | 13.1% | 1: 23, 3: 4, 7: 7, 15: 6 |
| GARCH, 상관 0.5 | 6.0% | 7.1% | 5.5% | 5.6% | 7.4% | 12.0% | 1: 20, 3: 13, 7: 2, 15: 4, 30: 1 |
| GARCH + AR 0.2 | 5.6% | 6.4% | 4.75% | 11.1% | 7.25% | 10.0% | 3: 16, 7: 20, 15: 3, 1: 1 |
| GARCH + AR 0.6 | 11.4% | 11.5% | 7.1% | 43.0% | 11.9% | 14.75% | 7: 20, 15: 20 |

- 3개 대립 + 7개 귀무 설정에서도 같은 순서(현행 4.25~8.4%, bootstrap-t 3.1~6.0%). bootstrap-t의 대립 평균 검정력은 현행보다 조금 낮다(예: GARCH 상관 37.3% → 34.6%).
- 결론: 현행 게이트는 자기상관이 약한 경우 명목 수준 근처(5.25~6.0%)지만, 자기상관이 강하면 넘는다. 논문 그대로의 bootstrap-t가 모든 과정에서 가장 명목에 가깝다. PPW 자동 블록은 개선이 없었다. 블록이 길수록(15, 30) 유한 표본에서 과대 기각한다.
- `stats_mc.stepm(..., studentize="bootstrap_t")`로 추가했다. 기본값은 그대로이며, 쓰려면 새 사전등록이 필요하다.
