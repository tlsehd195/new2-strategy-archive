# 알트 공개 호가 수집 안내 (동동 님이 직접 실행, 클라우드에서는 실행하지 않음)

목적: 알트 15종목의 실제 거래 비용을 공개 호가로 추정한다(ADR 0023 D2). 지금 알트 비용은 가정값이라 한쪽 0.5~1.7%로 아마 과하게 비싸다.

## 실행 (Oracle VM에서 기존 수집기와 별도 서비스 또는 한 번 실행)
```
python3 run/discovery/public_market_collect.py --allow-network --hours 96 --interval 30 \
  --symbols BTCUSDT ETHUSDT BNBUSDT XRPUSDT SOLUSDT TRXUSDT ZECUSDT DOGEUSDT XMRUSDT LINKUSDT ADAUSDT NEARUSDT XLMUSDT BCHUSDT LTCUSDT \
  --out ~/orderbook_alts
```
- 96시간(4일) 이상 켜 둔다. 최소는 72시간이다. 기존 BTC/ETH 수집(~/orderbook_data)과 다른 폴더를 쓴다.
- 요청량: 30초마다 15종목, 분당 약 30회(공개 API 한도 안).
- 끝나면 `~/orderbook_alts` 폴더를 zip으로 묶어 프로젝트에 올린다.
- 알트 호가는 얕아서 일부 종목은 1만 USDT도 못 채울 수 있다. 그때는 그 종목이 "측정 불가"로 나오고, 그 종목은 평균에서 빼지 않고 가정 비용을 그대로 쓴다.

## 올려 주신 뒤 제가 할 일
`public_cost_estimate.py --criteria run/discovery/config/cost_public_estimate_v2_alts.json`로 추정을 만들고, 가정 비용과 비교 보고서를 만든다. 기준은 BTC/ETH v2와 같고, 알트가 얕아서 충격 적합 크기만 10만 → 1만 USDT로 바꿨다(사유는 설정 파일 note).
