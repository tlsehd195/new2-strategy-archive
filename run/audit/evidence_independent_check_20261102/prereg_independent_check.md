요청: 동동 2026-11-02 "이 정도면 너가 뭔가 잘못해서 안되는거 아니야?"
범위: DEV 구간만(S1 2021-01-01~2023-09-18, S2 2024-06-19~2025-10-20, S2에서 BTC 제외).
2020, 2023-09-19~2024-06-18, 2025-10-21 이후 행은 읽자마자 버린다. 검증·잠금·IW1·종이 구간 안 열고 사전등록 활성화 안 함.
이 작업은 새 전략 시도가 아니라 계산 점검이다. 아래 문헌 전략 결과로 후보를 고르지 않으며 시도 기록에 더하지 않는다.

## 방법
- 자료: 바이낸스 USD-M 공개 아카이브(S3 미러) 1d klines, fundingRate 월 파일을 새 다운로더로 직접 받음(CHECKSUM 확인).
- 계산 코드: 기존 `run/*.py` 계산 코드를 읽지 않고 ADR·사전등록 JSON의 문장만 보고 새로 작성(`independent_engine.py`).

## 2. 답이 정해진 점검 (결정적)
- BTC·ETH 보유: 엔진의 1/1 롱 단순합 수익이 종가 비율 로그/단순 합과 맞아야 함(오차 < 1e-9).
- 미래 정보 오라클(신호 = 다음 보유기간 수익): S1 연 샤프가 매우 커야 함(> 5). 작으면 정렬 오류.
- 누설 점검: 신호를 진입 당일 종가까지 쓰게(미래 1봉 포함) 하면 성능이 크게 뛰어야 함(정렬 확인).
- 부호 반전: 비용 0·펀딩 제외 수익은 정확히 부호가 바뀌어야 함.
- 무작위 신호 200회: S1 연 샤프 평균 ≈ 0, 표준편차 ≈ √(365/일수) ≈ 0.6 근처.

## 3. 문헌 단순 전략 재현 (비용 0, 펀딩 포함/제외 둘 다 보고)
- L1 시계열 모멘텀(Moskowitz–Ooi–Pedersen 2012; 코인 Liu–Tsyvinski 2021 RFS): BTC, ETH 각각 지난 28일 수익 부호대로 1배 롱/숏, 매주 월요일, 하루 건너뜀.
  기준: S1 연 샤프 > 0(두 코인 모두). 크기 기대 0.3~2.0(문헌 코인 TSMOM, 기간 다름).
- L2 횡단면 모멘텀(Liu–Tsyvinski–Wu 2022 JF: 1~4주 모멘텀 양의 수익): U50, 7·14·21·28일 수익 상위10 롱·하위10 숏, 주간.
  기준: 네 개 중 3개 이상 S1 부호 양수면 "문헌 방향과 일치". 크기는 문헌(소형 코인 포함 2014~2018)보다 작을 것으로 예상.
- 판정: 문헌 방향과 맞으면 "엔진이 알려진 효과를 잡는다", 반대면 "엔진 또는 시대 차이 → 원인 추적".
