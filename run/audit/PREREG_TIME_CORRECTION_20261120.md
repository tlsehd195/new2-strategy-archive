# 사전등록 작성 시각 정정 (ADR 0096~0099, 2026-11-20)

사전등록 JSON의 `"written"` 값은 작성자가 손으로 적은 시각이고, 실제 시계와 맞지 않았다. **기준 시각은 git 커밋 시각**이며, 모든 사전등록은 해당 결과를 계산하기 전에 커밋되었다. 파일 내용은 커밋된 그대로 두고(사후 수정 없음) 여기서만 바로잡는다.

2~4라운드 사전등록은 1라운드 PR의 CI를 기다리는 동안 로컬 브랜치에 차례로 커밋했고, 1라운드 병합 뒤 같은 커밋을 그대로 이 브랜치에 가져왔다(내용·순서 변경 없음).

커밋 해시: 2~7라운드 사전등록은 처음에 로컬 보조 브랜치에서 1efc6f7, 9b3a111, 2c7098f, 8b43288, 980ce7a, 5072805, 8b32f6f로 커밋했고, 1라운드 병합 뒤 이 브랜치로 cherry-pick하여 a697faa, 75cdd81, 3287ae7, 2eb839e, ad01c08, 3ba6c38, e01aeb3이 되었다. 작성 시각(author date)과 내용은 그대로다. 5~7라운드 사전등록 파일은 "written" 칸에 커밋 시각을 기준으로 한다고 적었다.
