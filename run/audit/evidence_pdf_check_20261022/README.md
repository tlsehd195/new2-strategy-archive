# PDF로 받은 논문 3편 대조의 합성 시뮬레이션 (ADR 0032, 2026-10-22)

시장 데이터·검증·잠금 구간·IW1을 읽지 않았다. 모든 숫자는 정답을 아는 합성 과정에서 나왔다. 어떤 기준·기본값도 바뀌지 않았다.

## 재현
```
cd run
python3 pdf_check_sim.py --parts bets --out audit/evidence_pdf_check_20261022/bets_results.json                      # 수 분
python3 pdf_check_sim.py --parts gk --dgps iid_t4 --rowdir audit/evidence_pdf_check_20261022/rows --out /tmp/x.json   # dgp 4개를 병렬로, 행마다 체크포인트
python3 pdf_check_sim.py --parts gk_circ --out audit/evidence_pdf_check_20261022/gk_circ_results.json                 # 순환 블록
```
시드 20261022. 컨테이너 재시작으로 `gk`는 4개 프로세스로 나눠 행 단위로 이어 돌렸다(재개한 행은 난수 흐름이 한 번에 돌린 것과 다르다). `gk`는 600회, `gk_circ`는 800회(표준오차 약 0.9, 0.8%p).

## 1. StepM: Götze–Künsch 1996 블록 부트스트랩 (`gk_results.json`, `gk_circ_results.json`)
전략 10개, 365일, B = 499, α = 5%, 귀무 10개 모두(완전 귀무)에서의 FWER(%). 블록 길이: 현행·bootstrap-t는 평균 7.1, GK parzen 7, GK 직사각 4, "l15"는 15.

| 자료 과정 | 현행 게이트(고정 σ, 정상 부트스트랩) | bootstrap-t(정상 부트스트랩, ADR 0027) | GK 이동 블록 parzen l=7 | GK 이동 블록 직사각 l=4 | GK 이동 블록 parzen l=15 | GK 순환 블록 parzen l=7 | GK 순환 블록 parzen l=15 |
|---|---|---|---|---|---|---|---|
| iid t4 | 5.2 | 3.7 | 3.8 | 5.0 | 3.0 | 5.6 | 3.9 |
| GARCH, 상관 0.5 | 7.0 | 6.5 | 7.2 | 7.8 | 5.8 | 4.6 | 4.0 |
| GARCH + AR 0.2 | 5.7 | 4.5 | 5.2 | 5.5 | 4.0 | 6.1 | 5.1 |
| GARCH + AR 0.6 | 11.3 | 7.0 | 13.3 | 9.8 | 8.0 | 13.0 | 7.9 |

- 대립 3개 설정(n_alt = 3)에서도 순서는 같다. 평균 검정력(%): iid t4 현행 29.5 / bootstrap-t 25.7 / GK parzen l=7 24.9; GARCH 상관 38.1 / 34.2 / 33.2; AR 0.2 24.0 / 20.1 / 20.0; AR 0.6 13.1 / 8.0 / 13.6.
- GK 방식은 같은 블록 길이에서 정상 부트스트랩의 bootstrap-t보다 명목 수준에 가깝지 않다. AR 0.6에서는 오히려 더 높다. 길이 15는 보수적으로 기울고 AR 0.6에서도 8% 안팎이다. 현행 게이트를 바꿀 근거는 되지 못한다.
- 직사각 가중치는 분산 추정이 음수가 될 수 있다(`stepm`은 오류로 거부한다). 시뮬레이션에서는 그 반복을 빼고 쟀다(`usable_reps`).

## 2. e-값 베팅 규칙: WS-R v7 부록 B (`bets_results.json`)
블록 설계는 `evalue_walkforward_sim.py`와 같다(30일 블록, 손절 1sd, 증거금 2sd, 갭 허용치 0.05sd, λ 상한 0.75). 1만 경로, 60블록.

**크기(α = 0.0304, 귀무 6개 과정, 60블록 기각률 최댓값)**: plugin 0.23%, aGRAPA 0.32%, LBOW 0.11%, GRAPA 0.36%, ONS 0.26%, gKelly 0.13%, 베팅곱 PrPl(헤지 K⁺) 0.58%, 지수형 PrPl-EB 0.05%. 모두 목표 3.04%보다 훨씬 낮다.

**검정력(α = 0.0091, GARCH t4), 24 / 36 / 60블록 기각률(%)**

| 규칙 | 출처 | 샤프 2 | 샤프 3 |
|---|---|---|---|
| plugin(ADR 0027) | GROW/aSOS 식 | 5.7 / 36.9 / 81.4 | 47.0 / 87.6 / 99.3 |
| aGRAPA | 부록 B.3 | 9.0 / 43.9 / 85.0 | 56.9 / 91.3 / 99.5 |

- 귀무(샤프 0, α 0.0091)에서 모든 규칙이 60블록 기각 0.02% 이하다.
- aGRAPA는 ADR 0027의 `wsr_grow`와 식이 같다(테스트로 확인).
- gKelly는 기존 `mixture`와 같다.
- 인쇄된 ONS-m 알고리즘(식 `z = y/(1 − yλ)`, `λ ← λ − …`)은 log(1 − λy)를 올리는 방향이라 초과수익에 반대로 베팅한다. 논문 42쪽의 그림으로 인쇄 내용을 확인했다.
