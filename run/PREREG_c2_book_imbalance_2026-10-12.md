# PREREG — C2 오더북 잔량 불균형 추종 (bookDepth ±5% 밴드)
작성·고정: 2026-10-12 (Task 23, 측정 스크립트 실행 전). 본 문서 고정 후 규칙 변경 금지.

## 0. 배경·등급·데이터 제약 사전 고지
- C2는 신규 원리 스캔 잔여 2건(C2·C3) 중 첫 번째. 원리: 오더북 잔량 불균형이 단기 수익률을 예측한다는 미시구조 문헌(Cartea, Donnelly & Jaimungal 2018; Cont, Kukanov & Stoikov 2014 OFI). 저장소 기록상 "microstructure.py 기구현 — 미연결 채널 와이어링" 성격의 후보.
- **비용벽 최고위험 사전 고지**: 프로그램 누적(측정 13건)에서 taker 왕복 31~41bp($10k)가 방향 엣지(원시 2~115bp)를 전부 흡수. C2 신호도 같은 비용벽을 통과해야 승격 가능하며, 미시구조 신호일수록 엣지가 소폭일 가능성이 높다.
- **데이터 시작점 제약**: Binance futures bookDepth 아카이브는 2023-01-01부터 존재(S3 목록 실측). 로컬 15m kline은 BTC 2024-04-01, ETH 2026-04-30 종료(실측). 따라서 BTC 구간은 2023-01~2024-03으로 짧고, BTC의 2024-04 이후 구간은 측정 불가 — 본 PREREG는 이 비대칭을 사전 고지하며 보완하러 다른 데이터를 섞지 않는다.
- **잠금 구간 미사용**: BTC 2024-03-25~06-18, ETH 2026-04-28~08-31 (locked/reserved TEST). BTC는 kline 종료(2024-04-01)와 잠금 시작(2024-03-25) 사이 2024-03-25~03-31도 제외.
- 스키마 실측(2024-01-01 BTC 1일 표본): 30초 스냅샷 960회/일, 열 `timestamp, percentage, depth, notional`, percentage는 mid 대비 −15%~+15% 정수 30개 수준, depth/notional은 mid부터 해당 퍼센트까지 **누적** 잔량(단조성 실측 확인).

## 1. 신호 정의 (고정)
- 15m 봉 t의 불균형 B_t: 해당 봉 구간에 속한 30초 스냅샷들에서, bid측 누적 notional(percentage=−5)과 ask측 누적 notional(percentage=+5)을 스냅샷별로 각각 합산한 뒤, 스냅샷별 B=(N_bid−N_ask)/(N_bid+N_ask)를 산술 평균. (±5% 밴드 선택은 스키마 내 가장 유동성 높은 표준 밴드 — ±1%는 누적값 미세차로 노이즈, ±15%는 원리와 무관한 심층 유동성이라 배제. 이 표현 선택은 측정 전 고정.)
- z_t = (B_t − mean(B_{t−L..t−1})) / std(B_{t−L..t−1}, ddof=1), 현재 봉 제외(인과). 최소 L개 유효값 필요.
- L(윈도우) ∈ {96, 480, 1920} 봉 = 24h, 5d, 20d.
- 임계값 |z| ≥ 1.2816 (B80 양측, 프로그램 표준).
- **방향: 추종(follow)** — z ≥ +1.2816 → 롱, z ≤ −1.2816 → 숏. 근거: OFI/불균형은 미체결 수요의 방향 압력(가격 충격)을 예측한다는 문헌 방향. 반대(되돌림) 방향은 통제로만 사용.

## 2. 셀 구성 (고정)
- 심볼-구간 4개 × L 3 × h 3 = **36셀**.
- h(홀딩) ∈ {4, 16, 48} 봉 = 1h, 4h, 12h.
- 구간(잠금 해제 + 데이터 가용성만으로 분할, 성과 참고 금지):
  - BTCUSDT: span1 2023-01-21 ~ 2023-08-15, span2 2023-08-16 ~ 2024-03-24 (kline 종료·잠금 시작 직전까지)
  - ETHUSDT: span1 2023-01-21 ~ 2024-09-15, span2 2024-09-16 ~ 2026-04-20
  - 구간 시작 2023-01-21 = L=1920 윈도우 완충(2023-01-01 데이터 시작 + 20일).
- 진입/청산: 신호봉 t의 다음 봉(t+1) 시가 진입, t+1+h 봉 시가 청산(C1·X5 표준 인과성). 홀딩 중 15m 봉 결측(gap)이 있으면 해당 거래 drop(fail-closed).

## 3. 판정 기준 (고정, 프로그램 표준)
1. Holm step-down p<0.05 (36셀 패밀리, t 통계는 순16 기준, 유효표본 valid_n=n/h, df=valid_n−1)
2. 엔진 비용 차감 후 양수 (CandleCostModel $10k/$100k 교차검증)
3. 동일 (L,h) 조합이 4개 심볼-구간 중 ≥3 양수(순16) + valid_n≥30
4. OOS: 각 구간 하위 40% 세그먼트 순16 양수 ≥2/4
- 4개 전부 통과 시 즉시 중단 후 승격 후보 보고. 1개라도 미달이면 FAIL로 기록.

## 4. 비용 계산 (고정)
- 진단: 정액 왕복 net12/16/20 (12/16/20bp).
- 교차검증: 엔진 CandleCostModel — fee 5bp + half_spread 2bp + 10%·√(participation) per side, participation=주문액/봉 quote volume, MAX_PART 5% 초과 거래 제외(fail-closed), $10k/$100k 시나리오.

## 5. 통제 (고정)
- 반대방향 통제: 동일 트리거 반대 진입의 순16.
- 무작위 통제: ±1 랜덤 부호 100시드, P(랜덤 순16 ≥ 실측 순16).
- 패밀리 사전검증(정보성): C2 z vs P1 펀딩 z, vs C1 베이시스 모멘텀 z(L=48) 스피어만 — 마이크로구조 신규 패밀리 독립성 정량화.

## 6. 품질 게이트 (고정)
- 일별 스냅샷 수 <900/960이면 해당 일 제외(quality 기록). 15m 봉당 평균 스냅샷 수 기록.
- B_t 계산 시 N_bid+N_ask=0 스냅샷 제외(분모 0 방지), 봉당 유효 스냅샷 0이면 B=NaN.
- zip 무결성 실패/HTTP 실패 3회 재시도 후 실패 시 해당 일 결측 처리하고 quality에 기록 — 결측 일이 구간의 5% 초과면 측정 중단(중도 보고).
