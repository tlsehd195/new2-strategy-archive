# 사전등록: F2/X6-ALT — F&G 극단공포 후 대형 알트코인 반등 (교차 자산 진단, 진단 등급)

고정 시각: 2026-10-13 (측정 스크립트 실행 전) · 작성: Z.ai Code (Task 33, cron Job 453321 사이클)
규칙: 본 문서 고정 후 규칙 변경 금지. 사후 파라미터 재조정은 사전등록 위반.

## 0. 배경·목적·정직 선언 (진단 등급 사전 고지)

- **기원**: F2/X6(공포·탐욕 극단 역발, 36셀 Holm)은 Holm 0/36 FAIL이었으나 탐색 관측으로 **ETH
  극단공포→3일 엔진 순익 +36.2bp($10k, net>0 4/36)**가 등록되어 F2/X6-R 재검증 과제(2027-01, 신규
  극단 축적 대기)로 보존 중이다. 방향(극단공포→롱)의 근거는 이 ETH 탐색 관측이며 사후 발견이다.
- **본 측정의 목적**: 신규 극단 이벤트 축적(2027-01까지 불가)과 무관하게, **동일 극단공포 일자에 알트
  5종의 가격 경로**(BTC/ETH와 분리된 신규 데이터)로 가설을 시험한다. 알트는 극단공포 국면에 베타로
  더 큰 낙폭→반등 진폭을 가지므로 엣지 확대 가능성이 있다.
- **진단 등급 사전 고지(중요)**: 에피소드 병합(방법론 교훈 ⑦ 통일 기준) 적용 시 이벤트 수가 에피소드
  수로 감소(예상 15~30건) → h≥3일 셀은 유효n<30 **구조적 승격 불가**. 본 측정은 승격 후보 발굴이
  아니라 **F2/X6-R 재검증(2027-01) 자료실에 교차 자산 증거를 축적하는 진단 측정**이다. Holm 통과 여부와
  무관하게 승격 판정에는 사용하지 않는다(측정 전 고정).
- **재개 근거**: 사용자 지시(유니버스 확장 + 승격 가능성 최상위 방향 진행) — F2/X6-R의 교차 자산
  사전 검증은 해당 방향의 증거 강화/약화를 조기 판정한다.

## 1. 가설 (사전 고정)

- **H_F2X6-ALT**: F&G(로컬 3,172일 데이터) 극단공포(B80 ≤20) 에피소드 첫날 다음 날 00:15 UTC 진입 롱은
  대형 알트 5종에서 h∈{1,3,7}일 양수이며, ETH 원관측(+36.2bp 엔진 3일)보다 진폭이 크다.
- 반대(극단공포 후 숏)는 통제로만 기록한다.

## 2. 유니버스·데이터 (사전 고정)

- 알트 5종: X1-R-ALT와 동일(BNB/XRP/SOL/TRX/DOGE — 시총 상위 5종, §2 운용 규칙 동일, 데이터 동일
  305파일). 측정 윈도우: **2021-04-01~2026-04-20** (알트 데이터 풀 스팬, 표준 측정 종점).
- F&G: 로컬 저장본(3,172일 — fng_refresh_check.py 재다운로드 분 포함, 2026-10-13분).
- **잠금 구간 처리(보수적 고정)**: BTC 잠금 2024-03-25~06-18과 겹치는 에피소드는 알트 경로가 잠금
  대상이 아니어도 **제외**한다(논쟁 여지 원천 차단). ETH 잠금 2026-04-28~08-31은 윈도우 종료 후라
  교집합 없음.

## 3. 신호·거래 규칙 (사전 고정)

- 신호일 D = F&G ≤20일. 에피소드 = 연속 ≤20일 구간 병합(교훈 ⑦), 에피소드 첫날을 진입 신호일로 사용.
- 진입: D+1일 00:15 UTC 15m봉 시가(F&G 당일 발행 — D+1 최초봉 진입으로 인과성 보장). 결측 시 다음
  정상 봉 fail-closed 스킵 없이 드랍+카운트.
- 청산: 진입봉 + h{96, 288, 672}봉(1/3/7일) 후 시가. 보유 구간 15m 결측 시 드랍.
- 방향: **롱 고정(1차)**.

## 4. 셀 구조·판정 (사전 고정)

- 셀 = 5알트 × h{1,3,7} = **15셀 Holm** — 보고용(진단 등급, 승격 판정 미사용).
- 유효n = 에피소드 수 / h (h1만 30 근접 가능성, h3/h7 구조적 미달).
- 보고 지표: 원시 총bp · net16 · 엔진 CandleCostModel $10k 순익(§X1-R-ALT §7 동일 모델) · 전방위
  60/40 분할 일관성.
- **판정 기준(진단)**: 알트 5종 중 엔진 $10k 양수 ≥3/5 & 3일(h288) 셀에서 ETH 원관측(+36.2bp)과
  동방향 → F2/X6-R 자료실 "교차 자산 지지" 기록 / 미달 → "교차 자산 반증" 기록. 어느 쪽이든 2027-01
  재검증 대기 상태는 변하지 않는다.

## 5. 리스크 사전 고지

- 에피소드 수가 적어 모든 통계적 판정은 저검정력이다 — 유의성 주장 없이 효과 크기와 부호 일관성만
  기록한다.
- 극단공포 에피소드는 시장 전체 이벤트이므로 5알트 결과는 상호 독립이 아니다 — 일관성 참조로만 쓴다.
- F&G ≤20 일자의 상당수가 BTC 잠금 제외로 잘려나갈 수 있다(2024-04 클러스터) — 표본 수는 실측으로
  보고하고 사후 기준 변경 금지.
