## 0. 배경과 정직 고지

1. **관측 기반 후속 측정임을 명시**: X12(Task 32)에서 "극단 양의 일간 수익률 → 숏"이 최고 셀 gross +121.8bp(숏 net16 +105.8bp)로 방향 일관 관측됐으나 n=16·단일 국면(2022)·p=0.126 으로 Holm 0/48 FAIL 폐기. X13은 **동일 가설을 유니버스 확장으로 표본 5~10배 늘려 재검정**하는 관측 기반 후속 설계다. X12에서 Holm 통과 셀이 0이었으므로 승자의 저주 부채는 없으며, 본 측정은 **전체 승격 기준(Holm + 엔진 + 일관성 + OOS)** 을 그대로 적용해 보상한다.
2. **다중검정 계보 정직 기록**: X12 패밀리 48셀(전원 무유의) + X13 패밀리 12셀 — 동일 가설 2차 관측임을 결과 문서에도 명시한다.
3. **펀딩 비용 미포함 사전 고지**: h ≤ 1일(최대 3회 정산 ≈ 수 bp) 홀딩이며 X12 템플릿도 미포함. **Holm 통과 셀 발생 시 승격 판정 전에 반드시 펀딩 감사를 별도 실행**한다(승격 전제).
4. **신규 코인 잠금 장부 부재 고지**: 저장소 잠금 구간(BTC 2024-03-25~06-18, ETH 2026-04-28~08-31)은 해당 심볼에만 적용된다. 신규 코인에는 잠금이 없으며, 이는 유니버스 확장의 설계상 속성으로 기록한다.
5. **데이터 제한 고지**: 신규 코인은 Binance USDT-M 선물 상장일 이후 데이터만 존재한다. 상장 전 구간은 구조적으로 결측이며, 커버리지 규칙(§2.3)으로 처리한다.

## 2. 측정 규격 (X12와 동일 — 유니버스·풀링·군집 표준만 신설)

### 2.1 신호 (X12 규격 그대로)
- 일간 로그수익률 r_D: **완전일(96봉)만 유효**(fail-closed), 불완전일·결손일은 NaN 및 다음 일 자동 오염 처리.
- z_D = (r_D − mean(r_{D−L..D−1})) / std(r_{D−L..D−1}) — **인과(현재일 제외)**, L ∈ {90, 288}.
- 버킷: B80 (z ≥ +1.2816), B90 (z ≥ +1.6449) — 양의 꼬리만 1차 대상.
- **1차 방향(사전 고정, X12와 동일)**: z ≥ +thr → **숏** (복권 과열 정상화, Bali et al. 2011 prior). 방향 쇼핑 금지.
- 통제(관측 전용, 승격 불가): 추속 롱(양의 꼬리), 음의 꼬리 MIN 숏, 무작위 방향 100시드.

### 2.2 실행·에피소드
- 진입: 신호일 다음날(S일) 00:15 UTC 봉 시가. 청산: 진입봉 + h봉 시가. h ∈ {16, 48, 96}.
- **에피소드 병합 상태 머신(교훈 ⑦)**: 극단 상태 연속 구간당 1트레이드 — (coin, L, b)별. 진입·청산 봉 연속성(15m 간격) 검증, 끊기면 드랍 카운트.
- **군집 표준(신설)**: 같은 UTC 진입일에 여러 코인이 진입한 에피소드는 **동일 시장 이벤트**이므로 1군집으로 묶는다. valid_n = **군집 수(서로 다른 진입일 수)** — 교훈 ⑧(valid_n=n)의 다중코인 확장. 군집통계 = 진입일별 에피소드 수익률 평균, t = mean(군집평균)/(sd/√n_군집).
- 진입일별 가중: 동일일 다수 코인 진입 시 단순 평균(사전 고정 — 코인별 균등 가정, 볼륨 가중 미사용).

### 2.3 스팬
- BTCUSDT: (2021-05-02, 2022-08-17), (2023-04-07, 2024-03-18) — X12와 동일. 잠금 z-윈도우 오염 fail-closed.
- ETHUSDT: (2021-05-02, 2022-08-17), (2024-12-10, 2026-04-20) — X12와 동일. 잠금 동일 적용.
- 신규 코인: 데이터 커버리지 시작일(+L 워밍업) ~ **2026-09-30** (완전월만), 단일 스팬. 커버리지 <540 완전일 → 제외.
- 모든 진입·청산은 스팬 내 봉에서만(fail-closed).

### 2.4 패밀리·Holm
- **패밀리 12셀** = {B80, B90} × L{90,288} × h{16,48,96} — 코인 풀링 단일 셀 구조(X12의 스팬 분해를 유니버스 풀링으로 대체 — 표본 통합이 확장의 목적).
- Holm-Bonferroni 12셀 일괄. 통제·관측 셀은 Holm 대상 아님.

### 2.5 통계·비용
- 정액 비용: net12/16/20bp (기존 diag 연속성).
- **엔진 교차검증(별도 스크립트)**: CandleCostModel 공식 — fee 5bp + half_spread 2bp + 10%·√participation per side, participation = 주문금액/바 qv, >5% fail-closed. 시나리오 $10k/$100k. 엔진 순익 = 에피소드별 (r_i − c_i) 후 군집 평균 → 군집 t. valid_n = 군집 수.
- OOS: 코인별 스팬 하위 40% 경계 이후 진입 에피소드(풀링 재집계).
- **일관성(era)**: era1 = 진입일 < 2023-01-01, era2 = ≥ 2023-01-01. 각 era 군집 순익(정액16 및 엔진 $10k) 양수 + 군집 수 ≥ 15.

### 2.6 PASS 게이트 (사전 고정 — 전부 충족 시에만 승격 후보)
1. p_holm < 0.05 (12셀 패밀리)
2. 군집 수 ≥ 30
3. 엔진 순익 > 0 ($10k) — 정액 아니라 엔진 기준
4. OOS 군집 순익(엔진 $10k) > 0
5. era1·era2 동시 양수(각 군집 ≥15)
6. 폭( breadth ): 해당 셀 에피소드에 기여한 코인 ≥3개, 각 ≥5 에피소드
7. (승격 보고 전) 펀딩 감사 별도 실행

## 5. 이 규격의 근거 (왜 이 방향이 '최유망'인가 — 사전 논증)
1. **엔진 비용을 넘은 유일한 구조적 관측군은 (a) 3일+ 장홀딩(F2/X6-R +36.2bp), (b) X12 극단일 반전(+121.8bp gross)** — 둘 다 "저빈도·큰이동"으로 비용을 상각하는 구조. X13은 (b)의 표본 제약(코인 2개)을 직접 제거한다.
2. 유니버스 확장 자체가 이 패밀리에 최적: 극단 일간 이동은 코인별로 준독립 발생(시장 전체 이벤트와 구분) → 코인 수 ∝ 에피소드 수. F&G 같은 시장 공통 이벤트 패밀리는 코인 수를 늘려도 군집 수가 늘지 않는다(상관 1에 수렴) — X13이 확장의 수혜가 최대인 패밀리다.
3. 유동성 상위 코인일수록 알트 대비 변동성은 낮지만, 확장된 꼬리(z 버킷)는 상대 자체 표준편차로 정규화 — 고변동 코인의 더 큰 gross 무브를 포착.
4. 대안 기각 논거: 크로스섹셔널(X14)은 새 머신리스크(포트폴리오 리밸런스·양방향 비용)가 커서 다음 순서. N2 maker는 엣지 자체가 작아(순익 +7~11bp 무유의) 유니버스 확장과 독립. F&G 일반화는 군집 중복(§2.5 논거)으로 확장 수혜 미미.
