# 로컬 사전등록 (Phase A 진단 등급) — 2026-10-12, Z.ai Code

**성격**: NEW2 저장소 거버넌스의 "Phase A 진단" 등급 측정(등록 예산 3/30일 소모 없음, locked/reserved TEST 구간 일절 미사용).
저장소 장부는 수정하지 않는다(사용자/클로드코드가 결과를 검토 후 통합). **이 문서는 첫 실행 전에 고정되며 사후 조정 금지.**

## P1 — 펀딩비 극단 역발상 (fr_extreme, 15m daytrade)

- **시장 가설**: 영구선물 펀딩비가 최근 30일 대비 극단적으로 높으면 롱 레버리지 수요가 과열된 것 → 이후 1~12시간 가격이 반대 방향으로
  되돌린다(약한 형태: 극단 방향의 추종 수익은 비용을 넘지 못한다). 근거: 펀딩은 공매도·롱 수요의 직접 가격(bp)이고, 크라우드
  역발상 문헌 다수(방향성 프리딕터로서의 펀딩). 캐리 수집(funding_carry, dead pattern)·투표 구성요소(funding_crowding, ADR-0025)와는
  다른 원리(독립 이벤트 신호, |z| 임계값, 역발상 방향 베팅).
- **데이터**: 바이낸스 UM 월별 15m kline + fundingRate (data.binance.vision). BTCUSDT·ETHUSDT.
- **측정 구간**(저장소 잠금 해제 구간과 동일, ADR-0088/0089 준용): BTC 2021-05-02~2022-08-17, BTC 2023-04-07~2024-03-18,
  ETH 2021-05-02~2022-08-17, ETH 2024-12-10~2026-04-20. 워밍업: 직전 30일 이상(90회 정산) 필요 → 데이터는 2021-04-01/2023-03-01/2024-11-01부터.
- **신호(인과)**: 각 정산 시각 T의 펀딩 r_T. z_T = (r_T − mean(직전 90회)) / std(직전 90회). 직전 90회 미만이면 스킵.
- **버킷(고정)**: B80 = |z|≥1.2816, B90 = |z|≥1.6449 (정규분위수 고정 — 롤링 분위수 재귀 금지).
- **방향(고정)**: 역발상 — z>+thr → 숏, z<−thr → 롱. 추종 방향은 통제로만 보고.
- **진입/청산**: 정산 직후 첫 15m 봉 시가 진입, h봉 뒤 봉 시가 청산. h ∈ {4, 16, 48}봉(1h/4h/12h). 구간 내 데이터 구멍 있으면 해당 거래 폐기(fail-closed) 후 집계.
- **비용**: 왕복 12/16/20bp 정액(대표 16bp). 펀딩 자체는 미반영(보유 최대 12h, 8h당 ±1bp 내 — 한계로 명시).
- **시도 수(다중검정 가족)**: 2심볼 × 2구간 × 2버킷 × 3지평 = **24셀**. Holm 보정 over 24. 통제(추종 방향, 무작위 방향 100시드)는 시도 수에 넣지 않음.
- **판정(결과 보기 전 고정)**:
  - 셀 통계: 유효표본 n_valid = 신호수/h(겹침 보수 보정), t = 평균순수익/(sd/√n_valid).
  - **PASS** = Holm 보정 p<0.05인 셀이 1개 이상 AND 그 셀과 동일 (버킷,지평) 조합이 4개 심볼-구간 중 **3개 이상에서 16bp 순평균 > 0** AND 각 조합 n_valid ≥ 30.
  - PASS여도 등록이 아니다(선별 후보 제안까지만). 아니면 P1 폐기 권고 + 실패 원인 기록.

## P3 — 청산 캐스케이드 (liq_cascade) — BLOCKED_DATA, 가설 정의만

- **가설**: 강제청산(forceOrder) 급증(예: 15분 내 청산액 z>3) 직후 되돌림(청산 방향 반대)이 비용을 넘는다. 근거: 청산 캐스케이드 문헌·실무 관행.
- **데이터**: 바이낸스에 과거 아카이브 없음 → ADR-0085 수집기(2026-10-11 시작, 사용자 PC)가 데이터를 쌓는 중. **최소 90일 누적 후 측정 가능.**
- **사전 고정(지금 확정)**: 신호 = 15분 창 청산 명목액 USD 합의 직전 960창 대비 z; 버킷 q90/q95; 방향 = 청산 방향 반대(되돌림); 진입 = 신호 다음 봉 시가;
  지평 = {4,16,48}봉; 비용 = 왕복 12/16/20bp; 판정 = P1과 동일 규칙(Holm over 24셀, 3/4 구간 양수, n≥30). 수집기가 심볼당 1초 1건 하한(ADR-0085)이라
  실제보다 과소 계수됨 — z 임계값은 수집 시작 후 실측 분포로 재고정해야 하며, 그 재고정은 첫 측정 전 1회만 허용.

## 데이터 품질 검사 (실행 전 필수)

각 심볼-구간: 15m 봉 연속성(기대 1봉/15분) 검사, 결측·중복·timestamp 불일치 수 집계 → 결과 파일에 기록. 펀딩 결측 정산 수 집계.
