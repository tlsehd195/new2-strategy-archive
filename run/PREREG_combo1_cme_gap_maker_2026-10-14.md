## §0 조합 근거 (원기록 인용 — 측정 전 확정)

두 개의 기왕 실측 기록이 이 조합의 유일한 근거이며, 전부 results/ 원기록으로 검증 가능:

1. **F1 (results/f1_cme_gap_results.md)**: 사전등록 되돌림 방향은 Holm 0셀 FAIL. 그러나 **추종 통제열(반대 방향) h48이 4개 심볼-구간 전부 양수** — 원기록상 유일한 4/4 일관성 패밀리:
   - G100 h48 추종 순16: BTC s1 **+72.25** / BTC s2 **+115.23** / ETH s1 **+33.30** / ETH s2 **+11.65** bp
   - G50 h48 추종 순16: +19.85 / +73.05 / +26.83 / +33.07 bp (역시 4/4)
   - G100 h48 BTC s2 되돌림 p=0.0063 (n=17) — 추종은 동일 t로 반대 부호 (p=0.0063)
2. **N2 (results/n2_maker_exec_results.md)**: maker 실행계층 구조 실측 — **G-N1 경제성 PASS**(19셀 promo순>0, 최대 +10.86bp). G-N2~N4 FAIL의 원인은 신호(X1-R)의 엣지 부재였음이 원기록에 명시. δ=0·K16에서 체결률 ~99.5%·AS −0.5bp — maker 진입은 체결률을 거의 희생하지 않음.

**조합 논리**: 비용벽(taker 왕복 31~41bp)이 F1 추종의 원시 엣지(총 27~131bp)를 갉아먹던 것을 maker 진입(2bp)+엔진 taker 청산 1면(~7bp)으로 ~9~10bp로 압축 → 원기록상 유일한 4/4 일관성 양수 패밀리가 비용벽을 넘을 구조적 여지. **이 조합은 본 프로그램에서 비용벽과 엣지 부족을 동시에 치는 유일한 기측정 요소 결합이다.**

## §1 조합 구조와 사전 고정 파라미터

- **이벤트**: F1 관례 그대로 (f1_cme_gap_diag.py weekend_events) — CME 일봉 연속 갭 ≥2일 + 직전 봉 금요일 + sig_ms 관례(월스탬프 −6h / 일스탬프 +18h) + 현물 15m 첫 봉 진입, 지연 ≤30분 fail-closed. 데이터: `data/cme/{BTC_F,ETH_F}_1d.json` (2026-04-29까지 확인 — s3 커버) + `data/klines/{sym}-15m-*.csv` (2026-10-11까지 확인). **신규 다운로드 0바이트.**
- **방향 = 추종(continuation) 사전 고정**: gap>0 → 롱, gap<0 → 숏.
- **버킷 = G100 (|gap| ≥ 1.0%) 만 승격 패밀리**: 기관급 디스로케이션 크기 기준. |gap| 중앙값(BTC 1.07%·ETH 1.62%) 이상의 갭만 — 정규 주간 변동성 내 갭(G50)은 정보성만.
- **지평 = h48 (12h) 만 승격 패밀리**: 16h는 ETH s1 음수(−20.45bp)로 4/4 붕괴 — 기각. 48h는 유일한 4/4.
- **실행 = maker 진입 δ=0bp·K=16봉(4h) 사전 고정**: N2에서 체결률 99%+·AS 최소 조합. 체결 규칙 N2 그대로: 롱 P=open·(1−δ), 바 open<P면 open 체결, 아니면 low<P 시 P 체결, K봉 내 미체결 시 포기(미체결=0). 숏 대칭.
- **회계**: 진입 maker 수수료 2bp + 청산 엔진 taker 1면 (5bp 수수료 + half_spread 2bp + 0.1·√participation, 참여 >5% fail-closed). 진입 maker에는 임팩트 미부과(지정가 — 사전 고정).
- **promotion-basis 순엣지 = 체결률 × E[순익|체결]** (N2 회계 그대로). 이벤트별 promo 시리즈(미체결=0)로 t-검정, df=n−1, 양측.
- **valid_n = n** (주간 이벤트 비겹침 — h48 청산은 수요일, 다음 이벤트는 차주 월요일, F1 사전 고정 준용). **승격 카운트 셀은 n≥15 요건** (F1 판정 코드 준용).
- 참고열(비교용, 비승격): net16 동등값 = 추종 총수익 − 16bp 고정 (F1 표와 직접 비교 가능하게).

## §4 OOS·무작위 대조

- **OOS (프로토콜 사전 고정)**: 각 패밀리 셀 스팬 하위 40% (cut = s + 0.6×(e−s) 이후 이벤트), 동일 설정 promo순 양수 세그먼트 ≥2/4.
- **무작위 대조**: 100시드 부호 반전(이벤트별 promo 수익의 부호를 무작위 반전한 평균 분포 ≥ 실측 평균 비율), seed=20261014 — F1 관례 준용.

## §6 정직성 고지 (측정 전 의무 기재)

1. **방향(추종)·버킷(G100)·지평(h48)·실행(δ0 K16)은 F1/N2 FAIL 원기록에서 사후 선택된 값** — 엄밀한 의미의 독립 신규 가설이 아니라 **문서화된 발견의 재확인 측정**이다. 완화 장치: OOS 하위 40% 게이트, CME 갭 미측정 버진 구간(BTC s3) 홀드아웃, 무작위 대조, 엔진 양 스케일 비용, 4셀 Holm. 동일 데이터 재사용의 한계는 승격 보고서에도 반복 명시한다.
2. 이벤트 수가 적다(G100 셀 n=17~48) — 낮은 검정력을 사전 고지하며, n≥15 요건과 t-검정 df=n−1로 투명하게 처리.
3. 스팬 내 15m 연속성 깨진 이벤트는 fail-closed 폐기(카운트 보존).
4. 규칙·임계값·방향은 측정 시작 전 본 문서에서 확정되며, 측정 후 변경 금지(측정 전 정정은 §8 addendum로만 가능 — 원기록 보존).
