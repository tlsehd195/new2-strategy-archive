## §0 정직성 고지 (사전 고정)

1. **플래그 방향의 in-sample 기원**: 조합 플래그의 방향은 기존 27건 측정의 원기록 관측(같은 스팬 내 표본)에서 채택되었다 — X10 발견 ㉞(ASIA h16 롱 드리프트 Holm 유의 음수 → 하락 플래그), 발견 ㊱(고비유동 후 하락 추종 → 하락 플래그), 발견 ㊴(고왜도 후 상승·저왜도 후 하락 추종 → 대칭 플래그), X1-R Config A 원시 +14.7~+27.1bp(역방향 플래그). **컨플루언스(조합 증폭) 가설 자체는 신규이며 본 측정이 첫 검정**이나, 플래그 설계에 사내 표본 정보가 포함됨을 명시한다. 완화 조치: OOS는 각 스팬 후반 40%로 시간 분리, Holm 32셀 결합, 무작위·반대 통제 병행. 승격 판정은 Phase A 기준이며 1차 통과 시에도 플래그 설계 오염을 후보 보고서에 명기한다.
2. **X1-R 플래그의 스팬 비대칭**: ES/NQ 데이터 범위(2024-05-19~2026-10-12)로 인해 F_X1R은 4표준 스팬 중 ETH s2(2024-12-10~2026-04-20)에서만 기여한다. 타 스팬에서는 3플래그로 컴포짓이 계산된다(규칙 자체는 균일 — 플래그 가용성 차이만 존재).
3. **검정력 사전 고지**: K=2 컨플루언스는 이벤트 수 급감으로 valid_n≥30 미달 가능성이 높다. K=1은 플래그 밀도가 높아 사실상 단일 신호와 수렴할 수 있다. 두 극단 모두 측정하여 경계를 실증한다.
4. **maker 변형의 근거**: N2(Task 28)에서 검증된 체결 모델(δ=5bp·대기 16봉 — 체결률 82~99.6% 실측 구간)을 변형 없이 재사용한다. δ·K 값은 N2 원기록 참조로 사전 고정하며, 본 측정에서 튜닝하지 않는다.
5. 조합 대상에서 **제외된 패밀리와 이유**: F2/X6(극단공포 — ETH 신규 구간 이벤트 0건·2027-01 대기, 플래그 기여 무의미), KP·C3(일간 신호 — 15m 컴포짓 정렬 시 시간 해상도 불일치), X3/C1(선물 베이시스 — premiumIndexKlines 스팬 정렬 검증 비용 대비 원시 엣지 ≤20bp), ALT 계열(기기 상이 — 스팬 비대칭 과다). 제외는 측정 전에 고정되며 측정 후 결과를 보고 변경하지 않는다.

## §1 조합 플래그 정의 (원기록 방향 사전 고정 — 변경 금지)

모든 플래그는 BTC/ETH 15m 봉 기준으로 시점별로 계산하며, 패밀리당 컴포짓에 **최대 1** 기여한다.

| 플래그 | 방향 | 활성 조건 | 근거(원기록) |
|---|---|---|---|
| F_X10 | DOWN | 바의 UTC 일중 오프셋 < 16봉(00:00~04:00 UTC, ASIA 세션 창) | 발견 ㉞ — ASIA h16 롱 Holm 유의 음수(−14.9~−22.2bp) |
| F_A1 | DOWN | ILLIQ z(L=288, NWIN=960 shift1) ≥ +1.2816 (B80) | 발견 ㊱ — 고비유동 후 하락 추종 |
| F_X12 | UP 또는 DOWN | skew z(L=288, NWIN=960 shift1) ≥ +1.2816 → UP / ≤ −1.2816 → DOWN | 발견 ㊴ — 왜도 추종 지속 |
| F_X1R | 역방향 | ES/NQ 1h Δz(L∈{24,120}) \|z\|≥1.2816 발화 조합의 −sign(z) 다수결(동수 2-2 → 무플래그), 이벤트 시각 tt+1h부터 48봉 창 | X1-R Config A 원시 +14.7~+27.1bp |

- F_A1·F_X12의 z 계산은 a1_illiq_diag.py `illiq_z` / x12_skew_diag.py `skew_z` 규격 그대로(15m 로그수익률 연속봉만, qv>0, rolling(L) 후 960윈도우 mean/std shift1 — 인과).
- L=288 선택 근거(측정 전 고정): A1 Holm 통과 47셀·X12 44셀의 L 분포가 균등(96/288/960/2880 각 10~13셀) — 특정 L 우위 관측 없음, 중간값 대표 선택.
- F_X1R 계산은 x1r_reverify_diag.py `ext_z` 규격 그대로(Δ=close_t−close_{t−L}, 720윈도우 표준화). 4조합 {ES,NQ}×{L24,L120} 중 |z|≥THR 발화의 방향 다수결.
- **동일 패밀리의 UP/DOWN 동시 충돌 시**(F_X12는 대칭이므로 불가, F_X1R 다수결 동수는 무플래그): 구조적으로 발생하지 않도록 규격 고정 — 각 패밀리는 시점당 방향 1개만 산출.

## §2 컴포짓 규칙 (사전 고정)

- 시점 t(15m 봉)에서 net_t = (#UP 플래그 활성) − (#DOWN 플래그 활성).
- 1차 방향(사전 고정): net_t ≥ +K → 롱 / net_t ≤ −K → 숏 / 아니면 플랫. K ∈ {1, 2}.
- **상태 머신(봉별 중복 진입 금지 — 교훈 ⑦ 준용)**: 플랫 상태에서 조건 충족 시 다음 봉 t+1 시가 진입(1차=taker). 홀드 h봉 후 t+1+h 시가 청산. 청산 봉부터 재평가(청산 봉에 조건 충족 시 다음 봉 재진입). 홀드 중 신규 진입 없음.
- h ∈ {16, 48} (X10/X12/X1-R의 h16·h48 원 규격과 정렬).
- 진입 방식 2종(패밀리 내 병렬 변형):
  - **taker**: t+1 시가 시장가 진입, t+1+h 시가 시장가 청산.
  - **maker**: t+1 봉부터 지정가 대기 — 기준가=open(t+1), P=기준가×(1−δ·sgn), δ=5bp, 최대 대기 16봉(N2 모델 준용: open 갭→open 체결 / low·high 통과→P 체결 / 16봉 내 미터치→미체결 스킵). 체결 봉 f로부터 h봉 후 시가 청산. 대기 중 신규 신호 무시(펜딩 1건 제한).
- fail-closed: 진입~청산 구간 봉 연속성 파괴·스팬 밖 청산·(엔진) participation>5% → 트레이드 제외(드랍 집계).

## §3 패밀리·셀 구성 (사전 고정)

- **F1 = 3플래그**(F_X10·F_A1·F_X12) — 전 스팬 균일.
- **F2 = 4플래그**(F1+F_X1R) — X1R은 ETH s2만 기여(§0-2).
- 셀 = 패밀리{F1,F2} × K{1,2} × h{16,48} × 진입{taker,maker} × 스팸{BTC s1, BTC s2, ETH s1, ETH s2} = **64 cell-span**.
  - 정정 기록(측정 실행 전): 초안에서 32로 기재했으나 산술상 2×2×2×2×4=64가 정확 — 오타 정정. 셀 열거 규칙 자체는 무변경이며, Holm 셀 수 증가는 더 보수적 방향이다.
- **Holm은 64셀 결합 단일 패밀리** (보수적 — 패밀리별 분할 Holm 미허용). F2가 F1과 동일해지는 스팬(X1R 비기여 3스팬)의 중복 셀도 Holm 분모에 포함(보수적).
- 측정 스팬(잠금 완전 제외): BTC s1 2021-05-02~2022-08-17 / BTC s2 2023-04-07~2024-03-18 / ETH s1 2021-05-02~2022-08-17 / ETH s2 2024-12-10~2026-04-20 (종료 미포함 — 기존 X8/A1/X12 규격 동일).

- 각 스팬 후반 40% (cut = s + 0.6×(e−s)) — OOS 윈도우에서 플랫 시작 상태 머신 재실행.

## §6 게이트·승격 기준 (사전 고정 — Phase A)

- **G1**: Holm p<0.05 (정액 net16 기준 t, valid_n=n).
- **G2**: 엔진 net > 0 ($10k). taker 셀 = 엔진 양면(fee 5bp+half_spread 2bp+impact 0.1×√participation, part>5% fail-closed). maker 셀 = promo_net = 체결률 × E[net|체결] (maker fee 2bp + 엔진 청산 1면). $100k는 강건성 참고.
- **G3**: 일관성 — 통과 셀의 엔진 net 부호 일치 스팬 ≥ 2/4 (2구간 부호 일치).
- **G4**: OOS 후반 40% net16 > 0.
- **PASS = 동일 셀에서 G1~G4 전부** → 즉시 루프 중단·승격 후보 보고(근거 데이터 포함·플래그 설계 오염 고지)·사용자 결정 대기. 전원 FAIL 시 실패 원인 기록 후 종합정리·장부 갱신.
