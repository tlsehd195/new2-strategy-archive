# 사전등록: C4 프리미엄 인덱스 인트라-인터벌 스파이크 회귀

고정 시각: 2026-10-12 (측정 스크립트 실행 전) · 작성: Z.ai Code (Task 14)
규칙: 본 문서 고정 후 규칙 변경 금지. 사후 파라미터 재조정은 사전등록 위반.

## 1. 가설

2차 리서치 C4 원문: "8h 펀딩율이 아닌 프리미엄 인덱스의 순간 다이내믹스(스파이크/회귀)".
가설: 프리미엄 인덱스가 15m 봉 안에서 극단적으로 밀리면(스파이크) 프리미엄이 회귀한다 → 회귀는 주로 퍼페 가격 반대 움직임으로 실현 → **퍼페를 스파이크 반대 방향으로 진입** (스파이크 상승 → 숏, 하락 → 롱).
C1 실측(L≥48 베이시스 모멘텀 극단 후 추종 음수 = 되돌림 경향)과 방향 호환이나 본 등록은 봉 내(open→close) 스케일의 독자 규격. 펀딩 패밀리 인접성은 사전검증(정보성)으로 정량화.

## 2. 데이터

- 프리미엄 인덱스 15m kline: `NEW2_run/data/premium/{BTCUSDT,ETHUSDT}-15m-*.csv` (65개월, 결측 0) — 봉 내 스파이크 = close − open
- 가격 실행: `NEW2_run/data/klines/{SYM}-15m-*.csv` 시가
- 측정 구간 (X3·C1과 동일 — 잠금 해제 구간만, 예약 TEST 구간 미사용):
  - BTCUSDT: 2021-05-02~2022-08-17, 2023-04-07~2024-03-18
  - ETHUSDT: 2021-05-02~2022-08-17, 2024-12-10~2026-04-20

## 3. 신호 정의 (고정)

- Δp_t = prem_close_t − prem_open_t (15m 봉 내 프리미엄 순변화, 단위 %)
- z_t = (Δp_t − mean(직전 960개 Δp)) / std(직전 960개 Δp) — 현재 제외(인과, shift 1), std≤0 또는 NaN이면 신호 없음
- 버킷: B80 (|z| ≥ 1.2816), B90 (|z| ≥ 1.6449) — 양측
- 방향: **회귀(반대)** — z ≥ +thr → 퍼페 숏 / z ≤ −thr → 퍼페 롱

## 4. 거래 규칙 (고정)

- 진입: 신호봉 t의 다음 봉(t+1) 시가 — 다음 봉 없으면 스킵(fail-closed)
- 청산: 진입봉 + h봉 후 시가, h ∈ {4, 16, 48}
- 보유 구간 내 kline 결측(갭) 있으면 드랍 + 카운트(fail-closed)
- 청산봉이 구간 밖이면 드랍

## 5. 셀 구조와 통계 (고정)

- 셀 = (bucket, h) → 구성당 6셀 × 4구성 = **패밀리 24셀**, Holm step-down (α=0.05)
- 수익률: 단일 거래 수익 (롱/숏 부호 반영), 평균 → 총bp; 순12/순16/순20 = 평균 − 정액비용
- t검정: (평균 − 16bp) / (sd/√valid_n), valid_n = n/h, 양측 p
- 통제: ①스파이크 추종(각 거래 부호 반전) ②무작위 100시드(seed=20261012)
- 유효표본 조건: valid_n ≥ 30

## 6. 판정 규칙 (고정)

- **PASS = Holm p<0.05 셀 ≥1 AND 해당 (bucket,h) 조합이 4구성 중 ≥3 양수(순16>0, valid_n≥30)**
- 통과 시 즉시 OOS: 각 구간 하위 40% 동일 규칙, 양수 세그먼트 ≥2/4 필요
- 전원 실패 시 폐기 권고로 종결, 재파라미터링 없음

## 7. 비용 교차검증 (고정)

- 저장소 엔진 CandleCostModel (costs.py:104-117): fee 5bp + half_spread 2bp + 10%·√participation per side
- 시나리오: $10k / $100k, participation = 주문금액 / 바 거래대금(qv), 5% 초과 fail-closed
- 엔진 비용 기준 Holm 재계산 — 본 검증이 최종 판정 우선

## 8. 패밀리 사전검증 (정보성, 판정에 불가입)

- C4 z vs C1 L=16 z 스피어만 상관 — 동일 변수(프리미엄 변화) 패밀리 인접성 정량화 (C1은 봉간 close→close, C4는 봉 내 open→close로 정의 상이)
- C4 z vs P1 펀딩 z 스피어만 — 펀딩 패밀리 인접성(2차 리서치 조건) 확인
