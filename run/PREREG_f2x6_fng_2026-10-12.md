# 사전등록: F2/X6 공포·탐욕 지수 극단 역발 (Fear & Greed Contrarian, 일간 규격)

고정 시각: 2026-10-12 (측정 스크립트 실행 전) · 작성: Z.ai Code (Task 18, 루프 사이클 6)
규칙: 본 문서 고정 후 규칙 변경 금지. 사후 파라미터 재조정은 사전등록 위반.

## 0. 주파수 제약과 일간 valid_n 규약 (사전 고정 — 본 후보의 핵심 규격 차이)

- F&G는 **일간 1회** 발행(timestamp 00:00 UTC 실측). 15m 빈도 신호와 달리 신호 간 간격이 h와
  같은 스케일 → 기존 valid_n = n/h 규약은 일간 신호에 과잉 보정(무조건 실패로 만듦).
- 본 후보 전용 규약(사전 고정): **valid_n = n / max(1, h ÷ 96)** — h=96(1일) 보유는 연속일 거래와
  시간 분리(비중복) → 보정 1, h=288(3일) → 3, h=672(7일) → 7. 기존 15m 규약과 동일한
  "중복 보정" 원리의 일간 변형이며, 이완이 아니라 정확한 중복 정의임을 명시.
- 나머지 판정 규칙(Holm·3/4·OOS)은 표준 그대로.

## 1. 가설

센티먼트 극단은 역발 신호다 — 공포 극단(F&G ≤ 25) 직후 상승(롱), 탐욕 극단(F&G ≥ 75) 직후 하락(숏)
(X6 정의: "센티먼트 극단 역발"). 배제12(포지셔닝)와 메커니즘 상이(센티먼트 합성지수)는 3차 리서치에서
확인. 알려진 약점(사전 등록): 인덱스 성분의 ~50%가 가격 파생(모멘텀·변동성) → 가격 신호의 재포장 가능성.

## 3. 신호 정의 (고정)

- FG_t = t일(00:00 UTC 시작) F&G 값(정수)
- 버킷 3쌍 사전 고정: (lo,hi) ∈ {(25,75), (20,80), (30,70)}
- 방향: FG_t ≤ lo → **롱** / FG_t ≥ hi → **숏** (역발). 그 외 무신호.
- 임계값 z-스코어링 없음(지수 원값 사용 — 지수 자체가 표준화된 0~100 스케일).

## 4. 거래 규칙 (고정)

- 진입: 신호일 t의 00:15 UTC 15m봉 시가 (open_time == t + 900000). 해당 봉 없으면 스킵(fail-closed)
- 청산: 진입봉 + h봉 후 시가, h ∈ {96, 288, 672} (1일/3일/7일) — 3값 사전 고정
- 보유 구간 내 15m 결측 있으면 드랍 + 카운트(fail-closed), 청산봉 구간 밖이면 드랍
- 같은 날 두 조건 동시 충족 불가(≤lo와 ≥hi는 배타). 연속 극단일은 각각 신호(중복 보정은 valid_n 규약이 처리)

## 5. 셀 구조와 통계 (고정)

- 셀 = (thr쌍, h) → 구성당 9셀 × 4구성(2심볼×2구간) = **패밀리 36셀**, Holm step-down (α=0.05)
- 수익률: 단일 거래 수익(부호 반영), 평균 → 총bp; 순12/순16/순20 = 평균 − 정액비용(12/16/20bp)
- t검정: (평균 − 16bp)/(sd/√valid_n), valid_n = §0 규약, 양측 p
- 통제: ①추종 반전(극단 추종 = 공포→숏/탐욕→롱) ②무작위 100시드(seed=20261012)
- 유효표본 조건: valid_n ≥ 30

## 6. 판정 규칙 (고정)

- **PASS = Holm p<0.05 셀 ≥1 AND 해당 (thr, h) 조합이 4구성 중 ≥3 양수(순16>0, valid_n≥30) AND 유효표본 충족**
- 통과 시 즉시 OOS(각 구간 하위 40%), 양수 세그먼트 ≥2/4 필요
- 전원 실패 시 폐기 권고 종결, 재파라미터링 없음
