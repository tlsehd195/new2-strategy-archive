**성격**: NEW2 저장소 거버넌스의 "Phase A 진단" 등급 측정(등록 예산 미소모, locked/reserved TEST 구간
BTC 2024-03-25~06-18·ETH 2026-04-28~08-31 일절 미사용). 저장소 장부는 수정하지 않는다.
**이 문서는 첫 실행 전에 고정되며 사후 조정 금지.** 측정 큐 2순위(cron 지시: X3 다음).

## F1 — CME 주말 갭 되돌림 (cme_gap, 15m daytrade 실행)

- **시장 가설**: CME 비트코인/이더 선물은 주말에 거래가 끊기지만 현물·알트거래소는 계속 거래된다.
  재개 시 CME 기준 갭(gap = 재개봉 시가 − 직전 일봉 종가)이 크면 CME 트레이더의 미체결 헤지·담보 조정이
  남아 있어 가격이 **갭을 되돌려 메운다(갭 필)** → 재개 후 1~12시간 내 갭 반대 방향 수익이 왕복 거래비용을
  넘는다. 방향은 **되돌림 고정**(갭 상승 → 숏, 갭 하락 → 롱). 추종 방향은 통제로만 보고.
- **근거·비겹침**: CME 갭 필은 실무 관행 주장(lookintobitcoin/bitbo 계열)으로 학술 정합 근거는 약하나,
  만기 효과 문헌(Blasco 2023)과 같은 "선물 캘린더 이벤트" 패밀리. 시간대/세션 무조건부 효과(배제 1)와 달리
  **이벤트 조건부**(주말 갭 ≥ 임계값일 때만)라 비겹침 통과(3차 리서치 판정 유지). L1(분기선물 만기)과는
  만기 대상·메커니즘이 다름.
- **데이터**: Yahoo Finance 일봉 `BTC=F`, `ETH=F` (HTTP 200 실측; ETH=F firstTradeDate 2021-02-05 확인).
  거래 체결은 기존 로컬 Binance 15m kline(2021-04~) 시가 사용.
- **측정 구간**(X3·P1과 동일): BTC 2021-05-02~2022-08-17, BTC 2023-04-07~2024-03-18,
  ETH 2021-05-02~2022-08-17, ETH 2024-12-10~2026-04-20. 워밍업: 직전 일봉 1개면 충분 → 데이터는 2021-04-01부터.
- **신호(인과)**: Yahoo 일봉 시계열에서 연속 일봉 간 달력일 차이가 **≥2일**인 경계(금→일/월, 휴일 포함)를
  주말 갭 이벤트로 정의. gap% = (재개봉 시가 − 직전봉 종가) / 직전봉 종가 × 100. 신호 시각 = 재개봉의
  Yahoo 타임스탬프(epoch ms).
- **버킷(고정)**: G50 = |gap| ≥ 0.5%, G100 = |gap| ≥ 1.0% (고정 절대 임계값 — 롤링 분위수 금지).
- **방향(고정)**: 되돌림 — gap > 0 → 숏, gap < 0 → 롱.
- **진입/청산**: 재개봉 타임스탬프 이후 첫 Binance 15m 봉 시가 진입. 단, 진입 지연(yahoo ts → 봉 open_time)
  이 **30분(1,800,000ms) 초과면 해당 이벤트 폐기**(fail-closed, 스테일 신호 방지 — 사전 고정).
  청산은 진입봉 + h봉 시가. h ∈ {4, 16, 48}봉(1h/4h/12h). 구간 내 15m 연속성 깨지면 폐기(fail-closed).
- **비용**: 왕복 12/16/20bp 정액(대표 16bp) + 엔진 CandleCostModel 교차검증($10k/$100k) — X3·P1 패턴 준용.
- **시도 수(다중검정 가족)**: 2심볼 × 2구간 × 2버킷 × 3지평 = **24셀**. Holm 보정 over 24.
- **표본 독립성(사전 고정)**: 주말 갭은 주 1회 이벤트로 보유 ≤12h에서 상호 겹침이 없으므로
  **valid_n = n**(겹침 보수 보정 n/h를 적용하지 않음 — P1·X3의 연속 신호와 다른 이벤트 구조라 사전 고정).
- **판정(결과 보기 전 고정)**: **PASS** = Holm 보정 p<0.05 셀 ≥1 AND 그 셀과 동일 (버킷,지평) 조합이
  4개 심볼-구간 중 **≥3에서 순16 > 0** AND 해당 조합의 각 심볼-구간 n ≥ 15(주간 이벤트 최소 표본).
  PASS여도 등록이 아니라 선별 후보 제안까지만.
- **OOS 규칙(결과 보기 전 고정)**: Holm 통과 셀 존재 시, 각 심볼-구간을 시간순 60%(IS)/40%(OOS) 분할해
  동일 버킷·지평·방향 적용. OOS 순16 > 0 세그먼트 4개 중 **≥2**여야 승격 후보 자격 유지. 통과 0이면 미실시.
- **패밀리 유의사항**: X3와 동일 변수 아님(가격 갭 vs 베이시스), P1과 무관. C1(베이시스 모멘텀)과도 무관.
  유일 인접 = L1 선물 만기 효과(선물 캘린더 패밀리) — 신호 변수·이벤트 일자가 다름을 결과에 명시.
