# 사전등록: L1 선물 만기(납품) 효과 — 납품 직전 베이시스 압력 되돌림 (진단 등급)

고정 시각: 2026-10-12 (측정 스크립트 실행 전) · 작성: Z.ai Code (Task 20, 목표 루프 사이클 8)
규칙: 본 문서 고정 후 규칙 변경 금지. 사후 파라미터 재조정은 사전등록 위반.

## 0. 구조적 한계 사전 고지 (측정 전 선언 — 정직성 필수)

Binance USDT-M 분기선물 납품은 연 4회/심볼. 측정 구간(잠금 해제분) 내 납품 이벤트는
BTC span1 5건 + span2 4건, ETH span1 5건 + span2 6건 = **총 20건**(사전 계산, fail-closed
필터로 감소 가능). 셀당 n≈20 → 유효표본 valid_n = n/h ≤ 5 → **승격 기준 valid_n≥30 은
구조적으로 달성 불가**. 따라서 본 측정은 승격 후보 심사가 아니라 **만기 효과의 존재 여부와
효과크기의 진단(정보성)** 이며, 판정 규칙은 표준을 그대로 적용하되 PASS=False 예상을
사전 고지한다. 큐 소명 목적: r3_master_summary가 L1을 1순위로 올린 것에 대한 정식 회신.

## 1. 가설

분기선물 납품 순간(t0 = 납품일 08:00 UTC) 직후, 납품 직전 납품계약 베이시스가 밀어낸
포지셔닝 압력이 해소된다 — 납품 직전 계약이 프리미엄(양수 베이시스)이면 베이시스 차익
포지션의 현물 매도·선물 롱 청산 압력이 납품 시점까지 이어지다 해소 → 납품 후 **롱**,
디스카운트(음수)면 반대 → **숏**. 포지션 = −sign(b_pre) (압력 되돌림, fade).
근거: Blasco et al. (2023) 만기 효과 존재 보고 + Quantpedia (2024) 만기 주변 동학
(r3_literature.md L1 행) + 베이시스 수렴 메커니즘. X3(퍼페 프리미엄 붕괴 후 추종 하락)과는
이벤트 성격이 다름(기계적 수렴 완료 시점의 압력 해소) — 패밀리 상관은 정보성으로 산출.

## 2. 데이터 (전원 로컬, 다운로드 0원)

- 납품계약 1h: `NEW2_run/data/qfut/{SYM}_YYMMDD-1h.csv` — 48계약(BTC/ETH × 24, 2021-03~2026-09)
- 스팟 1h: `NEW2_run/data/spot1h/{SYM}-1h.csv`

  - ETHUSDT: 2021-05-02~2022-08-17, 2024-12-10~2026-04-20

## 3. 이벤트 정의 (고정)

- 계약 = 파일명 YYMMDD의 납품일. t0 = 납품일 08:00 UTC (Binance fapi 분기선물 납품 시각).
- 데이터 검증(quality, 판정 불가입): 각 계약 파일의 마지막 1h봉 open_time이 t0와 일치하는지
  기록. 불일치해도 t0 규칙은 변경하지 않음(사전 고정).
- 이벤트 채택: t0가 해당 심볼-구간 내에 있고 §4 데이터가 존재하는 경우만. 구간 밖 이벤트 제외.

## 4. 신호 정의 (고정)

- b_pre(W) = near_c(t0−W·1h) / spot_c(t0−W·1h) − 1, W ∈ {4, 24} 시간 (2값 사전 고정)
  - near_c = **납품되는 계약 자체**의 1h close, spot_c = 스팟 1h close. 해당 시각 봉이 없거나
    spot ≤ 0이면 신호 없음(fail-closed). b_pre == 0이면 스킵.
- 포지션 = −sign(b_pre): b_pre > 0 → 롱(+1), b_pre < 0 → 숏(−1). 문턱값 없음(파라미터 최소화).

## 5. 거래 규칙 (고정)

- 진입: t0 이후 첫 퍼페 15m봉(open_time ≥ t0, 같은 날)의 시가. 해당 봉 없으면 스킵(fail-closed)
- 청산: 진입 15m봉 + h봉 후 시가, h ∈ {4, 16, 48} — 3값 사전 고정
- 보유 구간 내 15m 갭 → 드랍 + 카운트(fail-closed). 청산봉이 구간 밖 → 드랍

## 6. 셀 구조와 통계 (고정)

- 셀 = (W, h) → 구성당 6셀 × 4구성 = **패밀리 24셀**, Holm step-down (α=0.05)
- 수익: 단일 거래 수익(부호 반영) 평균 → 총bp; 순12/순16/순20 = 평균 − 정액비용
- t검정: (평균 − 16bp) / (sd/√valid_n), valid_n = n/h, 양측 p
- 통제: ①추종 반대(+sign(b_pre), 정보성 — 압력 추종 가설) ②무작위 100시드(seed=20261012)
  ③세션 통제(정보성, 판정 불가입): 비납품 금요일 08:00 UTC 무조건 롱 진입 동일 h 베이스라인
  — 만기일 효과가 금요일 08:00 일반 드리프트와 구별되는지 문서화
- 유효표본 조건: valid_n ≥ 30 (§0 고지대로 구조적으로 불가 — 기록용)

## 7. 판정 규칙 (고정)

- 표준 규칙 적용: PASS = Holm p<0.05 셀 ≥1 AND 동일 (W,h) 4구성 중 ≥3 양수(순16>0) AND
  valid_n≥30. §0에 따라 PASS 불가 구조임을 재확인.
- 진단 판독(정보성): 셀별 총bp·부호·반대 통제 대비 차이로 만기 효과 방향과 크기를 기록.

## 8. 비용 교차검증 (고정)

- 엔진 CandleCostModel (costs.py:104-117): fee 5bp + half_spread 2bp + 10%·√participation per side
- 시나리오 $10k/$100k, participation = 주문금액/바 거래대금(qv), 5% 초과 fail-closed
- 엔진 기준 Holm 재계산까지 수행(표준 체크리스트 이행)

## 9. 패밀리 사전검증 (정보성, 판정 불가입)

- L1 신호는 이벤트 조건형이라 연속 z와 직접 상관 불가 → 대체 검증: b_pre 값과 같은 시각
  퍼페 프리미엄 인덱스(premium 파일 1h 환산) 스피어만 상관 — 납품계약 베이시스가 퍼페
  프리미엄(X3/C1 패밀리)과 동일 정보인지 확인. 표본 20건으로 낮은 파워 사전 고지.
- OOS: Holm 통과 셀이 있을 때만 실행(예상: 없음 — §0)
