## 0. 배경과 검정력 사전 고지 (정직 선언)

- 사용자 지시("지금까지 조사한 전략들을 조합해서 가장 승격 가능성이 높은 쪽으로 진행" + "조합 검증 더 해봐 승격 가능성 높은걸로")의 직접 이행. 측정 27건 전원 FAIL 상태에서 승격 가능성이 가장 높은 조합은, 27건 원기록 전수에서 **엔진 비용 차감 후 양수인 유일한 2건의 탐색 관측**(X1-R 엔진 +21.7bp·F2/X6-R 엔진 +36.19bp)을 **하나의 통합 풀로 결합**하고 **N2 maker 실행계층**을 적용하는 것이다. 두 관측은 동일 구조("외부 극단 스트레스 직후 암호자산 단기 반등")로 worklog Task 18에서 이미 통합 재검증 대상으로 문서화된 바 있다.
- **검정력 사전 고지 (결과 보기 전)**: 발표된 성분 통계로부터 Stouffer 결합 기대치는 Z_pool ≈ (0.58+0.76)/√(2+2ρ̂) ≈ 0.84~0.95 (taker arm)이며, Holm(2셀) 통과에 필요한 Z ≈ 1.96~2.24에 **크게 미달이 예상된다**. maker arm도 절감(~13bp) 대비 평균 증가분이 제한적이라 Z 상승폭은 소폭이다. **G-C1 통과 확률은 낮다.** 본 측정의 1차 과학적 가치는: (Q1) 조합의 승격 거리를 추정이 아니라 **실측으로 확정** (Q2) 두 성분의 실측 상관 ρ̂ — 포트폴리오 계층 설계의 직접 입력 (Q3) N2 maker 절감이 일간(FG) 이벤트에 전이되는지 실측. 승격 판정은 부수 결과다.
- **범위 고지**: 본 측정은 두 성분이 이미 발표된 원기록 위에서의 **통합 진단**이다. 성분 선택의 자유도를 차단하기 위해 성분 셀은 원기록에 발표된 그대로(셀 1개씩) 기계적으로 고정하며, 재선택·재임계값·지평 변경을 일절 하지 않는다. 통과해도 신규 구간 확인 전 승격 아님(CONDITIONAL_CANDIDATE — F2/X6-R 선례 준용).

## 1. 성분 정의 (사전 고정 — 원기록 그대로, 재선택 금지)

- **C-A: X1-R Config R 통합 이벤트 셋** (원기록: x1r_reverify_results.md Config R)
  - 신호: ES/NQ 1h Δz (L∈{24,120}, 직전 720 관측 인과 표준화), |z|≥1.2816, **역방향** (z≥+thr→숏 sgn=−1, z≤−thr→롱 sgn=+1)
  - 실행: ETHUSDT 15m, 진입 = 신호 1h봉 t 확정 → t+1h 시점 15m봉 ei 시가, h=48봉 청산 (ei+48 시가)
  - 구간: 2024-12-10~2026-04-20 (ETH s2 — 잠금 구간과 무관, 스팬 종료가 잠금 시작 이전)
  - **통합(union) 규칙 (기계적)**: 4구성(ES_L24→ES_L120→NQ_L24→NQ_L120 고정 순서)의 이벤트를 생성 후 (ei, sgn) 중복 제거 — 최초 출현 1개만 유지. 동일 ei에 상반 sgn 공존 시 둘 다 유지(포트폴리오 공존). 드랍 규칙은 X1-R 준용(fail-closed: [ei, ei+48] 갭·스팸 밖 드랍)
  - 유효n: n_union/48 (15m 규약)
- **C-B: F2/X6-R 셀** (원기록: f2x6_fng_results.md ETH span2 thr25/75 h288 — 엔진 +36.19bp 셀 그대로)
  - 신호: FG(D)≤25 (thr쌍 (25,75)의 롱측만) → D+1 00:15 UTC 15m봉 시가 진입, h=288봉(3일) 청산
  - 실행: ETHUSDT 15m, 구간 2024-12-10~2026-04-20 (원 셀과 동일)
  - 유효n: n/max(1, 288÷96) = n/3 (일간 규약 — 원 측정 사전 고정 규약 준용)
  - 숏측(FG≥75)은 원 셀 정의에 없으므로 **포함하지 않는다**(성분 재정의 금지)
- **교차 성분 규칙**: C-A와 C-B는 병합하지 않고 **독립 성분으로 병행 운용하는 포트폴리오 결합**이다. 같은 ETH 가격 경로에 걸리는 중복 보유(홀드 구간 중첩)는 결합 통계의 상관 항으로 처리한다(§3). 성분 간 이벤트 드랍·병합 없음.

## 2. 실행계층 (사전 고정)

- **Taker arm**: 성분별 원 측정 규격 그대로 — 진단 지표는 **정액 순16bp** (원기록 판정 기준 준용). 엔진 교차검증은 별도 스크립트(combo_engine_crosscheck.py)에서 CandleCostModel(§5)로 실시.
- **Maker arm**: N2 규격 그대로(δ=0bp, K=16봉만 사전 고정 — 체결률 최고 구성):
  - 지정가: 롱 P_lim = open(ei)×(1−0), 숏 P_lim = open(ei)×(1+0) — δ=0은 개선 없음(P_lim = open(ei))
  - 체결: ei 포함 K=16봉 내 롱 open(b)<P_lim → 체결가 open(b) / low(b)<P_lim → 체결가 P_lim. 터치(==)는 미체결. 숏 대칭
  - 체결봉 f → f+h 시가 taker 청산 (C-A: h=48, C-B: h=288). [f, f+h] 갭·스팬 밖 → fail-closed 드랍(체결 후 FC)
  - 비용: 진입 maker 2bp + 청산 taker 엔진 1면(5bp + half_spread 2bp + 10%·√participation, 주문금액 $10k, >5% fail-closed)
  - **promotion-basis 순엣지 = 체결률 × E[순익|체결]** (N2 §3 규약)
  - C-B(일간 h288)에의 전이가 Q3 — 체결윈도우 K=16봉(4h)은 진입 직후 4h로 동일 적용
- t검정: 성분별 원 규약(C-A: n/48, C-B: n/3; maker arm은 체결분 기준 valid_n = n_filled/h — N2 규약)

## 3. 결합 통계 (사전 고정)

- **Stouffer 결합 (상관 조정)**: Z_pool = (Z_A + Z_B) / √(2 + 2ρ̂), 단측(양의 방향)
  - Z_A, Z_B: 각 arm에서 성분별 t통계 (taker arm: 정액 순16 기준 t; maker arm: 체결분 net 기준 t — N2 규약)
  - **ρ̂ 실측 규칙**: 스팬 내 캘린더 일자별로 C-A 이벤트(당일 진입분)의 sgn-adjusted 원시수익 일평균과 C-B 이벤트의 원시수익 일평균을 매칭, 양쪽 모두 존재하는 일자에서 Pearson 상관. 매칭 일자 <30일이면 ρ̂ = 0.5 고정(양 성분 모두 ETH 스트레스 국면에 집중되는 구조적 상관에 대한 보수 기본값). ρ̂ 하한 0(음수면 0으로 절단 — 보수적)
- **패밀리**: {POOL-taker, POOL-maker} = **2셀 단일 패밀리 Holm** (성분 셀 C-A·C-B 단독은 이미 발표된 원기록의 재생산 확인용 — 정보성, 판정 가족에서 제외. 단 재생산 편차가 ±2bp를 넘으면 품질 게이트 실패로 전 측정 무효 처리)
- **통제 (사전 고정)**: 무작위 방향 100시드(시드 20261014) — 풀 각 arm에 적용(P(랜덤≥)). 추종/반대 통제는 성분 원기록에 이미 보고됨(재보고 없음)

## 4. 판정 게이트 (결과 보기 전 고정)

- **G-C1 유의성+경제성**: Holm(2셀) p<0.05인 arm이 존재 AND 그 arm의 순엣지 양수 (taker arm: 정액 순16>0, maker arm: promotion-basis>0)
- **G-C2 엔진**: combo_engine_crosscheck.py에서 해당 arm 성분 전부 엔진 순익 양수($10k; $100k는 보고만)
- **G-C3 일관성**: 60/40 시간 분할(cut = s + 0.6×(e−s), X1-R OOS cut 규용)에서 POOL 순엣지 양방 양수
- **G-C4 신규 구간 방향성 (정보성 게이트)**: 신규 구간(ETH 2026-04-21~04-27 + 2026-09-01~2026-10-12; 잠금 2026-04-28~08-31 제외)에서 POOL-taker 순16 방향 확인. F&G≤25 신규 이벤트 희소가 예상되어 유효n <3이면 "판정 불가"로 기록 — 판정 불가는 G-C4 FAIL이 아니라 **조건부 대기 사유**다. 방향이 음수면 FAIL.
- **전 통과 시 → CONDITIONAL_CANDIDATE**: 루프 중단, 사용자에게 승격 후보 보고(근거 데이터 포함) 후 결정 대기. 단 사후 고지: 본 측정은 기존 구간 내 통합이므로 신규 구간 재확인(2027-01경 F&G 재검증 사이클) 전 실전 승격 아님.
- 하나라도 FAIL → **C-COMBO 종결**: 결합 통계·ρ̂·승격 거리(필요 Z vs 실측 Z)를 기록 보존하고, "조합 계층도 기존 데이터로는 검정력 부족 — 성분별 신규 데이터 축적(2027-01)이 선행됨"을 결론으로 기록.

## 8. 부칙 — 측정 전 정정 (첫 실행 품질 게이트 발화, 결과 열람 전, ALT-P1 §8 선례 준용)

- **C-B 셀 정의 정정**: §1의 "숏측(FG≥75)은 원 셀 정의에 없으므로 포함하지 않는다"는 문구는 원 셀 정의에 대한 **부정확한 기술**이었음이 재생산 게이트(n=150 vs 기대 177)로 첫 실행에서 확인됐다. 원기록(f2x6_fng_results.md ETH span2 thr25/75 h288, n=177·총bp 74.78)의 셀은 **양측 셀**이다: v≤25 → 롱(sgn=+1), v≥75 → 숏(sgn=−1)이 모두 동일 셀에 집계된다(스크립트 f2x6_fng_diag.py의 셀 순회 구조 원기록 확인). 정정: C-B는 **양측 셀 그대로**(v≤25 롱 + v≥75 숏, h288, n≈177)로 구현하며 재생산 목표(n=177, 74.78bp)와 일치해야 품질 게이트 통과. 이 정정은 결과 열람 전이며 재생산 목표값은 원기록에서 사전 고정된 값 그대로다 — 결과 유도적 조정 아님. worklog에 정정 사실 기록.
- 참고(정직 고지): worklog Task 18의 "ETH span2 극단공포(≤25)→3일 롱 엔진 순익 +36.19bp" 기술은 셀의 롱측만 묘사한 것으로, 실제 셀은 양측 혼합이다. 본 측정의 C-B는 원기록 셀 정의(양측)를 따른다.
