## §1 신호·실행 (0-자유도 승계 — 변경 금지)

- **신호 = F2/X6 원규격 그대로**: FG(D−1) 확정 일간 값 → 일 D 전체 15m 신호봉. B90(≤10→롱 / ≥90→숏), B80(≤20→롱 / ≥80→숏) **역발상**. 진입 = 신호봉 t의 다음 봉(t+1) 시가, 청산 = t+1+h 시가. 연속성 깨짐·구간 밖 fail-closed 드랍(카운트 보존).
- **실행 = maker 진입 δ=0bp·K=16봉** (N2/COMBO-1 계약 승계): 롱 P = open(1−0) — 다음 봉 open이 P 아래로 갭하면 open 체결, low가 P 터치하면 P 체결, K봉 내 미체결 시 포기(프로모 시리즈 0 기여). 숏 대칭. 체결 시 진입 비용 = maker 2bp.
- **청산**: 체결 봉 f + H 봉 시가 + 엔진 taker 1면 (fee 5bp + half_spread 2bp + 10%·√participation, 참여>5% fail-closed). 청산 구간 연속성 깨짐 fail-closed.
- **회계**: 진입 maker 2bp + 청산 엔진 taker 1면. **자금조달(funding) 미포함 — COMBO-1과 동일**(h48은 funding 경계 최대 1회 — 승격 시 별도 정산 검증 필요 항목으로 고지).
- **promo순 = 체결률 × E[순익|체결]**, 봉별 promo 시리즈(미체결=0). t-검정 **유효n = n봉/h** (F2/X6 원관례 승계 — 같은 일 내 인접 신호봉의 지평 중첩 통제), 양측, df=유효n−1.
- ORDER_VALUE = $10k (기본). $100k는 정보성 I6.
