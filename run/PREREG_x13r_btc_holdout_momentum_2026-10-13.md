# PREREG — X13-R: 극단 일간 상승일 모멘텀(롱) BTC 홀드아웃 재검증

작성 일시: 2026-10-13 (Task 33 후반부 — X13 측정 직후, 같은 세션)
선례 준용: X1→X1-R 패턴(Task 24 — 반대 방향 엔진 양수 관측의 사전등록 홀드아웃 재검증)

## 0. 배경과 정직 고지
1. **관측 출처**: X13(Task 33, PREREG_x13_universe_extreme_reversal_2026-10-13.md)에서 1차 방향(극단 상승일 → 숏)이 기각되고, **반대 방향(극단 상승일 → 롱·모멘텀 추속)**이 원시 통계로 강하게 확인됨: B80 L90h96 pooled gross +92.4bp(net16 +76.44bp, p=0.0072, 군집 389, 6코인 전 기여, era1/era2/OOS 전방위 일관 — flat 비용 기준).
2. **엔진 교차검증 결과**: 풀링 엔진($10k) net −7.96bp — 전체 유니버스 기준 비용벽 소멸. **그러나 코인 분해에서 BTC 33.6bp·ETH 37.3bp의 낮은 비용 + era1(BTC/ETH 중심, 엔진 순익 +45.5bp) 관측**이 남는다. 이는 "유동성 최상위 자산에서만 모멘텀이 비용을 넘는다"는 자산 제한 가설로, 홀드아웃 검증 가능.
3. **사후 선택 문제 고지**: BTC/ETH 제한은 X13 결과를 본 후의 선택이다(데이터 스누핑 위험). 이를 보상하기 위해 (a) X13 측정에 사용된 BTC/ETH 스팬(2021-05~2024-03 BTC, 2021-05~2022-08 + 2024-12~2026-04 ETH)을 **완전 배제**, (b) X13 패밀리가 전혀 보지 못한 **BTC 신규 구간**만 사용, (c) 12셀 패밀리 Holm + 엔진 + OOS 전체 게이트 적용, (d) 게이트 통과 시에도 "조건부 후보"로만 보고(cron §5 승격 아님 — X1-R 선례).
4. **검정력 사전 고지**: BTC 단일 자산·홀드아웃 구간이므로 에피소드 수가 제한된다(L288은 잠금 오염 차단으로 유효 개시 ~2025-04). 원시 관측 크기(gross +92bp, net +58bp @ BTC 비용)가 유지될 경우에만 검정력이 존재 — 감쇠 시 무유의 예상(X1-R과 동일 구조).

## 1. 유니버스·스팬 (사전 고정)
- 자산: **BTCUSDT 단일** (엔진 비용 최저 자산 — X13 코인별 비용 지도 기반 사전 논증).
- 스팬: **2024-06-19 ~ 2026-10-12** (X13 BTC 스팬 종료 2024-03-18 + 잠금 2024-03-25~06-18 직후 개시 — 발견 풀과의 중복 0일. 데이터 실측: BTC 15m 파일 2026-10-11까지 존재).
- z-윈도우 잠금 오염 fail-closed: L=288은 z가 2024-06-18 이전을 참조하는 날 전부 NaN(유효 개시 ~2025-04-05), L=90은 ~2024-09-15부터 유효. 구조적 손실로 기록.

## 2. 신호·방향 (사전 고정)
- X13과 동일 신호: 일간 로그수익률(완전일만), z(인과 L∈{90,288}), 버킷 B80(z≥+1.2816)/B90(z≥+1.6449) — **양의 꼬리만**.
- **1차 방향: 롱(모멘텀 추속)** — X13에서 기각된 숏의 반대이며, X13 원시 통계가 지지한 방향. 진입 S일 00:15 봉 시가, 청산 +h봉 시가, h∈{16,48,96}.
- 에피소드 병합 상태 머신(교훈 ⑦) + 최소 진입 간격 2일 — h_max 24h < 48h → 겹침 0, valid_n = n(교훈 ⑧).
- 통제(관측 전용): 반대(숏·복권) 방향, 음의 꼬리 MIN 롱, 무작위 100시드.

## 3. 패밀리·통계·게이트 (사전 고정)
- 패밀리 12셀 = {B80,B90} × L{90,288} × h{16,48,96}, Holm-Bonferroni.
- 비용: 정액 12/16/20bp + **엔진 CandleCostModel($10k/$100k)** — X13 교차검증과 동일 공식·fail-closed.
- t-검정: valid_n = n (겹침 0 구조), 단일 자산이므로 군집=일=에피소드.
- **PASS 게이트(전부 충족 시 조건부 후보)**:
  1. p_holm < 0.05 (12셀)
  2. 엔진($10k) 순익 > 0
  3. OOS(스팬 하위 40%) 엔진 순익 > 0
  4. n ≥ 30 에피소드
  5. (보고 전) 펀딩 감사 — 롱 포지션은 양의 펀딩을 지불(또는 수취)하므로 정산 시점 비용 반영 감사 실행
- 펀딩 감사 방법(사전 고정): 진입~청산 구간이 걸치는 펀딩 정산(00/08/16 UTC) 횟수 × 구간 내 평균 펀딩레이트를 순익에서 차감하여 재판정. 펀딩 데이터: Binance Vision fundingRate 월간 아카이브(신규 다운로드 허용 — BTC만).
